## 2. Exact new claim and first-principles premise

**Target theorem (existence).** For the CA5-GNC-R dark sector on the compact leaf with fixed
carrier data (five real fields, `K_d, W_exc > 0` bounded, `V_0 > 0`), fixed gate data
(`f, Y_h` frozen; heat constraints imposed as in FINAL_ACTION §3–4), there exists a smooth
positive lapse `N > 0` and a smooth `Z` (with `t = 1 + Z − ⟨Z⟩_h ∈ (0, T]`, T fixed) solving
the coupled pair:

```
M_P²/2 { R(3) − T_K − 2Λ + c₂[−Q_K² + 2KQ_K − 2KA_K/N] + V_a − div_N[2α(a−DZ)+4DZ]
         + c_N[G(Y_h) − ℓΔ_h W_b] } = ρ_b + tK_d + W_exc/t + V_0F(t)        (L)
2 M_P² c_N div_N(DZ − a + DU) + (K_d + W_exc/t² − V_0F′(t))
         − ⟨N(K_d + W_exc/t² − V_0F′(t))⟩_h/N = 0                             (Z)
```

with `ρ_R = tK_d + W_exc/t + V_0F(t)` and `σ_R = K_d + W_exc/t² − V_0F′(t)` exactly as derived
in AS127 (★) and R3. First-principles premise: the varied common action of CA5-GNC-R
(FINAL_ACTION eq. (4) with R1 replacement); no new law, no fitted coefficient.

**Why AS127 does not already answer it:** (★) is a pointwise identity; the coupled
existence/positivity problem uses (★) as the *source* inside the elliptic pair (L)+(Z),
which is nonlinear in Z through `t` in both ρ_R and σ_R, and in N through `div_N`, `a = D ln N`,
and the mean projector. BARRIER_PROOF.md solves Z at fixed positive data only; (L) is not
treated there.
