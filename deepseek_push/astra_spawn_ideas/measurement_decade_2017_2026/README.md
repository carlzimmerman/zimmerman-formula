# Measurement decade: 2,500 additional work orders

250 individual tasks for each calendar year **2017–2026**, anchored to 100 dated primary measurement reports or data releases (10 per year). The 2026 cutoff is **27 September 2026**. Year means first public measurement report or actual data-release year, not necessarily observation year; observation epochs and date precision are recorded separately. These are proposed calculations, not executed research or evidence that gravity is closed.

Start with [INDEX.md](INDEX.md), [SOURCES.md](SOURCES.md), and [DISPATCH.md](DISPATCH.md). Every task has its own Markdown file in a year folder and a structured record in [manifest.json](manifest.json). The original [AS001–AS2000 catalog](../INDEX.md) remains separate: **4,500 seed tasks combined**. Finding-driven children and independently owned FGF tasks are additional and are not included in that count.

Each work order identifies its measured input, mathematical principle, equations, negative control, first-principles obligation, closure bridge and three follow-up routes. Derive the observation map from the core framework before using it. Source abstracts/release pages authenticate the reported measurement and chronology; they do not certify full likelihoods or the authors' conclusions. Raw files, covariances and selection functions must be obtained, inspected and hashed by the executing worker. Where unavailable, do valid symbolic work and return the exact data blocker.

Use the parent [framework contract](../FRAMEWORK_CONTRACT.md) and [first-principles/branching protocol](../FIRST_PRINCIPLES_AND_BRANCHING.md). Filtered MONO, criterion B, both acceleration footings and the amended thirteen gates remain explicit in each card. Measurement-conditioned support, a counterexample, and a proof of nonidentifiability are all useful outcomes. A successful fit cannot fill a missing action or dynamical equation.

**100 source anchors are not 2,500 independent datasets.** Reports often share observations or reuse prior releases. Each task requests a distinct observable/estimand or scoped mathematical obligation. Cross-release tasks must isolate new information, systematic differences or conditional updates; neither multiple tasks on one survey nor overlapping releases multiply independent evidence. Consult [REVIEW_NOTES.md](REVIEW_NOTES.md) for the limits of duplicate screening.

Validate from the repository root:

```bash
python3 deepseek_push/astra_spawn_ideas/measurement_decade_2017_2026/validate_catalog.py
```

Validation checks files, record fields, dates, links, hashes, counts and exact duplicates. It is not a proof of universal semantic novelty, scientific correctness or closure. The catalog installs no runner, buys no compute, and starts no DeepSeek jobs. [LAUNCH_PROMPT.md](LAUNCH_PROMPT.md) is the single orchestration prompt for an actual configured runner.
