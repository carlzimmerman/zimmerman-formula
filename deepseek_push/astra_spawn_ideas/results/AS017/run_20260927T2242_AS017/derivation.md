## 2. Step 1 — the precise statement and its two readings

**Global hypothesis H_G.** ε_L = ε_Λ = const (cosmological constant). Then a0 = κ c √(G ρ_Λ) is a *universal constant*: one number per footing (κ = 1/2 adopted). This is what the framework uses (README: "a0 = kappa c sqrt(G rho_Lambda)", κ = ½ fitted; z-evolution a0(z) ∝ √ρ_DE(z) only, spatially constant).

**Local hypothesis H_L (candidate).** ε_L = ε_L(x) — environment-dependent vacuum density; a0 = a0(x) via (L). Two facts follow immediately:

1. **Dimensional consistency:** [G·ε] = (m³ kg⁻¹ s⁻²)(kg m⁻¹ s⁻²) = m² s⁻⁴, so √(Gε) = m s⁻² ✓, κ² dimensionless ✓. a0² = κ²Gε reproduces the framework relation 4a0² = Gc²ρ_Λ with ε = ρc² at κ = 1/2 (certified: T1).

2. **The transfer identity** (task's stated object). From a0² = κ²Gε and (a0+δa0)² = κ²G(ε+δε):
```
2 a0 δa0 + (δa0)² = κ² G δε        (exact, no approximation)
δa0/a0 = (δε/ε) / (1 + a0'/a0)      (exact finite form; a0' = a0 + δa0)
δa0/a0 = (1/2)(δε/ε) + O((δε/ε)²)   (leading term)
```
The exact finite fraction is Lean-certified (T2, T3, T4): with a² = κ²Ge, b² = κ²Gf,
`(b−a)/a = ((f−e)/e)·(a/(a+b))`, whose b→a limit is the ½ coefficient. Because the identity is a ratio of same-dimensional quantities, **it is footing-independent**: it applies verbatim on the canonical and the alternative footing (verified numerically on both, C1; the finite correction q/(1+√(1+q)) at q = δε/ε = ±0.5 differs from q/2 by ≤ 0.043, i.e. second order).
