## Overview

As of 2025, three interstellar objects (ISOs) have been confirmed:
1. **1I/'Oumuamua** (2017) - First confirmed ISO
2. **2I/Borisov** (2019) - First interstellar comet with visible activity
3. **3I/ATLAS** (2025) - Largest ISO discovered, likely from galactic "cosmic noon"

Additionally, a new class called **"dark comets"** has been identified - asteroids with anomalous non-gravitational accelerations consistent with undetected outgassing.

## Dark Comets: Anomalous Non-Gravitational Accelerations

### Definition

Dark comets are asteroids that exhibit non-gravitational accelerations consistent with cometary outgassing, but show no visible coma, dust tail, or other cometary activity. First identified as a class in 2023.

### Key Property

- Non-gravitational accelerations exceed Yarkovsky effect
- No radiation-based nonradial effect can explain magnitudes
- Likely due to undetected volatile outgassing
- May represent "stealth comets" with subsurface ice

### 1I/'Oumuamua as Proto-Dark Comet

'Oumuamua was the first object to exhibit "dark comet" behavior - anomalous non-gravitational acceleration without visible outgassing. By 2024, it was reclassified as the first member of the dark comet class.

## Non-Gravitational Acceleration Models

### Standard Cometary Model

The non-gravitational acceleration follows:
```
a_ng = A₁(r/r₀)^n ê_r + A₂(r/r₀)^n ê_t + A₃(r/r₀)^n ê_n
```

Where:
- A₁, A₂, A₃: radial, transverse, normal components
- r: heliocentric distance
- r₀: reference distance (typically 1 AU)
- n: typically -2 for sublimation-driven acceleration

### 'Oumuamua Acceleration Analysis

| Model | Viability | Issues |
|-------|-----------|--------|
| Solar radiation pressure | No | Requires unrealistic area/mass |
| Yarkovsky effect | No | Too weak by orders of magnitude |
| Solar wind (magnetic) | No | Requires unrealistic magnetization |
| Cometary outgassing | Maybe | No visible tail; spin issues |
| H₂ ice sublimation | Tested | Cannot survive interstellar journey |
| N₂ ice fragment | Tested | Exotic composition required |
| Artificial sail | Unlikely | Simpler explanations available |
