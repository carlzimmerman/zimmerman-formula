# X60 AMENDMENT A1: retention-pattern gate R5 (coordinator request; POST-RESULT, disclosed)

Added after the first full run had produced graded numbers (not yet committed). The coordinator asked for it because
X58 (c3b4f2c7d9) finds the required retention pattern is non-monotone in mass. Disclosed as post-result. It can only add
failures; it removes none, and no frozen line is changed.

**R5 (pattern).** On each footing, the escape's key must give:
- RETAIN (dust) for dwarfs, M200 1e8 to 1e10 M☉;
- EXCLUDED (vacuum) for L* lenses, 10^11.35 to 10^12.05 M☉;
- RETAIN for groups and clusters, M ≥ 1e13 M☉ (graded at 1e13, 1e14, 1e15).

All three must hold for one threshold g′ (any g′ > 0 is allowed, so this is scanned, not fitted).

**How it is graded.**
- **E1-a and E2-L (smoothed key, mean model as frozen).** R5 passes if, at some R_k on the frozen grid, the smallest key
  over dwarfs and over M ≥ 1e13 exceeds the largest key over L*. Masses are sampled every 0.05 dex.
- **E1-b, E2-O, E3-P, E3-N (object core or virial key).** R5 passes only if the key is lower at L* than at both ends of
  the mass range. A key that rises monotonically in M fails.

**Disclosure.** Below 1e11 M☉, Σ_coll is a log–log extrapolation of X41's table, using the slope of its 1e11–1e12
segment. Uniform-sphere objects follow ledger A5.

Verdict lists gain R5 where it fails. The reported A3 block (dwarf > L* < cluster at 1e9–1e10, mean model) stays as a
reported diagnostic.
