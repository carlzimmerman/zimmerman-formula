# HX1 AMENDMENT A1 (pre-result: written with the code, before any check or graded number was run)

1. **SLUGGS B_need by root.** h50's `sigma_los` interpolates log sigma_r^2 between grid radii, so D = mean sigma_los^2 is linear in g only up to interpolation error. The criteria's closed form is exact for the B1 integral, Lovisari and X-COP, but not here. For SLUGGS, B_need is the root of D(B) = D_obs in B (brentq, xtol 1e-10), with g = g_N + B (law - g_N). When D_obs < D_N the root would need B < 0, where g can go negative and h50 floors sigma_r^2; there the closed form is used, and only the sign matters to the median. K2 reports the closed form's relative error against the exact D at B = 2 for 5 SLUGGS galaxies. A line of 1e-3 is reported, not the 1e-9 the other estimators must meet.
2. **Rung errors that reach B <= 0.** A rung whose bootstrap or systematic band reaches a median B_need <= 0 has an infinite or undefined s. In L-ORDER and K3 it is given s = 1e3 (no weight), and that is reported. A rung whose own median is <= 0 is still SUB-NEWTONIAN and fails L-ORDER, as frozen.
3. **K3 implementation.** The planted ladder and break are built at the rung level: y_planted plus normal noise at each rung's real s, at the rungs' real keys. Each reads its median p over 200 planted draws, with 500 inner bootstrap draws per p. The ladder must give median p >= 0.05 and median NEED Z > 2, and the break median p < 0.05. Whether the real keys put any elliptical rung below every group rung (so the planted break is a true break) is reported.
4. **X-COP rung bootstrap** resamples clusters, with all of a cluster's points kept together. Bootstrap objects elsewhere are systems.
5. **L-FLAT X-COP** uses the points with B_need > 0. The count is reported.
6. **SLUGGS's systematic.** Every measured outer sigma is shifted by +-sigma_A26a dex, where sigma_A26a is the law's A26a stat error on that footing, and half the change in y is taken.
