## 1. All three fitting starts

G1 item 4 says three starts agree within 15%. The historical scorer instead selected starts with chi-square within 9 of the best, so a singleton could pass. Corrected code compares ALL THREE finite positive speeds, on BOTH P-B and P0, at the radius actually scored. Spread = (maximum - minimum) / median; both spreads must be <= 0.15. No chi-square-based removal. An invalid or missing start fails the gate. Individual speeds, chi-square values and spreads are saved. The best-chi-square trial still supplies the reported fit. All other fit bounds remain unchanged.

## 2. Fixed uncertainty floor: explicit operational amendment

The historical implementation used the fractional RMS of the valid compact mocks in the committed ac1_score_power_results.json: sqrt(mean((V_rec/430 - 1)^2)) = 0.088731... (8.9% rounded). G1 item 6 described scatter “at the measured S/N”, which the code did not implement.

For this revision the fixed archived floor is explicitly retained, without claiming it is S/N-matched. Report error = max(quoted error, archived fraction * measured speed), separately for each pressure/inclination branch. The exact fraction, source SHA-256, quoted error and applied floor are saved in each scored output. The historical calibration sample is not reselected after fixing fit validity. Retaining it preserves the previously applied error floor; no precision improvement is claimed.

This is a finite mock calibration, not a frequentist 68% coverage guarantee or a bound for arbitrary morphology, velocity, inclination or noise. Scores remain conditional on the adopted thin-disc model and error prescription. The paper must state those limitations. A release whose fit is physically inappropriate (e.g. unresolved beam-smearing warning, non-disc structure) must not be promoted to evidence for/against the law merely because numerical gates pass. Report model inadequacy separately; do not invent an outcome-dependent gate or tune the floor on the released velocity.
