# HF1 AMENDMENT A1: readings fixed before any graded number

Written after reading the machinery and before any fit. Seen so far: one CLASS timing run at m 11.3 eV, T_nu, unfitted (h 0.702, N_eff 4.04, 9 s wall). No chi2 was computed. The criteria leave the points below open. These are readings, not changes to a line. kappa = 1/2 FITTED. Not theory closed.

**R1 Spectrum (gate 1).** The criteria don't state one. Primary: Fermi-Dirac at the fermion's own temperature, f(0) = 1/2, so the spectrum and the Tremaine-Gunn bound below use one f_max. T_f = T_nu (omega_f x 93.14 / m)^(1/3), with deg_ncdm = 1 (g_f = 2) and N_ur 3.044 kept, so the fermion's relativistic energy adds to N_eff. Thermal at m near 11.3 eV. Two more spectra run as reported variants, never graded and never able to move the label: V-chi, T_nu with number scaled by chi, legal where chi <= 2; V-cold, degenerate at ksi = 5 with the same f_max and same n. If a variant passes where the primary fails at every m, the label stays EARLY FAIL and the case goes to the owner.

**R2 Gate 1 line.** RF5's gates: G-CMB, G-BAO, G-SN, G-SHEAR at p >= 1e-3, RF5's fixed shear cut read from RF5's file, G-A0 in CFG689's band, and G-S with S - S_min <= 25. S_min is RF5's 2324.03, read from `rf5_results.json`: the line is RF5's own, and a minimum over this lane's six cells would let a poor family pass against itself. The S against this lane's own minimum is printed beside it. RF5's forest channel isn't in the frozen list for gate 1. An unconverged fit reads UNDETERMINED, as RF5. Free as RF5: omega_b, omega_f, theta_s, A_s, n_s, tau, w0, wa, A_planck. A massless-sector change isn't fitted.

**R3 Choosing m and omega_f.** omega_f is each m's best fit. Among m passing gate 1, m is the one that passes X-COP train (positions 0, 2, 4, 6, |mean| <= 0.05, rms <= 0.10) and SPARC train (odd names, BF1's rms <= 1.05 x the law's, |median| <= 0.03); if several pass, lowest S; if none pass both, smallest |mean| on X-COP train. If no m passes gate 1, the same rule runs over all six for the numbers-only gates 2 and 3. Holdouts play no part.

**R4 Fermion profile, one rule for every system.** rho_f(r) = min(rho_cap, rho_1 exp(-(Phi(r) - Phi(r_ta)) / sigma^2)), with M_f(<r_ta) = (omega_f / omega_b) M_b(<r_ta), fair share, by CRG1's measured chain and r_ta, and M_f constant beyond. rho_cap = m^4 (g_f / 2 h^3) (2 pi sigma^2)^(3/2). sigma^2 = V_max^2 / 2, V_max the highest circular speed of the model inside the system's radius: R500 for clusters, R_last for SPARC, R_max for LITTLE THINGS, 3 Hernquist a for groups, r_1/2 for dwarfs. Solved self-consistently with the law on M_b + M_f. Fair share is an upper bound on retention; infall isn't modelled. sigma is the model's, never an observed one, so no dynamical datum enters the prediction. One reported variant on SPARC uses measured V_flat / sqrt 2. QUMOND and AQUAL coincide in spherical symmetry with this nu, so the AQUAL bracket on gates 2 and 3 is zero by identity, and that's stated rather than computed.

**R5 Gate 2 line.** X-COP all seven, FG1's X line, train and holdout printed. Keys: FG1's K line, 15 of 15, either h, template mode, f* 0.034, gas +0.005, on CRG1's code; f* 0.0615 reported. B = 1 from DA1's code form, n(z) from DA1's stored factor `F` in `da1_keys.json`. Gate 2 passes on X and K. OUTER Z printed for NU1's warning.

**R6 Gate 3 line.** Must hold, per criteria, on both backgrounds' identical law path, canonical primary, alt beside: S rms <= 0.110 and Upsilon 0.50-0.80; Tl <= 0.15; surface-brightness slope |Z| <= 2 by RQ3's `hs_row`; LT <= 0.10; G CONSISTENT. Dw, MW, IC 1613, DiskMass are reported. The law fails Dw, MW and IC already, so they don't decide this gate; MW and IC are stated as expected fails in the criteria. DA1's windows beside.

**R7 Gate 5.** Runs only on an m that survives gate 1, since it reads "the surviving m". RQ3 writes into its own directory, so it would run from a scratch copy with that disclosed.
