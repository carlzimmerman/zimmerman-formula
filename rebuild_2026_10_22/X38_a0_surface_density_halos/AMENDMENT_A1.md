# X38 AMENDMENT A1 (pre-result: written after the first run crashed in K1, before any graded number)

The first run stopped in K1's root solve; no SPARC or cluster number was computed. Cause: at fixed surface density, a
Burkert halo's mass inside R, M(r₀) = π Σ r₀² B(R/r₀), is not monotone in r₀. It rises from 0 (r₀ → 0), peaks at
r₀,pk, and falls again as (4π/3)(Σ/r₀)R³ (r₀ → ∞). So a target mass has two roots, or none.

1. **Branch:** take the compact root, r₀ ≤ r₀,pk (the halo has a core inside R and the usual outer fall-off).
2. **Saturation:** if M_target > M_max(R) = M(r₀,pk), the halo cannot hold that mass at Σ_a₀. It is set to M_max
   (r₀ = r₀,pk) and flagged SATURATED. The count is reported per footing for SPARC and per cell for clusters. This is
   physics of the hypothesis: Σ_a₀ caps the cold dark energy that fits inside R, at M_max ∝ Σ_a₀ R². It is not tuned.
3. **K1 test mass:** 10¹¹ M☉ inside 97 kpc (feasible), in place of 10¹² M☉ (above the cap at that radius).

Nothing else changes.
