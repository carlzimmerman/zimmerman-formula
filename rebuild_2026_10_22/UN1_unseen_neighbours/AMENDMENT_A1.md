# UN1 AMENDMENT A1 (post-result, before any number from it; the frozen class stays on record)

**What failed.** The frozen term treats everything below MLIM as unseen. MLIM is a 95th-percentile limit: 57 % of catalogued neighbours lie below it. So the frozen term counts visible galaxies twice. It gave the law χ² about 4,900 and route E A_O1 1.05. The frozen class reads SHORTFALL CLOSES on canonical S1 at R2. That is what the frozen text outputs. It is a design error of mine, not a physical closure, and must never be quoted as one. K1–K3 could not catch it.

**The correction, no parameter.** Only mass the catalogue lacks is added. In each 0.01 z bin (counted over ±0.01 in z, native background volume, the G3C area 0.05481 sr) and each type t ≥ lg M_b 7.5:

missing(t, z) = max(0, φ(t) − n_cat(t, z)), in the same units per dex

W(t, z) = missing(t, z) Δt / n_ref(z)

n_ref(z) is the density of reference neighbours at z, as frozen (within 0.5 dex above MLIM). Pairs, offsets, tables, B and the class rule are unchanged. φ's units are taken from `am1_bmf.py`.

**Disclosures before running.** I have seen the frozen run's numbers and a table of n_cat against φ. n_cat exceeds φ by up to about 20× near lg M_b 11 at z above 0.2, so φ is not a clean description of the catalogue's bright end, and n_ref is inflated by the same effect, which lowers W. So a reported variant takes n_ref as φ integrated over the band instead. The amended class is reported under both, each labelled.

**Added check.** K4: n_cat + missing ≥ φ at every (t, z) and missing = 0 where n_cat ≥ φ. MUTATE: φ × 1.3 raises the term in O1 for both models.

**Reading.** The amended class is a post-result diagnostic with the frozen rule's wording. If it closes, that still needs saying as post hoc. κ = ½ FITTED. Not theory closed.
