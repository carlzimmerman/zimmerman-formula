# FD1 amendments

## A1 (pre-result: committed alone, before the script and before any FD1 number)

**1. The error s.** §1 says s is "X1's per-system sdMC for the iso-AQUAL column". HO3, whose E/Z Step 0 must reproduce,
actually uses X1's `sdMC[Newton]`. For IC 1613 that is 0.079231, against 0.077505 for iso-AQUAL. FD1 uses
`sdMC[Newton]`, as HO3 does, so that K0 can reproduce HO3's Z.

**2. The binary correction.** HO3's executed X51 copy multiplies σ by X51's binary correction b. b is Arroyo-Polonio's
sig_free/sig_f0 where the table lists the dwarf; otherwise it is their median when M_V > −7.7, and 1 elsewhere. FD1
applies the same b, so that K0 matches HO3.
