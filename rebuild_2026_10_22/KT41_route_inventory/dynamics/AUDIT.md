# KT41 dynamics and energy-endpoint novelty audit

This is a read-only repository audit with new audit records only. No prior source, numerical result, observational cut, or baryon parameter was changed. No new physics run was performed. The purpose is to distinguish untested final implications from familiar mechanisms under new names.

## Decision

1. **Do not open a generic extra-field, AeST, superfluid, causal-memory, or covariant-completion lane as a new mechanism.** These are extensive existing programs, including explicit actions, static reductions, mode counts, kinetic companions, field-response Hessians, and failures.
2. **Reuse static-limit inheritance; do not advertise it as a new theorem.** Its KT40 quantitative application appears useful and was not located among the examined records. Positive kinetic inertia or a retarded relaxation time cannot change a genuinely stationary force if the same static functional, constraints, physical matter coupling and boundary data are retained.
3. **A constant isotropic quadratic Hessian endpoint correction has an inexpensive sign discriminator.** Its application to KT40 was not located. It would be a scoped closure of the simplest endpoint repair, not a new viable law.
4. Finite-frequency response, nonstationary histories, independently gravitating fields, nonzero steady field currents, changed boundary stress, different static functionals, and density-dependent coefficients are outside that inheritance implication. They are not thereby demonstrated viable or novel. They owe a specified action and a fresh static reduction before a full galaxy calculation is justified.

## Three bounded next obligations, ordered by cost

### D1 — static inheritance, specialized to KT40 (reuse + new quantitative application)

Settle the exact scope before coding. Suppose auxiliary fields q have a stationary solution q_*(rho) under the SAME boundary data, and the full completion's reduced static energy/action differs from KT40 only by a constant, a boundary term with fixed variation, or a term with zero matter functional derivative. Require the same physical matter coupling, not merely matching one linear susceptibility. The chain rule/envelope identity then makes the physical static potential/force identical. No change to a positive time-derivative quadratic form or stable relaxation rate changes that conclusion.

For a normalized causal kernel with convergent static response, K(omega=0)=1 is only a linear-response check. It is not sufficient to prove equality of the nonlinear static functional. Initial homogeneous modes, steady field currents, differing branches, boundary stresses and independent static energy must be treated explicitly.

Reuse KT40's actual finite witnesses to quantify a necessary change:

- At R=12 kpc,z=.3 kpc, canonical cell1368: partial_z Phi_old=−843.769944 (km/s)²/kpc. At fixed density and same matter coupling, restoring force requires partial_z DeltaPhi >=843.769944; a strictly restoring force requires strict inequality. Alternate cell1287 requires >=936.111425. These values have recorded discretization error/convergence, not exact continuum bounds.
- Canonical prescribed Draco, Upsilon2, uniform eta=.01: W_old/(3M)=−19.3383 (km/s)². Nonnegative kinetic trace and vanishing confining surface terms require DeltaW/(3M)>=19.3383 merely to reach W_new>=0. A nonzero-dispersion equilibrium requires more. The result is about that fixed uniform-field Plummer diagnostic, not the real satellite's full tidal/orbit history.

If a proposed completion has exactly zero static correction, it cannot meet either necessary condition. If it has a small nonzero correction, it must be assessed against these finite deficits before a large spectral/dynamical scan. Changes to anisotropic/magnetic stress or a nonstationary system alter the matter problem; they do not rescue the same hydrostatic test for free.

Novelty status: inheritance is old; exact KT40 threshold application was not located by the targeted query or nearest-source reading. Proposed cost: one-page derivation plus independently checked signs and source hashes; no field solve needed.

### D2 — constant isotropic quadratic endpoint terms (candidate scoped implication)

For the KT40 auxiliary Hessian H_ij=partial_i partial_j psi, the most general constant isotropic quadratic addition is

    Delta E = alpha (tr H)^2 + beta H:H,    c=alpha+beta.

The full variational source gives

    Delta(DeltaPhi) = −c Delta² psi,
    DeltaPhi = −c Delta psi = −4piG c rho,
    DeltaN(n)=c,

assuming the same decaying/inherited harmonic boundary solution. alpha,beta have units length². The difference of the two invariants is a Hessian null Lagrangian under the fixed boundary variation. At a positive-z point with partial_z rho<0, the counterterm changes the vertical derivative by −4piG c partial_z rho. Thus c<0, the sign that reduces positive high-k N, makes the already negative MW derivative more negative; c>0 improves that static sign but increases N. In a decaying prescribed dwarf the same contact correction obeys

    DeltaW = −4piG c integral rho r.grad rho d³x
           = 6piG c integral rho² d³x.

Consequently c<0 also lowers the already negative scalar virial. This is a promising algebraic closure of the simplest endpoint repair, subject to independent check by parent. It is not a no-go for g-dependent coefficients, nonquadratic terms, nonlocality, altered physical matter coupling, or additional stresses. An affine Hessian term only changes a boundary term and does not remove the old positive second derivative.

Novelty status: density-contact and sign tradeoffs are prior; this exact KT40 classification and two-deficit application were not found. No parameter scan was run. Proposed decisive check: independent tensor contraction, integration-by-parts virial sign, and actual fixed MW density derivative; retain the old KT40 errors and boundary conditions. If the checks hold, reject this constant quadratic family before running MW/Cassini grids.

### D3 — actual new dynamical host, only after its static difference is specified

A proposal surviving D1 must expose the changed reduced static functional and quantify the reciprocal response, not merely name an extra field. The existing mediator parent proves why this is necessary: the compulsory positive kinetic companion and finite-M density-gradient energy come together. Useful last-implication tests would be (a) deriving the exact static Schur complement of a specific new parent, (b) checking whether its full correction has the signs/magnitudes required by D1/D2, and only then (c) frozen kinetic/gradient and constrained mode counts. We did not locate a fully specified new parent to authorize on novelty grounds in this audit. Whole AeST/superfluid/retarded-bath resweeps would repeat extensive prior work.
