# NumPy source provenance

compiled_base.c is the official v1.26.4-tag source, obtained from
https://raw.githubusercontent.com/numpy/numpy/v1.26.4/numpy/core/src/multiarray/compiled_base.c.
installed_gradient.py.txt was captured with inspect.getsource from the actual
NumPy1.26.4 environment used by the computation. SOURCE.json records provenance;
numpy_LICENSE.txt preserves the NumPy redistribution terms. The calculation
manifest hashes these files before and after. No installed library was changed.
Version matching is not independent authentication of the installed C binary.
