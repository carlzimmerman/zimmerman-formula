# X45 AMENDMENT A1 (POST-RESULT, disclosed)

RUN1 (`*_RUN1*` files, kept) is graded but meaningless as a derivation.

1. **Internal inconsistency fixed.** §1 set ν = δ_c/(σ₀ D(z_f)) from the peak's central smoothed value. The enclosed
   linear mean inside the half-mass radius q_M is lower than the central value, so only about 1 % of q_M had collapsed by
   z_f. That contradicts the construction's own definition: the half-mass object collapses at z_f. With nothing
   collapsed, no slope crossed −2 at any mass, every c_f fell back to 1.85, and the regrade simply reproduced X44.
   **Fix:** ν is solved so that δ̄(<q_M) = δ_c / D(z_f) (the Dalal-style normalisation). The model, collapse thresholds,
   profile formula, c_f definition and regrade are unchanged.
2. **K2's design is fixed.** ⟨x|ν⟩ approaches γν slowly (1.17 at ν = 6), so 5 % at ν = 6 was not a valid limit test. It is
   now checked at ν = 30.

Because this amendment follows a graded run, the rerun's verdict is reported as **post-hoc**.

## A2 (POST-RESULT, disclosed; the verdict becomes POST-HOC EXPLORATORY)

RUN2 (`*_RUN2*`, kept) still found no slope crossing −2 at any mass. The collapsed object was a near top-hat: slope ≈ 0
over 75 % of the shells. Cause: §1's profile used the smoothed–smoothed correlation (W_G²), which removes all structure
inside the peak scale. The Dalal et al. construction uses the **unsmoothed** density around a smoothed peak, i.e. the
cross-correlation with one W_G. A2 switches the collapse profile to that form. K1's identities stay on the smoothed field,
where they hold. Two post-result changes have now been made, so **this lane's result is post-hoc and exploratory, not a
frozen pass**: it can motivate a new frozen lane, nothing more.
