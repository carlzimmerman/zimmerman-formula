## The action (DEW 2011, PRD 84, 124054, arXiv:1106.4984; field equations DEW 2014, PRD 90, 064038, arXiv:1405.0393) [PROVISIONAL, snippets]

A purely metric action, R plus a function of a non-local scalar built with the retarded inverse □⁻¹ from a timelike 4-velocity that is itself a non-local functional of the metric. The function is chosen so that (i) the static spherical ultra-weak-field limit gives the MOND force, (ii) weak lensing equals GR's for the same potential, and (iii) it is GR in the Solar-System regime.

**Static limit for G2a.** The published reduction is static and spherical only. The EFE (the Sun in the Galaxy's field) needs the non-spherical static limit, which the snippets do not give. The non-local scalar is built from □⁻¹ of the metric; in a static field that is ∇⁻² of the source, so the function plausibly sees the Newtonian-like field (QUMOND-type), but it may see the total field (AQUAL-type). **Both are graded; a candidate survives G2a if it passes under either form**, and the label says which.
