## Definitions used for the counts

- **FULLY CLOSED** — the lane landed a `RESULT.md`, the frozen label is a definitive verdict
  (FAILS / KILLED / EXCLUDED / NO VALUE / NO STATE / DOES NOT / NO RULE / BREAKS DOWN /
  STRUCTURE FAILS / ILL-POSED / NOT WELL-DEFINED / BREAKS AT / NO CANDIDATE) on **both** footings,
  **and** no post hoc amendment is needed to reach that label. Open sub-rows are listed in the
  "still untested" column; they do not un-close the headline.
- **NO VERDICT** — landed, but the frozen label is NO VERDICT / NOT SEPARATED / NO POWER /
  NOT EVALUABLE / STOPPED / PENDING / NOT DECIDED on at least one footing, **or** the reported
  label only holds under a post hoc amendment.
- **NEVER LANDED** — the folder exists but produced no `RESULT.md` (or `RESULT_BLIND.md`).
- **PARTIAL / OTHER** — landed, but the label is a pass with scope limits, a fragile fail, an
  assembly, a Lean certificate, a forecast or a proposal.

Cost/effort key: **S** = under one engineer-day, existing code; **M** = 1-5 days, existing
pipelines; **L** = new data, a new pipeline, or a catalogue not on this disk.
