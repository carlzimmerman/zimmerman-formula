# H057 — VON NEUMANN DOORS
Structurally bold, cross-domain, in the spirit of JvN: self-reference,
automata, operator algebras, computation, games, measurement. Grounded in
this repo's results. Each is a real question, not a metaphor.

## SELF-REFERENCE AND SELF-REPRODUCTION
**V1 The theory must contain its own derivation.** Von Neumann's
self-reproducing automaton needs a description that is also a program. Does
a_0 = 0.5 c sqrt(G rho_L) similarly require the theory to specify how it is
read? If the framework's equations pick out their own interpretation, that is
a fixed point. Formalize it.
**V2 Self-referential measurement.** H054 says the framework is effective.
An effective theory must state its own domain of validity FROM INSIDE. Can
the framework compute its own breakdown scale? If yes, that is the completion.
**V3 The ghost as a self-reference pathology.** Wrong-sign kinetic energy is
what happens when a system's description is mistaken for the system. Compare
to a map that contains itself. Formalize with fixed-point logic.
**V4 Does the framework predict its own falsifier?** Von Neumann would ask for
the machine that builds the machine that stops it. Which prediction, if
measured, would make the framework stop? Name it and pre-register it.
**V5 Bootstrap: derive a_0 FROM the RAR and the RAR FROM a_0.** If they imply
each other, it is a fixed point, not a postulate. Test whether the
implication closes both directions.

## AUTOMATA AND COMPUTATION
**V6 Spacetime as a cellular automaton.** If the framework is effective
(H054), maybe the substrate is discrete. Does a CA with a rule derived from
mu_2 reproduce the r^-2 phantom? This is the "microscopic system" of H054
made concrete.
**V7 Is the MOND law a computation?** mu_2 as a CDF (H055): is the Universe
sampling from a distribution? If so, what is the sampler, and what is the
computational cost per galaxy?
**V8 Monte Carlo the dark sector.** Use the Lomax distribution of H055 as a
sampler: generate synthetic halos by sampling accelerations, and compare
their rotation curves to SPARC. If they match, the statistical reading is
confirmed without any field equation.
**V9 Cellular-automaton derivation of D=4.** H043 derived D=4 from continua.
Does a CA argument independently select 4? (Neighbourhood structure,
isotropy, signal propagation.) If yes, two independent derivations agree.
**V10 Is n=2 a computational bound?** Shape of the Lomax = n. Could n be
limited by an information or complexity constraint rather than physics?
**V11 Automaton for the phantom/dust transition.** Model the G132
first-order step as a CA phase change. Does the latent heat emerge?
**V12 Turing-completeness of the framework.** Are its equations rich enough
to embed universal computation? If yes, some questions are formally
undecidable -- which would explain why the completion keeps failing.

## OPERATOR ALGEBRAS (von Neumann algebras)
**V13 The dark sector as a type III factor.** Von Neumann algebras of type
III appear in QFT and have no trace -- no notion of "number of particles."
If the dark sector is type III, that EXPLAINS why there is no particle
(H047: no free-streaming) and no conventional thermodynamics. Test it.
**V14 Modular theory / Tomita-Takesaki.** Every state has a modular flow.
Is the MOND "time" or relaxation direction the modular flow of the dark
sector? This would make the equilibrium reading (G084) deep and rigorous.
**V15 Is the ghost a signature of the wrong factor type?** Wrong-sign
Hamiltonians are natural in type III: there is no trace, hence no positivity
requirement of the usual kind. Maybe H045's ghost is a category error --
we demanded type I positivity of a type III object.
**V16 The KMS condition.** Equilibrium states satisfy KMS. Does the phantom
satisfy KMS at the temperature sigma^2 = 0.5 sqrt(G M_b a_0)? If yes, the
equilibrium reading is exact, not approximate.
**V17 Non-commutative geometry.** If the dark sector is non-commutative,
spacetime at galactic scales has a fuzzy structure. Does that generate mu_2?
**V18 Entropy of the dark sector.** Type III has infinite entanglement
entropy. Does that match the observed halo entropy?

## GAME THEORY AND ECONOMICS
**V19 Gravity as a game.** Baryons and the dark sector as players. Is the
MOND law the Nash equilibrium? Von Neumann founded game theory -- use it.
**V20 Minimax and the ghost.** H053's IR argument is a minimax statement:
the adversary picks k->0. Formalize screening as a game; the value is
negative, so no strategy wins.
**V21 Does the framework optimize something?** Find the functional. If the
Universe is optimizing, state the objective -- then the MOND law follows.
**V22 Free-rider problem in clusters.** If the dust is a public good
supplied by baryons, does game theory explain the cluster amplitude (C2)?
**V23 Auction theory for halo formation.** Which baryons "win" the phantom?

## MEASUREMENT, INFORMATION, COMPLEXITY
**V24 Is a_0 a channel capacity?** If the dark sector transmits information
about baryons, a_0 might set the bandwidth. Compute the capacity.
**V25 Kolmogorov complexity of the RAR.** How compressible is it? If the
framework's description is shortest, that is a formal argument for it.
**V26 Does the framework minimize description length?** (H051 M061.) Formal
comparison against LCDM on identical data.
**V27 The observer.** Von Neumann worked on measurement. Does measuring a
galaxy's rotation curve disturb the phantom? Probably not -- but prove it.
**V28 Irreversibility.** G132's transition has latent heat and looks
irreversible. What is the arrow of time? Entropy production rate?
**V29 Can the framework simulate itself?** If yes, von Neumann's
self-reproduction applies and V1 becomes concrete.
**V30 Quantum information bounds.** Does the dark sector's entropy respect
holographic bounds? Test with the measured halo entropy.

## STRUCTURALLY BOLD
**V31 Is the Universe a computer running the framework?** Not mysticism:
ask whether the equations are the cheapest way to produce the observed
rotation curves, in a formal complexity sense.
**V32 Self-similarity across scales.** The framework has r_M, r_cap, r_M in
D dimensions. Is there a renormalization fixed point making all scales
equivalent? (H051 M030.)
**V33 Does the framework need a new logic?** If the completion fails
repeatedly, maybe classical logic is wrong for it. Try paraconsistent or
modal logic for the two-zone structure (inside/outside r_M).
**V34 The framework as a programming language.** Formalize its primitives
(a_0, mu_2, r_M, the amplitude law) as a language. What programs can it not
write? That delimits its physics.
**V35 Undecidability.** Prove SOME question about the framework is
undecidable. Then stop trying to answer it. This is a real research
contribution and saves future waves.
**V36 Is the 22% an irreducible constant?** If it is not environmental
(H054 C4), maybe it is structural -- like a constant of the formalism.
**V37 Does the framework have a conservation law we have not found?** Search
systematically for conserved quantities (H051 M042).
**V38 Fixed-point characterization of the phantom.** The phantom is the
configuration that reproduces itself. Prove the fixed point exists and is
unique -- that is the equilibrium theorem upgraded.
**V39 Is D=4 Turing-optimal?** Among all D, is 4 the one allowing the
richest computation? Connect to H043.
**V40 Von Neumann's cat.** He loved self-reproducing machines. Build the
simplest computational model that regenerates mu_2 from scratch. If you can,
the theory is complete in his sense.
