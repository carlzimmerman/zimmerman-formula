This is the provenance appendix to a read-only audit of the research history; only audit documents were created. It covers the requested March 9–September 9, 2026 interval. It records what dated repository objects contain, not whether their scientific claims are true. A commit's author/committer timestamps are not independently authenticated public-disclosure timestamps. “Published” in a commit message is evidence that the repository records a publication, not independent verification of the server record.

The public GitHub front page was accessible during this audit and identifies the repository as public: [carlzimmerman/zimmerman-formula](https://github.com/carlzimmerman/zimmerman-formula). Exact publication/creation timestamps and deposited file contents therefore remain unauthenticated here.

## Main distinctions

- The original March 17 formula uses **critical density**: `a0 = c sqrt(G rho_c)/2 = cH0/[2 sqrt(8pi/3)]`. The exact denominator later called Z is already present in the root paper.
- The **dark-energy-density expression appears March 18 as the asymptotic future floor**, `a0,infinity = c sqrt(G rho_Lambda)/2`. It is not yet the current galaxy-scale claim. The contemporary inversion includes `Omega_Lambda` when it uses today's `a0`.
- The June 4 record explicitly changes the interpretation from total density to dark-energy density, leading to constant or mildly nonmonotonic/decreasing `a0(z)`. It should not be retroactively described as the March prediction.
- The **a0-line**, `g_obs^2-g_bar^2=a0 g_bar`, implies `nu(y)=sqrt(1+1/y)`. It is not `nu_RAR(y)=1/[1-exp(-sqrt(y))]`, and neither is the inverse of the exact `mu(x)=1-exp(-x)` law. These are different mathematical objects and need different priority comparisons.
- A June 13 spatial resolvent/slip investigation precedes the August screening work, but it does not contain the later two-filter QUMOND screening action. A common Helmholtz resolvent alone does not identify the same theory.

## The filtered-action priority question

The coordinator identified an external August 7–8, 2026 candidate attributed to Sanitha Elit with a projected spatial resolvent and two elliptic auxiliary fields. That external source is being authenticated separately; this report does not treat the relayed description as independently verified.

The local chronology distinguishes three levels:

1. **June 13: general resolvent and projected-spatial filtering in a lens-only slip attempt.** The full code is committed in `69f81a6...`, and the Fourier smoothing formula is explicit. It does not establish the later two-auxiliary/four-second-class screened-QUMOND construction. The script comments describe an auxiliary smoothing field, but the calculation substitutes its resolvent directly; it does not implement the complete independent auxiliary Hamiltonian sector.
2. **August 22: an explicit local elliptic low-pass action used to determine a screening argument.** This is stronger architectural overlap but later than the reported external August date. It is still a different screening prescription and is recorded as unsuccessful.
3. **September 4–5: QUMOND on the smoothed Newtonian field, the variational two-filter construction, and the first covariant clock action.** These are later than the reported external August date.

Queries covered Helmholtz, low-pass, spatial filter, elliptic auxiliary and resolvent spellings in tracked Markdown/Python/LaTeX outside `ai_slop` and vendored `.lake` trees. Strong matches were the June 13 package; most other hits were temporal memory filters or AeST's oscillatory `+mu^2 Phi` cluster equation. Those are not equivalent to the screening resolvent. This is a bounded negative search, not proof that no earlier relevant occurrence exists anywhere, and not evidence of copying in either direction.

## Interpretation limits

Novelty needs exact statements, not project labels. The density choice, definition of the interpolation variable, physical metric/matter coupling, filter placement, kernel sign, auxiliary constraints and external-field treatment all change the statement. Likewise, numerous observational channels generated from one chosen kernel are often mathematical consequences of that kernel rather than independent novel laws.

The evidence here supports a dated evolution of the project and identifies what must be compared with external papers. It does not support an allegation of plagiarism, an inference that another author accessed the repository, or a global novelty claim. To strengthen public priority, authenticate DOI registration/publication histories and versioned deposited PDFs/code, and seek independent first-publication evidence for the relevant GitHub commits. A manuscript's self-entered publication date alone is weaker than a server creation/registration timestamp accompanied by the matching file contents.
