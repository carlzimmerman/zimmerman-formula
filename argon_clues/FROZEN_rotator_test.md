# Frozen criteria: slow- vs fast-rotator early types (written before any rotator class was attached to any offset)
Claim under test (Argon 'snapping' route): merger remnants (slow rotators) carry an extra cold-energy core, relaxed/quiescent fast rotators do not: predicted outer excess ~ +0.26 dex (slow) vs 0.00 (fast) -> difference >= +0.15 dex.
Data (all on disk except the class labels): CFG330 K0 per-galaxy outer offsets `off` (SLUGGS GC velocities vs the JAM-calibrated law, 16 galaxies: NGC 821, 1023, 2768, 3377, 3607, 4278, 4365, 4374, 4459, 4473, 4486, 4494, 4526, 4649, 4697, 5846, 7457 -> 17 listed; use all that CFG330 reports), both footings, never pooled; log M_JAM (`lMjamlaw`).
Class labels: ATLAS3D lambda_R fast/slow classification (Emsellem+2011), by galaxy name. NOT on disk; to be fetched only with the owner's explicit yes (VizieR J/MNRAS/414/888, ~100 kB).
Statistic: D = mean(off | slow) - mean(off | fast); permutation p (10^5 label shuffles, one-sided); mass control: OLS of off on lMjamlaw + slow-indicator, report the slow coefficient and its SE; mass-matched subset (|dlogM| < 0.25) difference.
Pass: D >= 0.15 dex, permutation p < 0.05, and the slow-indicator coefficient (mass-controlled) >= 0.10 dex at > 2 sigma. Kill: D <= 0.05 or negative, or mass-controlled coefficient consistent with 0 and D explained by mass. Labels 'NOT DIAGNOSTIC' if n_slow < 4 or n_fast < 6.
Disclosed up front: slow rotators are the most massive galaxies, so mass confounds; the `off` values are outer-GC offsets (tens of kpc), not the KiDS 50-100 kpc stack; n is small (about 5 slow vs 11 fast); SLUGGS centrals CFG331 already found environment does not remove their excess. Mutation: shuffle labels within mass bins -> D must fall to ~0.
