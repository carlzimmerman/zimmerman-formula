# Frozen criteria T-A and T-B (written before NGC 3608's offset was computed and before any offset was correlated with gas)
**T-A (slow vs fast, n_slow = 4).** Sample: CFG330's 17 + NGC 3608 = 18 galaxies (4 slow: 3608, 4365, 4374, 5846; 14 fast), ATLAS3D F/S class (table B1, column F/S). Offset convention for T-A: `off_sl` (SLUGGS K-band stellar mass, same law/kernel nu_mono, outer GC bins), for ALL 18, because NGC 3608 has no JAM mass (ATLAS3D qual 0). The JAM-calibrated `off` for the original 17 is reported for comparison only. NGC 3608 is computed with CFG330's own code (qual filter relaxed to >= 0, output redirected; nothing in CFG330 is edited). Both footings, never pooled.
Statistic and pass/kill rules exactly as FROZEN_rotator_test.md (D >= 0.15 dex, permutation p < 0.05 [10^5 shuffles, seed fixed], mass-controlled slow coefficient >= 0.10 dex at > 2 sigma; kill if D <= 0.05 or the difference is explained by mass; NOT DIAGNOSTIC if n_slow < 4 or n_fast < 6).
**T-B (hot gas).** Sample: the 8 CFG330 galaxies in Fukazawa+06 Table 4: NGC 3377, 3607, 4365, 4374, 4494, 4649, 4697, 5846. Gas indicator: n_e(10 kpc) (the table gives only this per galaxy; no profile shape, so no M_hot(<R) can be built). NGC 3377 and 4494 are VCXG (no extended halo gas, n_e(10 kpc) = nan): ranked lowest (tied). Offset: `off` (JAM) as in CFG330. Statistic: Spearman rho(off, n_e10) with exact one-sided permutation p over the 8 (ties handled by average ranks); and a two-regressor OLS off ~ a*slow + b*rank(n_e10), reporting b and a with SE. Prediction of the hot-gas selector (CFG745): rho > 0. Prediction of merger-snapping with no gas dependence: b ~ 0 given slow. Pass (selector leans): rho > 0 with p < 0.10; Fail: rho <= 0. Label n = 8 'low power: a lean, not a verdict' regardless.
Disclosed: 4486 (M87) has no Fukazawa row in this sample (Virgo cD not in the table) and so is outside T-B though it is the highest offset; its Lakhchaura+18 profile could extend T-B only with a new frozen note.
