# Derivation chain -- handoff, 2026-09-27

This page is for whoever picks up the FP lanes next. It records where the chain stands, what was fixed today, what is
undecided, and what to do next. The details live in `README.md` (the action, the knob ledger, failures, errata),
`CHAIN_STATUS.md` (every lane's ledger, assembled by `run_chain.py`) and each lane's own `.out` / `_results.json`.

## The goal and the rules the chain runs on

- **Goal.** One covariant action at the root, with every observable varied out of it and no hand-set constants.
  kappa = 1/2 is the one accepted fitted input. Every other constant must be derived, eliminated, shown observably
  irrelevant (a regulator), or proved irreducible.
- **Lane contract**, enforced by `run_chain.py`:
  - named checks, and the verdict line `N/M checks pass; load-bearing failures: K`;
  - a results JSON with a top-level `ledger` of links, each marked DERIVED / TIED / POSTULATED / FITTED / CONSTRAINT /
    OPEN / FAILS;
  - a `MUTATE=1` control that must flip a load-bearing check (rc = 1) and write to separate files.
- **Running and checking lanes.**
  - `python3 real_research/derivation_chain_2026/run_chain.py` rebuilds `CHAIN_STATUS.md` from the committed lanes and
    skips uncommitted ones.
  - `--only FPn` checks one lane without touching `CHAIN_STATUS.md`.
- **Working rules.**
  - Always compute both a0 footings: 9.3603e-11 m/s^2 (canonical) and 1.1312e-10 (rho_total).
  - Report a failure as hard as a win, and check every affected gate.
  - Never call the theory "closed".
- **Repository rules.**
  - Committed files carry no personal names, usernames, e-mail addresses or absolute home paths. Grep for them before
    every commit, and let the grep gate the commit (`&&`, never `;`).
  - Never commit `ai_slop/`. Never rewrite history.
  - Never edit another thread's lane files, and never edit the frozen DR4 pre-registration or `*_HASH.txt`.
  - Particle-mesh runs belong to the review lanes (`real_research/cross_thread_review_2026_09_26/`, the XR series).

## The action as it stands

The full form is in README "The action as it stands". In outline:

- **Gravity core.** FP7's AQUAL-type repair of the C-H/K root, with FP14's eliminations:
  - c_2 goes to infinity and becomes a multiplier;
  - alpha_c is a regulator;
  - the MOND kernel is J_P2, embedding g = sqrt(g_bar^2 + g_bar a0) exactly;
  - the a0-Lambda link is TIED by the unimodular multiplier (XR20).
- **Separator H_K1** (FP19). It reads the state only through <K>_h:
  - the band-pass length is L = L_Lambda 3 Lambda/<K>_h^2 with L_Lambda = 2.9 Mpc;
  - the yield floor switches on above z = 0.635 (the q = 0 ramp), with c_y = 2;
  - lambda is a regulator inside a declared range 0 < lambda <= 0.03 (XR18b);
  - it is linearly well posed and causal (XR18b).
- **Dark sector.** FK1's internal splitting (FP10): a light complex scalar (m >= 1.9e-19 eV) whose conversion kicks
  daughters at v_k = sqrt(2 eps/(m^2 + eps)).
- **Coupling, adopted today (FP22).** FK1 sits on the root's own Einstein-frame metric g~ = g + (1 - e^(-2 chi)) n n.
  - Effect: baryons source and feel the MOND phantom; the dark component feels Newtonian gravity only.
  - Why it was needed: without it the action implies that all matter feels MOND, and CMB lensing then excludes late-time
    web MOND. The dark lanes had assumed Newtonian-only dark matter, and that had no action on this root.
  - Cost: no new field or constant, but dark-baryon free-fall universality breaks where chi != 0. FP25 estimates
    galaxy-carrier offsets of tens of kpc in mergers. This is OPEN on the Harvey and Bullet gates.

   against the LCDM control (XR28). Clusters want L0 ~ 0.75-1.0 Mpc; KiDS needs L0 >= ~1.5.

   (FP23).
4. **CMB lensing.** This one is UNDECIDED, not failed:
   - in the all-matter reading it is excluded (FP22, XR26);
   - in the adopted reading it passes Planck and ACT DR6 in linear theory but fails ACT at halofit level (>= 3.8 sigma);
   - the decisive number is the hub's XR21 stage-2a particle-mesh run in the adopted reading ("chain"), run through
     XR26's lensing code.

Other failures and tensions:

  from 575 to 650 km/s (FP16).
