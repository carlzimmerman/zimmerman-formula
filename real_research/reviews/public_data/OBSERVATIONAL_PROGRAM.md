# Public-data observational program — pre-registration & fence (2026-06-09)

*The law (rungs C1–C5 of §12) is won in the archives and the telescope, not in derivations. This is the prioritized map of what public data can do **now**, with the discipline that keeps it honest.*

## ⛔ The fence (read before any analysis)
**Public/archival data can substantially advance C1, C2, C5. It CANNOT deliver C3's verdict.** The clean, environment-classified, kinematically-resolved **deep-MOND z≈3** galaxies the decisive a₀(z) test needs **do not exist in any archive** — that is *why* C3 is an ELT-class measurement (2028–32). What is archival for C3 is **preparation only**: compilation, systematics modeling, pipeline-building. **"We tested the evolution with public data" is a banned overclaim** — it would burn the credibility everything else built. Any a₀(z) result from archival data is labelled *underpowered / preparation*, full stop.

## Cross-cutting discipline (non-negotiable, extends the week's lessons to data)
1. **Pre-registered analysis plan committed BEFORE data touches the pipeline** — especially the wide-binary fork analysis. The plan states the cuts, the estimator, the null, and the decision rule in advance.
2. **Published-method fidelity before any deviation** — implement Chae/Banik/Brouwer/Chae-EFE as published; only then vary, with each variation logged.
3. **Provenance-pinned data products** — every catalog version pinned (DOI/checksum), every cut scripted; the `retraction_guard` + `PROVENANCE.md` discipline extends to data.
4. **A framework-favorable archival result gets the HOSTILE verification tier** — the whole value of the program is that nobody, including us, has had to take its word for anything.
5. **C3 fence enforced** — no archival a₀(z) result is ever stated as a test of the evolution; only as preparation.

*None of this replaces the telescope. All of it makes the telescope's answer land on a framework that already survived everything the archives could throw at it — which is what rungs C1–C2 of a law of nature look like from the inside.*
