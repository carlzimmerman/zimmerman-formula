# Execution and reproduction qualifications

The original lanes are never edited. Reproduction copies each target lane into a mirror, starts its original script, captures outputs and differences, records repository file opens and input hashes, and keeps mutation output separate. A main return code of 1 can represent a predeclared scientific failure. A mutation crash before its intended check is not a valid negative control.

The host's default Python 3.9 contains NumPy 1.26.2/SciPy 1.11.4/SymPy 1.14.0, but no CLASS/CAMB. CLASS 3.3.4.0 was built from the already-present unpatched distribution archive in `fable_independent_2026/L152_class_running_cs2/src/`, in a temporary directory. Neither of the existing patched CLASS installations was used as vanilla CLASS.

CAMB 1.6.6, explicitly named by XR26, requires newer Python. A separate temporary Python 3.11 dependency directory was therefore built with NumPy 1.26.4, SciPy 1.11.4, SymPy 1.14.0, CAMB 1.6.6, CLASS 3.3.4.0 and Colossus 1.3.9. Package downloads were approved through the execution tool. No research catalog was downloaded. The Python 3.9 folder also contains CAMB 1.6.0; runs using it are explicitly distinguished from exact-CAMB-version reruns. Initial missing-dependency failures are retained as environment failures, never as physics evidence.

The original mirror recipe links `.git` and input files. Git consequently interpreted input symlinks as type changes, causing CFG1 K4 to fail on all 47 inputs. The minimal diagnostic was `git status --porcelain -- EMPIRICAL_TESTS.md`: it reported `T` in the mirror and no change in the source checkout. Setting `GIT_DIR` and `GIT_WORK_TREE` alone did not fix pathspecs: the mirror remained nested in the source checkout, so Git still prepended its nested path to `ls-files`. A minimal `ls-files --error-unmatch` diagnostic established this second cause. Moving the mirror to an external temporary directory while pinning the real Git work tree fixes that prefix. Final provenance-corrected runs have `_external` names; the unsuccessful `_gitfix` attempt remains intact. No physics source or threshold changed. Source read hashes independently pin actual bytes.

Some original checks demand agreement at 1e-9 or tighter. Current CLASS/CAMB calculations differ in lensing amplitude by about 4.4e-7 and chi-square by 6.3e-5, preserving the astrophysical conclusion but failing those exact reproduction gates. They remain failures at the declared thresholds. We do not lower tolerances after observing results or relabel these as a new physical exclusion. Distinguish strict reproduction, stable scientific verdicts, finite numerical accuracy, and action-level proof.

All original hypotheses and grid ranges remain unchanged. New experiments have their own contracts and negative controls. Seeded source experiments retain their original seeds; manifest notes distinguish script-local literals from dependency-defined seeds. The legacy v1 harness manifests include supplemental read hashes but do not capture every C-library file read or `git show` subprocess input. Independent new mathematical checks use v2 bounded-run manifests where available.

An attempted restart of the single-worker XR22 calculation with more workers was rejected by automatic approval review because its completed work had no checkpoint. No process was terminated; the original run continues. That rejected restart is not a completed execution or an abandoned run.

The initial two-heavy-run scheduling target was exceeded while the original binary run continued and independent reproduction queues overlapped. This is a scheduling deviation, not a scientific parameter change. After checking the host's 64 GB memory capacity and the jobs' modest individual footprints, the coordinator allowed the existing sequential queues to finish and added one bounded corrected-spectrum queue. Original script-internal worker counts were retained; no large PM box was launched. Numerical-library thread limits remain cooperative, as disclosed in individual manifests.

XR32 survey reproduction initially stopped at a missing `fitsio` import before any survey assertion. Version 1.2.8 was installed only in the temporary Python 3.11 environment, and the full rerun is distinguished by `_fitsio`. No source, observational catalog or acceptance threshold was changed.
