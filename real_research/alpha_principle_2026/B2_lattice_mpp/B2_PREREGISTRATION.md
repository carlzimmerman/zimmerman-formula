# B2 pre-registration: an independent lattice Monte Carlo attempt to sharpen the Multiple Point Principle (MPP)

*Written 2026-09-29 BEFORE any B2 simulation was run. Nothing in this file uses a B2 result. The only things run before this file existed were (i) reading the B1 files and the primary texts (hep-ph/9311321 and hep-ph/9607278, re-fetched as PDF and converted to text locally to read the conversion formulas), and (ii) nothing else: no code was compiled or timed. Later amendments are appended at the bottom, never edited in.*

## Goal

Lane B1 found that the published MPP couplings (Bennett and Nielsen) lie within their own stated 8 to 15% uncertainties of lane Y1's Planck-scale values, a WEAK pass. B2 asks whether independent lattice Monte Carlo can make that mechanism sharper (uncertainty on each 1/alpha_i(M_P) of 3% or better), or whether it cannot be sharpened with this machine and budget. Failing to sharpen is an acceptable, reportable outcome, and so is a FAIL against Y1.

## Independence and ceiling (stated in advance)

MPP uses neither kappa = 1/2 nor Z. Even perfect lattice numbers leave the Planck-scale identification (which mass is M_Planck; Y1 targets move by about 1.2, 0.5, 1.2 in 1/alpha_(Y,2,3) for a factor-3 move of M_P, from B1), the one-loop boundary matching, the N_gen = 3 premise and the continuum-correction conventions uncertain at about the 1-unit level in 1/alpha. So B2 can at most tighten the mechanism to a few percent and can never give the measured digits of alpha. Alpha stays an INPUT.

## What is computed (observables)

All lattices are 4-dimensional, periodic, hypercubic L^4.

**b2_1 (compact U(1), Wilson action)** S = -beta sum_p cos(theta_p). Observable: E = <cos theta_p> per plaquette time series. beta_c(L) = the position of the maximum of the energy susceptibility chi(beta) = V (<E^2> - <E>^2) (V = L^4 plaquette count factor 6 not included; fixed: chi uses V = L^4) obtained by single/multi-histogram reweighting between simulation points; cross-check: the minimum of the energy Binder cumulant. beta_c(inf) from beta_c(L) = beta_c + a / L^4 (first-order finite-size form) fitted to L >= 8; finite-size systematic = |beta_c(L>=10 fit) - beta_c(all L fit)|; statistical error from a jackknife over >= 8 blocks per run (blocks longer than the measured autocorrelation time or, if not, the error is inflated by the ratio and this is reported). The Villain action (periodic-Gaussian, sum over n = -2..2) is done only if it costs < 10 minutes wall; target beta_c^Villain about 0.643 (as printed in the papers).

**b2_2 (SU(2), fundamental-adjoint)** Normalisation exactly as in the papers' formulas (36)-(37) of hep-ph/9311321 (weights beta_r with the representation normalised by its dimension, so that pure fundamental has beta_F = 4/g^2):
S = beta_F sum_p (1 - (1/2) Tr U_p) + beta_A sum_p (1 - (1/3) Tr_adj U_p), with Tr_adj U = 4 (Tr U / 2)^2 - 1 for SU(2).
Observables per plaquette: X_F = (1/2) Tr U_p, X_A = Tr_adj U_p / 3.

**b2_3 (SU(3), fundamental-adjoint)** S = beta_F sum_p (1 - (1/3) Re Tr U_p) + beta_A sum_p (1 - (1/8) Tr_adj U_p), with Tr_adj U = |Tr U|^2 - 1. X_F = Re Tr U_p / 3, X_A = Tr_adj U_p / 8.

**b2_4 (confrontation)** applies the papers' own conversion to my triple-point coordinates and compares with Y1.

## Conversion formulas (FIXED NOW, taken from hep-ph/9311321 eqs (4), (34)-(37) and B1's ledger; not to be altered after results)

For SU(N), C_adj = N, C_f = (N^2-1)/(2N):
1/alpha_full = 4 pi (C_adj beta_A + C_f beta_F)/(N^2-1);
1/alpha_cont(exponentiated) = 4 pi [C_adj beta_A exp(-pi C_adj alpha_full) + C_f beta_F exp(-pi C_f alpha_full)]/(N^2-1);
non-exponentiated: the same with exp(-x) replaced by (1 - x).
Planck-scale prediction: 1/alpha_i(M_P) = N_gen x 1/alpha_cont, N_gen = 3.
PRIMARY = exponentiated (as B1's primary central values, which are the papers' printed Planck values 49.5, 56.7). The exponentiated-minus-not difference is carried as an INHERITED conversion uncertainty, taken as one sigma (this is B1's secondary treatment).

For the U(1) row (Wilson action, hep-ph/9607278 eq (139)): alpha_cont = 0.20 - 0.24 (Delta_gamma / (beta_c + Delta_gamma))^0.39 with Delta_gamma_eff the authors' modelled jump (not measurable by B2); Planck-scale 1/alpha_Y = (enhancement factor 6 to 8.04, printed rows 6.66-6.83 at tau = 0.79) x 1/alpha_cont. The Luck/Jersak fit (139), the Delta_gamma_eff model and the enhancement interpolation (134)-(138) are INHERITED and cannot be independently recomputed here.

## Precision criterion (declared)

An independent recomputation counts as SHARPER for a coupling only if the resulting 1/alpha_i(M_P) uncertainty from my OWN statistical + finite-size + extrapolation error (methods stated here; no error bar borrowed from any paper) is <= 3% of the central value. This "lattice-only" uncertainty is propagated through the fixed conversion by finite differences in the triple-point coordinates. The inherited conversion uncertainty (exponentiated vs not, and the papers' stated +-1 per group) is NOT part of the 3% test but IS part of the verdict sigma below. The criterion is not met for a coupling if the triple point cannot be identified on the lattices I can afford; then the coupling is UNDECIDED (or, if the structure is found but too imprecise, INSUFFICIENT PRECISION).

## Verdict criterion against Y1 (declared)

z = (prediction - Y1 target)/sqrt(sigma_lattice^2 + sigma_inherited^2 + sigma_Y1^2), Y1 targets (55.234, 49.203, 52.971) with relative errors (0.23%, 0.021%, 0.12%) as B1 read them from y1_lib. PASS if |z| <= 2, FAIL if |z| > 2, UNDECIDED if the triple point was not identified or a needed step was not done. I also print the lattice-only z (sigma_inherited dropped) as a second column. A PASS counts as INFORMATIVE only if the total sigma is <= 5% (B1's criterion 3) and the lattice-only sigma is <= 3%.

## Operational definition of "triple point" (declared; the papers' references were NOT read)

The papers extract (beta_F, beta_A) = (0.54, 2.4) for SU(2) and (0.8, 5.4) for SU(3) from figures in Bachas-Dashen (1982), Bhanot (1982) and Drouffe-Zuber (1983), which I have not read. I therefore cannot say from the text which phase lines meet there. Definition D-TP used by B2: map the first-order structure in the fundamental-adjoint plane by susceptibility maxima of X_A (and X_F) along lines of fixed beta_F (beta_A scans). A "first-order point" is a susceptibility maximum whose peak height grows between L = 4 and L = 8 with effective exponent d_eff = ln(chi_max(8)/chi_max(4))/ln 2 >= 3 (volume scaling is 4); d_eff <= 1.5 is a crossover; in between is weak/critical. The triple point is the intersection of two DISTINCT first-order lines (each fitted linearly or quadratically in the window near the branching), or the point where a single first-order line splits into two. If only one first-order line and its critical endpoint are found in the searched window, then the fundamental-adjoint plane alone shows no triple point in that window for my lattices, the coupling is UNDECIDED for the papers' triple-point conversion, and I report the endpoint conversion only as a labelled alternative (no pass/fail claimed for it). If the papers' triple point involves an extended action (additional Z2 monopole-suppression term, SU(2)/Z2 or SO(3) lattices) that I cannot identify from the text, that is stated and marked UNDECIDED, not fitted. Second-stage scans along fixed beta_A (beta_F scans) are allowed when the first stage shows a line that is not close to horizontal; this is declared now.

Finite-size treatment for the triple point coordinates (both directions): x(L) measured at L = 4, 6, 8 (SU(2)) and L = 4, 6 (and 8 if affordable) (SU(3)); x(infinity) from x(L) = x + b/L^4 using the two largest L; alternative x + b/L^2; sigma_ext = max(|x_{L^-4} - x_{L^-2}|, |x(L_max) - x(L_max-step)|/2); sigma_stat = jackknife over independent seeds (>= 4 independent seeds per run) combined with block jackknife inside; total lattice sigma on each coordinate = quadrature of stat and sigma_ext. Coordinate resolution is also limited by the beta grid: the beta_A grid spacing enters as a uniform-distribution uncertainty (spacing/sqrt(12)) unless reweighting interpolates.

### Amendment 4 (stage-1 protocol replaced after aborting it; disclosed in full)
What happened: the stage-1 WHAM-susceptibility scan of Amendment 2 was started for SU(2) and SU(3) and ABORTED after 3 SU(2) lines and 1 SU(3) line at L = 4 (outputs kept as b2_2_stage1_ABORTED.out and b2_3_stage1_ABORTED.out; I saw those few lines: SU(2) L=4 susceptibility maxima at beta_A about 2.58, 2.58, 2.41 for beta_F = 0, 0.2, 0.4 and SU(3) L=4 at beta_A about 6.49 for beta_F = 0). Two reasons: (i) the shared machine runs at load 100+, each of my processes gets roughly a third of a core, so the planned production would take several hours; (ii) a substantive flaw: at a strong first-order transition the coexistence window in beta_A is about 1/(N_p Delta X_A), i.e. 0.002 at 4^4, far narrower than the 0.2 grid spacing, so no run tunnels and the multi-histogram estimate of the relative phase weights (hence of the susceptibility maximum) is not determined; the near-identical maxima at beta_F = 0 and 0.2 and the vanishing jackknife errors are signs of this. No verdict, gate or criterion depended on those partial results.
Replacement, fixed before any further SU(2)/SU(3) physics is inspected: Stage 1H is a HYSTERESIS MAP. At each point of a (beta_F, beta_A) grid, two runs (hot start, cold start), 4000 sweeps with 1000 thermalisation, at L = 4 (SU(2) grid: beta_F in {0, 0.2, 0.4, 0.54, 0.7, 0.9, 1.2, 1.6}, beta_A = 0.4-3.4 step 0.1; SU(3) grid: beta_F in {0, 0.4, 0.8, 1.2, 1.6, 2.4}, beta_A = 1.0-8.0 step 0.25). A grid point is flagged first-order-like if |<X_A>_cold - <X_A>_hot| exceeds 5 sigma (block errors, 10 blocks) and 0.005; otherwise crossover-like. First-order lines are the bands of flagged points; the triple point candidate is where two distinct bands meet or one splits (D-TP). Stage 2 then locates each line at each L by WHAM on grids whose spacing is at most 1/3 of the hysteresis-band width found at that L (so runs inside the band see both phases where tunnelling permits), lines whose tunnelling cannot be achieved are reported by the hysteresis-band midpoint with the full band width as the error, and the finite-size extrapolation is attempted only when at least two L have a located line. A line for which no tunnelling is achievable at L >= 6 within the budget counts as NOT located at that L.
Consequence stated in advance: for strong first-order lines, locating them at L = 6 and 8 by simple Monte Carlo is probably not affordable here; then the finite-size error on the triple-point coordinates will be the L = 4 versus L = 6 spread or the full band width, likely far above the 3% criterion, and the verdict for that coupling is INSUFFICIENT PRECISION / UNDECIDED.

### Amendment 5 (algorithm change after stage 1H showed frozen center sectors; disclosed; stage 1H redone)
What was seen: in the first stage-1H maps (kept as b2_2_stage1H_NOFLIP.out/.json and b2_3_stage1H_NOFLIP.out/.json) hot starts at large beta_A stayed in a state with the adjoint plaquette ordered but the fundamental plaquette X_F small (0.2-0.5) for the whole run, while cold starts sat at X_F 0.8-0.9. The production programs are therefore su2z and su3z (the same C sources compiled with -DZFLIP). The validation gates are RE-RUN with these programs (they have their own cache), and the earlier no-flip stage 1H results are NOT used for any conclusion. Stage 1H is redone at L = 4 with a reduced grid to fit the budget: SU(2) beta_F in {0, 0.2, 0.4, 0.54, 0.7, 0.9, 1.2}, beta_A = 1.4-3.0 step 0.1; SU(3) beta_F in {0, 0.4, 0.8, 1.2, 1.6, 2.4}, beta_A = 3.5-8.0 step 0.25. ### Amendment 8 (post-hoc estimator correction; found while inspecting the stage-2 outputs)
The W estimator (WHAM susceptibility maximum, used when >= 2 runs of a scan are 'mixed') is DISABLED for the line positions. Evidence: the WHAM maxima fall exactly on grid points (SU(2) L = 4 and L = 6 give the same 2.5196 and 2.4592 to four digits at beta_F = 0 and 0.4, which are grid points of both grids), and the 'mixed' runs are located far from the coexistence point (for example SU(2) L = 6, beta_F = 0: a mixed run at 2.5596 while the WHAM maximum is at 2.52; SU(3) L = 4: mixed runs at 5.75-5.85 and 6.65 while the maximum is at 6.25). They are decaying metastable states, not equilibrium tunnelling, so the multi-histogram relative phase weights are undetermined. Every line position is therefore taken from the hysteresis bracket alone (estimator H): the true coexistence lies between the lowest beta_A at which a run ends in the high phase and the highest beta_A at which a run ends in the low phase, PROVIDED metastable states persist over the run length (verified only in the sense that the brackets do not shrink with longer runs at the points repeated with different run lengths, not otherwise); estimate = midpoint, error = half the bracket width (or half the grid step if the bracket is narrower), i.e. the error is a bound, not a statistical error. This makes the errors larger than the ones printed in the raw WHAM lines of the *.out files. The Monte Carlo error of the intersection is quoted as the half-width of the 16-84 percentile range (the earlier standard deviation was dominated by nearly parallel draws). None of this can make the estimate more accurate than the bracket; it can only stop me claiming more precision than the data have.
