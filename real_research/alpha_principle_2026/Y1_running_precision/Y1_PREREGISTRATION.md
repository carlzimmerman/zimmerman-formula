# Y1 -- a validated, three-/four-loop running of the SM gauge couplings and an honest error budget (pre-registration)

Written 2026-09-29 BEFORE any script of this lane was written or run. No number of this lane has been computed when this file is written.
Nothing here derives alpha. alpha stays an INPUT; kappa = 1/2 stays FITTED; the SM mass and coupling sector stays walled (measured masses and couplings are inputs).
The point is an honest error budget, never a target. Nothing is tuned.

## Conventions

a_i := 1/alpha_i, i = Y, 2, 3; alpha_Y in the normalisation Q = T3 + Y (b_Y = 41/6); GUT-normalised a_1 = (3/5) a_Y; g_1^2 = (5/3) g_Y^2. a_em := a_Y + a_2 (the SM MS-bar 1/alpha_em, unbroken-phase). Running variable t = ln mu.
Scales: X_P = 1.220890e19 GeV, X_R = 2.435e18 (the campaign's value; the exact M_P/sqrt(8 pi) = 2.4353e18 differs by 1e-4, negligible and reported), X_S = X_R/sqrt(118) = 2.242e17, X_c = the a_1 = a_2 crossing (~1e13; also the a_Y = a_2 crossing ~5e20 that U3's V12 uses).
Beta-function normalisation of the papers: mu^2 d/dmu^2 (alpha_i/pi) = beta_i; Buttazzo: d g^2/d ln mu^2 (their g_1 is GUT-normalised, y_t^2 and lambda with V = lambda |H|^4).

## Expectations (stated so they can be false)

(1) The running, not the inputs, is validated by V1-V3 at the printed-digit level (1e-4 or better). (2) After the upgrade the 1-sigma total on a_Y and a_2 at X_P is 0.05-0.3%, on a_3 0.1-0.2% (alpha_s dominated); the campaign's 0.5-1.5% band was mostly variant-to-variant scatter of crude approximations (with/without the top threshold, set A/B, one- versus two-loop), not a sampled uncertainty. (3) The route-P versus route-G difference (E9) is the largest single item for a_Y (~0.1-0.3%). (4) V09 and V25 do not change into passes; V09's UNDECIDED depends on the free content, not on the running. (5) a_em(X_P) reaches a relative precision (÷137.036) of order 1e-4, so that lane U3's statement "the bar cannot be reached by the running" is FALSE for the SM-desert running alone and TRUE once E9, E10 and the mapping to alpha(0) are included with honest weight -- I expect the honest bottom line to be "roughly 3e-4 to 1e-3, marginal at k = 34".
