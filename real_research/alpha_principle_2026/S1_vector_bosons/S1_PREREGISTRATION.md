## Hand derivation to be CHECKED by scripts (conformal frame; H = c = hbar = 1)
Metric a^2 eta, a = -1/tau. Action (mostly plus), W complex, D = d - ieA, W_{mu nu} = D_mu W_nu - D_nu W_mu:
  S = Int d^4x sqrt(-g) [ -(1/2) W*_{mu nu} W^{mu nu} - m^2 W*_mu W^mu + i c e F^{mu nu} W*_mu W_nu ],
c = 0 minimal (g = 1), c = +-1 (sign fixed by the requirement below) g = 2. In the planar patch sqrt(-g) g^{mu a} g^{nu b} = eta eta (Weyl weight zero) and sqrt(-g) g^{mu nu} = a^2 eta^{mu nu}:
the problem is the FLAT-space Proca problem with time-dependent mass M(tau)^2 = mu^2/tau^2 and electric field calE(tau) = F_{tau z} = E a^2 = E/(H^2 tau^2), potential A_z = -E/(H^2 tau) (kinetic momentum p = k_z + lambda/tau, lambda = eE/H^2, mu = m/H).
1. Constraint. Applying D_nu to the field equation: the term proportional to F_{nu mu} W^{nu mu} cancels iff the sign of c is the g = 2 one; what remains is  D_nu (M^2 W^nu) = (c-term) (d_nu F^{nu mu}) W_mu, with d_nu F^{nu mu} != 0 here (its dS form is nabla_nu F^{nu z} = -2EH/a, as AH4 V3). So even for g = 2 the Lorenz-like condition is sourced by the non-vacuum background; for g = 1 it also contains F W.
2. W_tau is auxiliary. Canonical variables (W_i, Pi_i = W_{tau i}), i = x,y,z, mode e^{i(k_perp x + k_z z)}. Eliminating W_tau by its own equation gives a POSITIVE Hamiltonian
