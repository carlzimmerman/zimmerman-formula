# Experimental data released in the preceding year: closure-oriented search

**Search date:** 2026-09-27. **Release window:** 2025-09-27 through 2026-09-27 (inclusive). This is a sourced inventory of *newly released measurements, data products, or reanalyses of experimental data* relevant to the current theory, not a fit or a claim that the theory is observationally closed. Observation dates can be older than release dates. Public paper-level measurements and public machine-readable products are distinguished below.

**Repository deduplication update:** See [the per-release audit](REPO_AUDIT.md) before starting work. D01/D02/D03/D05/D09/D15 and the KiDS-Legacy summary have already received substantial repository analysis; repeating them would not meet the request for unused data. D06 has been noticed but its **published two-distance covariance had not been used**; a reproducible, limited calculation is in [the Lyα shape check](LYALPHA_SHAPE_RESULT.md). D10, D12 and D13 are the clearest public, apparently unfit products for required lensing/growth/GW sectors. D07's full likelihood is **not yet public**, correcting the initial version of this inventory.

## The target being tested

The operative goal is the [13-requirement one-action theory](../../qwen_claude_field_theory/closure_2026/FRIED_CHICKEN_SPEC.md): the amended `nu_mono`/filtered weak-field law, two gravitational tensor degrees of freedom, derived lensing and conservation, acceptable PPN and GW behavior, stable evolution, cosmology, and controlled limits. The relation `a0 = (c/2) sqrt(G rho_Lambda)` and possible `a0(z) proportional to sqrt(rho_DE(z))` are desirable but explicitly **not required** for closure. Some older repository files discuss AeST or modified inertia as if they were the operative theory; this inventory uses the current specification and does not transfer a data fit from those predecessors to the proposed action. The [2026-09-26 review](../peer_review_2026_09_26/README.md) finds the present construction incomplete.

**Priority key:** P1 = can directly test a currently exposed phenomenological claim or remove a major empirical ambiguity; P2 = constrains a required sector once one action makes a prediction; P3 = useful preparation or ancillary calibration. `Public` means an accessible data product is identified; `paper` means a reported measurement is available but the needed object-level inputs or full likelihood have not been verified here. A release is not independent of a previous release when it reuses the same observations.

## Exclusions and near-term watch points

- **Gaia DR4** is expected in December 2026, so it is outside this completed-release inventory: [ESA status](https://www.esa.int/Science_Exploration/Space_Science/Gaia/%28archive%29). Existing Gaia DR3 reanalyses are D09.
- **Euclid full DR1** is scheduled in phases from November 2026 through mid-2027, outside the window: [mission timeline](https://euclid.caltech.edu/page/data-release-timeline). Q2 is D18.
- **DESI DR2 object spectra/redshifts** were not public on 2026-09-27; the released chains and Lyα measurement are D05-D06: [DESI documentation](https://data.desi.lbl.gov/doc/papers/).
- **WALLABY pilot DR1/DR2**, **ACT DR6**, **Gaia DR3**, **eROSITA DR1**, and **GWTC-4.0** were released before 2025-09-27. They remain valuable baseline/control data, but are not new entries for this one-year search. [WALLABY DR2](https://wallaby-survey.org/data/data-pilot-survey-dr2/), [ACT data](https://act.princeton.edu/act-dr6-data-products), [GWTC-4.0 release date](https://www.ligo.caltech.edu/LA/news/ligo20250826).
- **BepiColombo/MORE Mercury science data** had not yet begun by the cutoff; orbit insertion is scheduled for November 2026 and science for 2027: [mission status](https://www.asi.it/2026/09/mercurio-si-avvicina-parte-la-fase-piu-delicata-della-missione-bepicolombo/).

## Recommended order of work

1. **Lock one forward model.** Derive observables from the same action, with the amended `nu_mono`, heat filter, source/force operator, Solar-System limit and cosmology. This is required before declaring any release a pass/fail for the theory.
2. **Use the genuinely new geometry summary:** D06 Eq. 26 is now checked against the Unite central CPL point in this folder. Obtain the full AP likelihood when released and combine it with D05 using the survey covariance. Unite's D07 object-level likelihood is pending, so do not claim a full joint fit.
3. **Build the theory prediction for unused public products:** D10 DES Y6 and D12 SPT-3G lensing require both metric potentials and perturbation transfer functions from the same action. D13 GWTC-5 requires an explicit tensor waveform/propagation prediction. These are high-value, but fitting a generic ΛCDM template would not close the theory.
4. **Check the specifically new Bullet image catalog D04** against the existing Bullet mass ledgers before any fresh model fit. The repo already analyzed related 2026 Bullet measurements; use new image positions only if they add a genuinely distinct constraint.
5. **Do not rerun completed lanes by default:** D01/D02 high-z galaxies, D03 Cassini, D05 DESI chains, D09 wide binaries, and D15 eROSITA have existing computations. Reopen them only with a changed action-level prediction or a clearly new observable. D16-D19 are ancillary or access-limited.

## Search method and limits

I checked the repository's current target and 2026-09-26 review, searched primary collaboration/mission release pages and primary papers across galactic dynamics, dark-energy distance probes, lensing/CMB, clusters, Solar-System gravity, and gravitational waves, and then searched the local repository for exact paper IDs, dataset names, cached files and analysis scripts. Dates above are **release/publication dates**, not collection dates. I did not download large catalogs or authenticate every supplementary file. [The audit](REPO_AUDIT.md) records which claims are based on exact identifiers and which are channel-level matches. The inventory is comprehensive across the specified *closure-relevant channels* found by this search, not a guarantee that no small specialized release exists.
