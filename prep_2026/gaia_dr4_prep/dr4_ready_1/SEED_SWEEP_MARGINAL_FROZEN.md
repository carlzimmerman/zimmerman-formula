# SEED SWEEP — FROZEN QUESTIONS M1–M4: where does the build-to-build pair flipping come from? (DR3, descriptive)

Written 2026-09-30 and committed BEFORE the script that answers it exists or runs. **DR3 numbers are code-path tests, never results (Amendment 7(e)); NON-SCORING; no verdict words; no threshold.** Not blind to: the stream decomposition (`seed_sweep_streams_dr3.out`, a51d6f8f2: every stream alone flips about as many pairs as all together, 142 / 152 / 158 one-way) and to the one-pair test run ad hoc before this file (removing one pair from the array given to `vt_error_mc` changed the MC sigma_vt of ALL 1,999 other pairs of a 2,000-pair slice, median relative change 4.9%, 90th percentile 11.8%). The questions below quantify that picture; nothing frozen is touched (the builder is imported read-only, hash checked).

## Questions (PRIMARY base, N_SHIFT = 30, the ten WP2-gamma builds and the extract's own k = 0 stage F)
- **M1 inclusion frequency.** Across the ten ALL-family final tables (`seed_streams/ALL_k*.csv`): the number of pairs in all ten (core), in 1 to 9 (marginal), ever in any; the same for the ten G-only tables.
- **M2 membership against flips.** For each ALL build k = 1..9: the number of cut-13 candidates (pairs passing every cut except A_V, vtilde error and 13) present in k but not in k = 0 and the reverse, next to the number of final-pair flips against k = 0 (one way each).
- **M3 stream alignment.** `vt_error_mc` on the same 2,000-pair slice with one pair removed at positions 0, 1000 and 1999: the number of the other pairs whose sigma_vt changes, and the median relative change; and the same with the pair list reversed (a permutation of the SAME pairs): whether a pair's sigma_vt depends on its position.
- **M4 threshold margin.** With the extract's stage F (k = 0's E and F) and G seeds SEED + k, k = 0..9: per pair r_k = sigma_vt,k / (0.1 max(1, vtilde/2)) (the cut of the builder's stage G: pass if r <= 1). Reported: the median over pairs of the relative scatter of sigma_vt across the ten seeds (for a Gaussian estimate from 212 trials the expected relative standard error is 1 / sqrt(2 x 211) = 4.9%); the number of pairs that pass in some seeds and fail in others; and the model prediction of the one-way flip count between two independent draws, sum over pairs of p (1 - p) with p = the pass fraction over the ten seeds, next to the observed G-only one-way flips (142.3 mean over k = 1..9).

## Declared limits (before the run)
The pass fractions over ten seeds are coarse (steps of 0.1) and k = 0's own draw is one of the ten, so the model prediction is approximate; M1 to M4 say nothing about DR4 (other N, other cuts on the catalogue).
