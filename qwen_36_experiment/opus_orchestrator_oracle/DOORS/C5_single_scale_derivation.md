## The door
The relabelling theorem kills any construction that **combines** `G rho_Lambda` with `c^2 Lambda`, because
`Lambda = 8 pi G rho_Lambda / c^2` makes them one scale up to 8pi. But its boundary is sharp and favourable:
`sqrt(G rho_Lambda)` is **pi-free** while `sqrt(8 pi G rho_Lambda/3)` is not, so a derivation whose **only**
input is the density rho_Lambda has no second scale to average against and no 8pi to hide in. Such a
derivation is not excluded — and it would **automatically exclude c H_Lambda**, because it can never
manufacture the Friedmann 8pi/3.
