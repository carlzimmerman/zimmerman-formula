# Project Protogonos (Πρωτογόνος — "The First-Born")

## The Question

**What are the exact physical conditions required for non-organic matter to spontaneously organize into self-sustaining organic matter?**

This project seeks to identify and computationally demonstrate the complete set of physical parameters — temperature, pressure, pH, mineral surfaces, electromagnetic fields, radiation flux, and geometric constraints — that make the transition from prebiotic chemistry to self-replicating life **inevitable**, not miraculous.

## The Name

Protogonos (Πρωτογόνος) — in Orphic cosmogony, the primordial being that emerged from the Cosmic Egg. The very first thing that was born from nothing. This project aims to specify the exact physical "Cosmic Egg" that gives birth to life.
