# Reproduction and source integrity

Each route contains its frozen contract, declared inputs, execution program, structured outputs, stdout/stderr and manifest. The manifests describe historical runs in the original temporary directories. Copying evidence into this branch does not change those records. A completed manifest is execution provenance, not proof of the scientific interpretation.

The inverse and full-catalog design programs resolve their input data relative to their own directory. Their raw SPARC files are byte-preserved, including original header whitespace. Run reproductions into new output directories, retain the declared software versions and limits, and generate new manifests; never overwrite a historical run. The inverse report discloses inherited metadata errors, including the actual 500-evaluation quotient optimizer cap, and preserves the failed unregularized DDO154 block.

The theory program also rehashes thirteen original repository source files named with absolute paths in `theory/inputs.json`. Those unchanged bytes have been archived under `theory/source_inputs/`, with their original-to-snapshot correspondence in `theory/source_snapshot_map.json`. On another machine, make a separate working copy and remap only those input paths to the archived snapshots before a new manifested run. This changes the provenance input JSON for that new execution; it does not change the mathematical calculation or permit editing the historical manifests. The program itself imports no execution code from those thirteen files.

Theory runs 001 and 002 failed. Their exact historical script bytes are retained as `check_portal.py.snapshot` inside the respective run directories and match their original input hashes. Run 003 is the accepted corroboration; its source snapshot is retained too. The portal's first failed script likewise remains available. The coordinator's integrated integrity audit resolves these explicitly recorded historical source versions instead of pretending every run used the final script.

The portal and growth symbolic checks, positive-baryon bounds, quotient simulations and candidate-action matrix fixtures have different assumptions. Their separate results cannot be concatenated into a single action passing all observational and health gates. The independent reviews and handoff describe the allowed implications.
