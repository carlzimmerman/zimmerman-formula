# Classical Mechanics: The Foundation

Before quantum mechanics, gauge theory, and string theory, there was classical mechanics. The concepts here - especially the Lagrangian and Hamiltonian - are the foundation of all modern physics.

---

## 1. Newton's Laws

### The Three Laws

1. **Inertia:** Objects at rest stay at rest; objects in motion stay in motion (unless acted on by a force)

2. **F = ma:** Force equals mass times acceleration

3. **Action-Reaction:** Every action has an equal and opposite reaction

### Limitations

Newton's laws work but:
- They're coordinate-dependent (ugly in curved coordinates)
- They don't easily generalize to fields
- They obscure the deep structure (symmetry → conservation)

We need a better formulation.

---

## 2. The Lagrangian Formulation

### The Lagrangian

```
L = T - V = (kinetic energy) - (potential energy)
```

**Example:** A particle of mass m in potential V(x):
```
L = ½mẋ² - V(x)
```

where ẋ = dx/dt is velocity.

### The Action

The **action** S is the integral of L over time:
```
S = ∫ L dt = ∫ (T - V) dt
```

### The Principle of Least Action

**The path a particle takes extremizes the action.**

This one principle replaces all of Newton's laws!

### Euler-Lagrange Equations

The condition δS = 0 gives:
```
d/dt (∂L/∂ẋ) - ∂L/∂x = 0
```

**Example:** For L = ½mẋ² - V(x):
```
∂L/∂ẋ = mẋ
∂L/∂x = -∂V/∂x = F

d/dt(mẋ) = F
ma = F  ✓ Newton's second law!
```

---

## 3. Why Lagrangians Matter

### Coordinate Independence

The Euler-Lagrange equations have the same form in ANY coordinate system.

**Example:** Polar coordinates (r, θ):
```
L = ½m(ṙ² + r²θ̇²) - V(r)
```

The equations of motion automatically include "centrifugal force" terms - no need to add them by hand.

### Symmetry and Conservation (Noether's Theorem)

**If L has a symmetry, there's a conserved quantity.**

| Symmetry | Conserved Quantity |
|----------|-------------------|
| Time translation (t → t + a) | Energy |
| Space translation (x → x + a) | Momentum |
| Rotation (θ → θ + α) | Angular momentum |

This is **Noether's theorem** - one of the most important results in physics.

### Generalization to Fields

The Lagrangian formalism extends naturally to:
- Many particles
- Continuous systems (strings, fluids)
- Fields (electromagnetism, quantum fields)

**Why this matters for Z²:** All of physics - the Standard Model, general relativity, string theory - is formulated using the action principle.

## 4. The Hamiltonian Formulation

### Conjugate Momentum

Define the **canonical momentum**:
```
p = ∂L/∂ẋ
```

For a free particle: p = mẋ (ordinary momentum).

### The Hamiltonian

The **Hamiltonian** is the Legendre transform of L:
```
H = pẋ - L
```

For a standard system (L = T - V with T quadratic in velocities):
```
H = T + V = total energy
```

### Hamilton's Equations

The equations of motion become:
```
ẋ = ∂H/∂p
ṗ = -∂H/∂x
```

These are **first-order** equations (Lagrange gives second-order).

### Phase Space

The state of a system is a point (x, p) in **phase space**.

Dimension of phase space = 2 × (degrees of freedom).

---

## 5. Poisson Brackets

### Definition

For functions f, g of (x, p):
```
{f, g} = ∂f/∂x · ∂g/∂p - ∂f/∂p · ∂g/∂x
```

### Equations of Motion

```
df/dt = {f, H}
```

Time evolution is generated by the Hamiltonian.

### Canonical Relations

```
{x, p} = 1
{x, x} = 0
{p, p} = 0
```

**Why this matters:** In quantum mechanics, Poisson brackets become commutators!
```
{f, g} → (1/iℏ)[f̂, ĝ]
```

---

## 6. Symmetry and Conservation Laws

### Noether's Theorem (Detailed)

If the Lagrangian is invariant under a continuous transformation:
```
x → x + εδx
```
then there exists a conserved quantity:
```
Q = ∂L/∂ẋ · δx
```

### Examples

**Time translation symmetry:**
- Transformation: t → t + ε
- Conserved: Energy H

**Spatial translation:**
- Transformation: x → x + ε
- Conserved: Momentum p

**Rotation:**
- Transformation: θ → θ + ε
- Conserved: Angular momentum L

### Gauge Symmetry (Preview)

In field theory, **local** symmetries (different at each point) lead to **gauge fields**.

The Standard Model IS a gauge theory!

---

## 7. Constraints

### Types of Constraints

**Holonomic:** Can be written as f(x, t) = 0
**Non-holonomic:** Involves velocities, can't be integrated

### Lagrange Multipliers

For a constraint f(x) = 0, modify the Lagrangian:
```
L' = L + λf(x)
```

The multiplier λ is determined by the constraint.

### Why Constraints Matter

- Gauge theories have constraints
- General relativity has constraints (Hamiltonian and momentum constraints)
- The ADM formalism is built on constrained Hamiltonian mechanics

## 8. Field Theory Preview

### From Particles to Fields

| Particle | Field |
|----------|-------|
| Position x(t) | Field φ(x, t) |
| Velocity ẋ | Gradient ∂φ/∂x, time derivative ∂φ/∂t |
| Lagrangian L | Lagrangian density ℒ |
| Action S = ∫L dt | Action S = ∫ℒ d⁴x |

### The Field Lagrangian Density

For a scalar field:
```
ℒ = ½(∂ᵤφ)(∂ᵘφ) - ½m²φ² - V(φ)
```

### Euler-Lagrange for Fields

```
∂ℒ/∂φ - ∂ᵤ(∂ℒ/∂(∂ᵤφ)) = 0
```

This gives the field equations (e.g., Klein-Gordon equation).

---

## 9. Connection to Quantum Mechanics

### The Path Integral

Feynman's formulation of quantum mechanics:
```
⟨x_f|e^{-iHt}|x_i⟩ = ∫ 𝒟x e^{iS[x]/ℏ}
```

Sum over all paths, weighted by e^{iS/ℏ}.

### Classical Limit

When S >> ℏ, the path integral is dominated by the classical path (stationary action).

Quantum mechanics reduces to classical mechanics as ℏ → 0.

### Quantization

To quantize:
1. Start with classical Lagrangian/Hamiltonian
2. Promote variables to operators
3. Replace Poisson brackets with commutators: {,} → [,]/iℏ
