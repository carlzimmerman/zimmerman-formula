# String Theory Basics

String theory replaces point particles with tiny vibrating strings. Different vibration modes give different particles. This framework naturally incorporates gravity and requires extra dimensions - exactly what the Z² framework uses.

---

## 1. The Basic Idea: Everything is Vibration

### Real-World Analogy: A Guitar String

A guitar string can vibrate in many modes:
- **Fundamental** (lowest frequency) → lowest note
- **First harmonic** (2× frequency) → octave higher
- **Second harmonic** (3× frequency) → fifth above octave
- Each mode has different energy

```
    Fundamental:     ∿∿∿∿∿∿∿∿∿∿
    1st harmonic:    ∿∿∿∿╱╲∿∿∿∿
    2nd harmonic:    ∿∿╱╲╱╲╱╲∿∿

    Different modes = different notes
```

### Strings in Physics

In string theory:
- **Different vibration modes = different particles**
- An electron is a string vibrating one way
- A photon is the same string vibrating another way
- A graviton is yet another vibration mode!

```
    Point particle:     ●
    (no internal structure)

    String:             ∿∿∿
    (rich internal structure = many particles)
```

### Why Strings?

Point particles cause problems:
- Infinities in quantum gravity
- Can't consistently combine with gravity

Strings solve these:
- "Smeared out" over tiny distance
- Natural UV cutoff
- Gravity emerges automatically!

## 4. Critical Dimensions

### The Surprising Result

String theory only works in specific dimensions:

| String Type | Dimension |
|-------------|-----------|
| Bosonic | 26 |
| Superstring | **10** |
| M-theory | 11 |

### Why 10 Dimensions?

Quantum consistency requires:
- **Conformal invariance** on the worldsheet
- Absence of **anomalies**
- These only work in D = 10 for superstrings

### Where Are the Extra Dimensions?

We only see 4 (3 space + 1 time). The other 6 must be:
- **Compactified** (curled up small)
- At the string scale: l_s ~ 10⁻³³ cm

```
    What we see:         Reality (maybe):

    ─────●─────          ─────●═══○─────
    1D space             1D extended + 1D curled up

    The circle is too small to see!
```

### Real-World Analogy: A Garden Hose

From far away:
- A hose looks 1-dimensional (a line)
- Up close, it's a 2D surface (tube)

```
    Far:    ─────────────────
            (looks 1D)

    Close:  ═══════════════○
            (2D tube!)
```

**Extra dimensions could be "too small to see."**

### Calabi-Yau Manifolds

The most studied compactifications use **Calabi-Yau** spaces:
- Complex 3-folds
- Ricci-flat (R_μν = 0)

```

**Why this choice?**
- Simpler than Calabi-Yau

## 6. D-Branes

### What is a D-Brane?

A D-brane (Dirichlet brane) is a surface where **open strings can end**:

```
    D-brane (extends in some dimensions)
    ═══════════════════════════════════
        │           │           │
        │ ∿∿∿∿∿∿∿∿ │           │
        │  string   │           │
        │           │           │
        ●───────────●───────────●
        endpoints fixed on brane
```

### Real-World Analogy: A Bulletin Board

Imagine strings are rubber bands with thumbtacks:
- The thumbtacks can only stick to the bulletin board (brane)
- The rubber band stretches between tacks
- The board is a D-brane!

### Gauge Fields Live on Branes

Open strings ending on a D-brane create **gauge fields**:
- Dp-brane (p spatial dimensions) → (p+1)D gauge theory
- **D3-branes** → 4D gauge theory (Standard Model!)

### The Standard Model from Branes

```

                    │
    SU(2) branes ═══│═══════════  ← 2 branes → SU(2) weak
                    │
    U(1) brane   ═══│═══════════  ← 1 brane → U(1) hypercharge
                    │
                 fermions at
                 intersections!

In string theory:

## 9. Supersymmetry

### What is SUSY?

Supersymmetry relates bosons and fermions:
```
Q|boson⟩ = |fermion⟩
Q|fermion⟩ = |boson⟩
```

Every particle has a **superpartner**:

| Particle | Superpartner |
|----------|--------------|
| Electron | Selectron |
| Quark | Squark |
| Photon | Photino |
| Graviton | Gravitino |

### Why Strings Need SUSY

- Removes **tachyon** (faster-than-light particle) from bosonic string
- Makes theory stable
- Reduces dimensions from 26 to 10
- Helps with hierarchy problem

### The Z² Framework and SUSY

T³/Z₂ compactification **breaks** some supersymmetry:
- Start with N = 8 SUSY in 3D
- Z₂ projection breaks some
- Gives chiral fermions and realistic physics

## 10. Dualities

### The Web of Theories

What seemed like 5 different string theories are **all related**:

```
         Type IIA
            ↕
     Type I ←→ Type IIB
            ↕
         Heterotic SO(32)
            ↕
         Heterotic E₈×E₈
```

All connected by **dualities**!

### T-Duality

Strings on a circle of radius R are equivalent to radius α'/R:
```
String on circle R = String on circle α'/R
```

**Small and large radii are physically equivalent!**

### Real-World Analogy: Looking in a Curved Mirror

In certain curved mirrors:
- Small objects look big
- Big objects look small
- Two different sizes can look the same!

T-duality is like nature having a built-in "mirror."

### S-Duality

Strong coupling ↔ Weak coupling:
```
g_s → 1/g_s
```

What's hard to calculate in one theory becomes easy in another!
