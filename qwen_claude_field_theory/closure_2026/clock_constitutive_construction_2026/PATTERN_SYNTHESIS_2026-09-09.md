# Pattern across the latest doors

The latest repository work is not a collection of unrelated failures.  It is
converging on one architectural fork.

1. The deep-MOND, two-metric, memory, and AeST audits all put pressure on the
   same missing object: a non-Einstein response that is strong enough to make
   the MOND force law, but does not become a scalar graviton, a slip source, or
   an independently propagating hidden sector.

2. A purely local curvature modification produces the familiar slip/lensing
   problem.  A spatially elliptic projector can repair the static constitutive
   law and cancel selected inverse-Laplacian residues, but its metric-dependent
   kernel and York decomposition must themselves be varied.  A causal memory
   repair replaces the elliptic residue with extra state data; it therefore
   spends the two-tensor degree-of-freedom budget unless the extra state is
   separately counted and healthy.

3. The constructive clock branch shows the same fork in a sharper finite
   calculation.  The scalar-only residue condition admits two coefficient
   branches.  The all-six-polarization conserved-source gate removes the second
   branch and forces the V3 scalar, vector, and TT normalizations onto one
   `C/2` surface.  This is why the TT term is not cosmetic: it repairs the
   tensor part of the same response budget.

4. The empirical work shows an analogous identification problem.  The current
   cluster/group lane cannot separate a metric phantom from hydrostatic bias,
   while the precise collisionless-tracer comparisons constrain the available
   phantom amplitude.  The supernova and high-redshift `a0` lanes provide tests,
   not a derivation of the action.  Thus “the data are compatible” is not a
   closure certificate, and “the action fits one static lane” is not a
   relativistic theory.

The strongest surviving statement is therefore conditional and constructive:
the fixed exponential kernel is not the immediate algebraic obstruction.  In a
constant-coefficient linearized family, a nonlocal spatial repair can be made
to pass the six-source response gate, but only on a forced coefficient surface.
The next unavoidable calculation is the full nonlinear variation and Dirac
closure of the metric-dependent York-TT and Hodge pseudoinverses.  That is the
point at which the fork is decided: either their metric variation closes into
constraints without an instantaneous physical channel, or the construction
falls back into the same extra-state/slip obstruction found elsewhere.

This synthesis is a research checkpoint, not a claim that the original
ten-gate theory is complete.
