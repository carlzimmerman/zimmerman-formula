# Frozen concurrent Lean input

`ConcurrentMondlean.lean` is an unmodified source snapshot of
`fable_independent_2026/lean_2026/Mondlean.lean` at commit
`293b4e70a167e6845e544b42671f7c24994c80a4`.

The first root verification run could not recompile this file in the available
cached Mathlib environment: an imported Asymptotics declaration conflicted with
another cached module. Its own saved project lacked materialized dependencies,
and an attempted ordinary build-context lookup failed on network DNS. Neither
failure establishes a mathematical defect in the propositions.

The live file is being updated concurrently. This snapshot preserves the exact
source used in the failed check without modifying that work or treating a
potentially moving source as permanent pinned evidence.
The snapshot remains credited to its original repository authors/commit; it
is not counted among this checkpoint's new theorems. Compilation checks the
formal propositions, not the physical interpretation of their comments.
