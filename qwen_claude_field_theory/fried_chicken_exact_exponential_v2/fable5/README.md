This is the handoff package for a stronger model. Start with MASTER_ATTACK.md.

The primary published reference is:
C. Deffayet and R. P. Woodard, A Nonlocal Realization of MOND that Interpolates from Cosmology to Gravitationally Bound Systems, arXiv:2512.10513v2 (30 Apr 2026), JCAP 04 (2026) 081.

The paper itself says the cosmology-to-bound-system transition, nonlinear structure formation, clusters, and EFE require further work. Do not treat those as solved merely because the paper presents a candidate interpolation.
