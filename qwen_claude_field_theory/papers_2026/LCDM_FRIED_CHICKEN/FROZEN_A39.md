## Sources (web look-ups PROVISIONAL; equations from memory flagged)

- Creminelli, D'Amico, Norena, Senatore, Vernizzi 2010 (JCAP, arXiv:0911.2701), abstract read 11-04: with negligible sound speed "quintessence follows dark matter during the collapse"; the overdensity evolves as a separate closed FLRW universe; quintessence "contributes to the total halo mass by a fraction ~ (1+w) Omega_Q / Omega_m". The equations below are FROM MEMORY in their structure (not read in the paper): inside the top hat, c_s = 0 means delta p = 0, so p = p_bar(t), and the local energy equation is d rho_in/dt = -3 h (rho_in + p_bar), h = Rdot/R the shell's expansion; the shell obeys Rddot = -G M_m/R^2 - (4 pi G/3)(rho_in + 3 p_bar) R. Linearised this gives d delta_DE/d ln a = 3 w delta_DE + (1 + w + delta_DE) d delta_m/d ln a, with the matter-era attractor delta_DE = (1+w)/(1-3w) delta_m (Sefusatti and Vernizzi 2011 relation, from memory; checked as a control below, the algebra was redone here).
- Simpson 2010 (PRD, arXiv:1007.1034), abstract read 11-04: elastic DE-DM scattering, background unchanged, structure growth suppressed. The drag term is FROM MEMORY: DM Euler equation gets -(1+w) rho_DE (sigma_D/m) c (v_DM - v_DE), i.e. a drag rate Gamma = xi (1+w) rho_DE c with xi = sigma_D/m. The amplitude A_ds = xi (1+w) is what KiDS-1000 constrains: Carrion et al. 2024 (arXiv:2402.18562, via a web search summary, provisional) |A_ds| <~ 20 b/GeV (KiDS alone), A_ds = 10.6 +4.5 -7.3 b/GeV (with Planck + BAO). 1 b/GeV = 0.05609 m^2/kg. Pourtsidou et al. 2013 Type 3 and Asghari et al. have velocity-proportional momentum couplings of the same structure with different coefficients; only the elastic-scattering form is implemented, stated.

## Route (a): clustering dark energy, c_s = 0 (zero new knobs)

Spherical collapse in each background, units H0 = 1, rho in rho_crit0: Rddot = -(1/2)[rho_m,in + Ode0 (x + 3 w f)] R, dx/dt = -3 (Rdot/R)(x + w f), with f(a) = rho_DE(a)/rho_DE0 and w(a) from colossus, rho_m,in = Om0 a_i^-3 (1 + delta_i)(R_i/R)^3. Start a_i = 0.01, growing mode Rdot/R = H(1 - delta_i/3), x_i = f(a_i)[1 + (1+w_i)/(1-3w_i) delta_i]. delta_i root-found so the shell collapses (R < 1e-3 R_ta) at a_c = 1/(1+z_obs) (primary convention: halo collapses at the epoch it is observed, as A29 builds halos at rho_crit(z); sensitivity row: collapse at z_obs + 1 for z_obs = 0). Virialisation at R = R_ta/2 on infall (standard approximation; the c_s = 0 virial correction is not modelled, stated); x frozen there (h = 0 after virialisation gives d rho_in/dt = 0).
- eps_M = Ode0 (x_v - f(a_c)) / rho_m,in(v): DE mass fraction of the virialised top hat (the published quantity, expected of order (1+w) Ode/Om at collapse).
- eps_y = Ode0 (x_v + w_v f_v) / rho_m,in(v): the ratio of (rho + p_bar) to matter on the shell.
Two readings at galaxy radii:
- R1 (published top hat): DE overdensity uniform inside the virial sphere, Delta g = (4 pi G/3) eps_M Delta_v rho_m_bar(a_c) r, Delta_v = rho_m,in(v)/rho_m_bar(a_c).
- R2 (generous tracer, upper bound): (rho + p_bar) of the DE keeps tracing the DM through the halo's inner compression with no shell crossing, so Delta g = eps_y G M_DM(<r)/r^2 - (4 pi G/3)(1+w) rho_DE_bar r on the R11b halo. Imposed, not derived: a single-stream c_s = 0 fluid would form caustics where the DM shell-crosses; this reading overstates the effect.
Controls: B0 gives eps = 0 exactly and linear delta_c in 1.66 to 1.70 (collapse at z 0, Om0 0.315); constant w = -0.9 background, delta_DE,i = 0 at a_i: delta_DE/delta_m at a = 0.1 within 2 % of (1+w)/(1-3w) = 0.0270.

## Route (b): dark scattering drag (one knob, xi = sigma_D/m >= 0)

Force per unit mass on DM only: -Gamma(t) (v - v_DE), Gamma = xi (1 + w(t)) rho_DE(t) c. Internal motions taken relative to the halo frame with the DE at rest there (the bulk part -Gamma v_bulk is a uniform acceleration on DM only; reported as a DM-baryon offset acceleration at v_bulk 300 km/s, not modelled further). For any orbit the torque gives dj/dt = -Gamma j exactly, so j_f = j_i exp(-tau), tau = integral Gamma dt over the halo's life: from max(t(z_obs) - 10 Gyr, t(z = 10)) to t(z_obs). Imposed: circular-orbit mapping with no shell crossing (the Blumenthal assumption), r_f M_tot(r_f) = exp(-2 tau) r_i M_tot,i(r_i), DM shell mass conserved, baryons held fixed (they do not feel the drag; their own response to the contracted DM is not followed, stated). Initial state = the R11b halo at K11B in that background (A29 galx on a fine radius grid; baryon mass inside r interpolated from SPARC, as r^3 inside the first point and constant outside the last, stated). tau < 0 (phantom eras, 1 + w < 0) is anti-drag and expands the halo.
Rows: L literature, A_ds = (1+w0) xi = 10.6 b/GeV, sign following (1+w0) (skipped in B0 and B5 where 1+w0 ~ 0); T tuned, xi fitted to the law on all SPARC at z = 0 (bounded so |A_ds| <= 200 b/GeV, ten times the KiDS bound; at bound disclosed); H holdout, xi tuned on GS[::2], graded on GS[1::2] (gate 0.025). z rows use the z = 0 tuned xi.
