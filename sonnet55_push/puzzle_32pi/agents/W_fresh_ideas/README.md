## 1. The constraint map I used to screen (all from the lanes, restated so the screen is auditable)
- **Lindemann wall (G, L, M, N, R).** a0/(cH) = 1/Z = sqrt(3/32π) is transcendental. Any condition that is an algebraic relation between geometric quantities (Λ, r, M) gives a0/H algebraic. Proved once more here for the extended thermodynamics of Schwarzschild-de Sitter: for ANY horizon radius, κ²/|P| = 2π(1-x)²/x with x = Λ r² and P = -Λ/8πG, so every algebraic condition gives κ²/|P| = π × algebraic while the puzzle needs 1/4 (script, section W03).
- **Where a rational can live: the pi-free variable Gρ (H3 of the audit).** In Gρ_Λ = 4 a0² the coefficient is rational, so the mechanism must (a) involve c, (b) involve ρ_Λ through a source (an 8πG) and (c) contain a compensating 1/π (a solid angle, a Gaussian, a slab-vs-sphere Gauss law). I call these "rational carriers": Newtonian mean-density thresholds (2ρ_Λ, 8ρ_Λ), F_Λ = 6 F_max, g_Hubble = cH/2, Σ_Λ = 4π Σ_M, a_nn² = Gρ·(Gm/ℓ). All are identities of the pi-free variable; none has an independent dynamical selection of the coefficient.
- **hbar-free**: the mechanism may not contain S = A/4ħ-type counting unless it cancels in a ratio; anything with ħ in a0 is 60+ orders off (A, Q, U).
- **No knob**: a declared free constant beyond kappa is forbidden; a hit obtained by solving for a parameter is void (D, J).
- **Poisson-prefactor theorem (K, G, recomputed in W11 below).** In any density-linear model with the Poisson-normalised prefactor a0²/(8πG), Gρ_vac/a0² = c/(8π); the puzzle needs c = 32π (transcendental), so rational shape functions cannot do it.
- **Branch structure worth stating plainly (new framing).** Two branches are logically distinct: the *rational-in-H* branch (a0/cH = 1/2, 1/3, 1/6: reachable by every geometric or thermodynamic mechanism, and 1/6 is inside the data's 68% interval) and the *transcendental-in-H* branch (1/Z = sqrt(3/32π), 1/2π: reachable only through a source term with a compensating 1/π). The 20 lanes show no mechanism produces the second; W14 is the only idea below that looks at the first with a π-free rational carrier (F_max). The data cannot choose between the branches (lane V: Z = 5.789, 6, 2π not separable below ~2-4% error).
