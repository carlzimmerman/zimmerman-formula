## What the certificates say that is worth knowing (and what they do not)
1. **The 32 pi of the three big constants is bookkeeping, again.** 32 pi^2 = Vol(S^3) x 16 = 32 pi^2 chi/1 = A_a0 Lambda are three different computations that give the same number; Lean confirms the arithmetic and the
   size-independence (`bpst_size_independent`, `s4_euler_scale_free`). Nothing links the size-independent topological numbers to the a0-Lambda relation (which is a size relation): the link exists only
   through the puzzle's own equation.
2. **Graviton (arrow 4) is a relabelling.** `puzzle_in_kappa_g_form`: with G = 1 and kappa_g^2 = 32 pi G, Lambda = 32 pi a0^2 reads Lambda = kappa_g^2 a0^2. That is the same 32 pi written with the graviton coupling, not
   evidence that the two are related. The Isaacson normalisation 1/(32 pi G) and the coupling 32 pi G are the same 32 pi by the canonical-normalisation bridge (`kappa_g_bridge`, `canonical_energy_matches_isaacson`).
3. **Free fall (arrow 5).** The pi/2 of the integral gives 3 pi/32 under the square root (`tff_uniform`); with the puzzle relation the vacuum-density free-fall time is t_ff = r_s sqrt(3 pi/32) (`tff_sq_over_rs_sq`). Exact but definitional.
4. **Correction to a peer note (`p06`, README section 8, and the docstring of `p06_embedding_no_go.py`, control E).** They write "embeddable iff Z <= 2, i.e. kappa >= 1". With the framework's Z = sqrt(8 pi/3)/kappa
   (kappa = 1/2 gives sqrt(32 pi/3); kappa = 1 gives 2.894) the exact threshold is **kappa >= sqrt(2 pi/3) = 1.447**; `embeddable_iff_kappa` and `kappa_one_not_embeddable` prove this, and the false claim "Z <= 2 <=> kappa >= 1" is
   `M6e` (fails) with twin `M6e_refuted`. The conclusion of p06 (kappa = 1/2, Milgrom's 2 pi and Verlinde's 6 are all outside) is unchanged; only the parenthetical was off. p06's script checks Z > 2 numerically and is unaffected.
5. **Transcendence of pi is NOT in Mathlib** (checked: only `Mathlib/NumberTheory/Transcendental/Lindemann/AnalyticalPart.lean`, no theorem about pi). So p09's "an algebraic local potential cannot give U_v = 32 pi" is certified only in two forms:
   unconditionally for quadratic rational-coefficient potentials (the stationary value is rational and 32 pi is irrational by Mathlib's `irrational_pi`), and for every rational-coefficient polynomial potential
   **conditional on the hypothesis `Transcendental Q pi`** (`polynomial_potential_no_32pi`; the hypothesis is Lindemann 1882, a true theorem, but it is an explicit premise here, not a Lean-proved fact).
