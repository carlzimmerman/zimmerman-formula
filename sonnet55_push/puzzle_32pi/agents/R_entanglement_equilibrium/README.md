## 1. Small-ball reproduction (r01, r02) -- every factor
- Ball in RNC, in n = d-1 spatial dimensions: A = Omega_{n-1} l^{n-1}[1 - R l^2/(6n)], V = Omega_{n-1} l^n/n [1 - R l^2/(6(n+2))] (exact spheres and hyperboloids n = 2..7; only the SCALAR curvature enters: S^2 x R, S^2 x R^2; random algebraic Riemann tensors in d = 4 by quadrature, error ~ l^2).
- K = 0 slice: R_slice = 2 G_00 (checked for random Lorentzian curvature tensors d = 4,5,6; a mutated R_slice = G_00 is rejected).
- Fixed radius: dA|_l = -Omega l^d R/(6(d-1)). Fixed volume: dA|_V = dA - (d-2)dV/l = -Omega l^d R/(2(d^2-1)) = -Omega l^d G_00/(d^2-1) (3/(d+1) times the fixed-radius value; dropping the correction changes the Einstein coefficient by exactly 3/(d+1), reproducing the paper's "(d+1)/3" remark).
- Matter: int xi dV = Omega l^d/(d^2-1) with xi = (l^2-r^2)/(2l) (zeta of unit surface gravity: L_zeta g = -(2t/l) g). Chain (1/4G) dA|_V + 2 pi d<H_zeta> = 0 => G_00 = 8 pi G T_00 for every d (d = 3, 4, 5, 10 numerically). Honest limitation: only the product 2 pi x 4 is detected.
- Controls fire: a wrong volume coefficient 1/(6(d-1)(d+2)) changes the result to 8 pi G (d+2)/(d+1); doubling the weight gives 16 pi G; pi for 2 pi gives 4 pi G.
- Lambda: dS_d has G_ab = -lambda g_ab, lambda = (d-1)(d-2)/(2L^2), slice S^{d-1}(L) with R_slice = 2 lambda, so eq (22) G_00 + lambda g_00 vanishes identically for every L (explicit sympy dS_4). The equilibrium never selects L; the paper's Lambda is an integration constant.

## 2. The new step: the exact finite ball (r03)
Exact ball on S^n(L), geodesic radius x L: d = 4: A = 4 pi L^2 sin^2 x, V = 2 pi L^3 (x - sin(2x)/2) (the task text's expression has V(pi) = pi^2 L^3, half of Vol S^3; rejected by control E1c). dA/dV = (n-1) cot(x)/L = the boundary mean curvature, zero at the equator. Small-ball limit: A_dS(V)/A_flat(V) - 1 = -(1/5)(l_f/L)^2 = eq (22) with G_00 = 3/L^2 (my first hand value -1/10 had a spurious 1/(d-2); the script caught it, control E1d).

**Proposition (verified, not only argued).** Slice ds^2 = dchi^2 + s(chi)^2 dOmega_{n-1}, s = L sin(chi/L) + eps p(chi), R[s] = -2(n-1)s''/s + (n-1)(n-2)(1-s'^2)/s^2 (= 16 pi G rho on the K = 0 slice). For a geodesic ball of radius chi_b = x L,

    dA|_V = -8 pi G int_ball xi(chi) drho dV_0,   xi = L (cos(chi/L) - cos x)/sin x,   any n, any x in (0, pi).

Derivation (areal radius r = L sin th, f_0 = 1 - r^2/L^2, f = f_0 - w, (r^{n-2} w)' = 16 pi G r^{n-1} drho/(n-1)): dV = (Omega/2) int r^{n-1} w f_0^{-3/2} dr, dA|_V = -(n-1) sqrt(f_0(r_b)) dV/r_b; swapping the order of integration, int_{r'}^{r_b} r f_0^{-3/2} dr = L^2 [f_0^{-1/2}]_{r'}^{r_b}, gives dA|_V = -8 pi G (L^2/r_b) int dV_0 drho (sqrt(f_0(r')) - sqrt(f_0(r_b))) = -8 pi G int xi drho dV_0.
Verification: (a) linearised geometry with random regular perturbations (3 profiles, n = 2..7, L = 1 and 2.3, x = 0.2 ... 2.9 incl. x > pi/2): 180 cases, max relative difference 2.35e-30 (30-digit quadrature); (b) fully non-linear (finite eps, root-finding for the fixed volume, central difference): agreement to 1e-33 to 1e-40 at n = 3, 4, 5; (c) uniform density, independent of any weight: dA_V/d(L^-2) from the closed forms of S^3(L') equals -3 L^4 int xi dV_0 identically (sympy); (d) generic axisymmetric non-spherical first-order perturbation (n = 3, conformal factor): identical to 1e-14 (this is expected: the first-order functionals are linear and see only the SO(3)-average of the perturbation); (e) controls: the flat-space weight is off by 21% (x = 2.1) and 12% (non-spherical, x = 1.4), no fixed-V term by 27%, a coefficient 4 pi G is rejected.
Matter side (r03 E6): zeta = [(cos t cos th - cos x) d_t - sin t sin th d_th]/sin x is a conformal Killing vector of R x S^3 with kappa = 1, vanishing on the cap edge, restricting at t = 0 to the weight above and to (l^2-r^2)/(2l) as x -> 0. What is assumed, not re-derived: the CFT modular Hamiltonian of the dS cap is 2 pi times this charge (the conformal image of the flat statement the paper uses), and the state-independent UV term eta A with eta = 1/4G. This is the finite-diamond first law of the (A)dS diamond literature (the paper's appendix D; arXiv:1812.01596, abstract only opened): I claim no novelty, only the explicit exact-radius check and the response function below.

Consequences.
- Einstein's equation holds at every radius in this construction: delta S = dA|_V/4G + 2 pi delta<H_zeta> = 0 <=> 8 pi G-Einstein. There is NO radius where it fails at O(1).
- What does fail is the truncation (7). Response to a uniform density: F_4(x) = exact/small-ball = 1 - (2/21) x^2 + (1/105) x^4 + ...; F_4 = 0.976, 0.914, 0.821, 0.769, 0.812 at x = 0.5, 1, pi/2, 2, 2.5; minimum 0.7626 at x = 2.158; back to 1 at x = 2.751; diverges as x -> pi (weight ~ 1/sin x). ## 3. The Newtonian ball (r05)
- Flat space, spherical matter: dA|_V = -8 pi G int xi rho dV, xi = (l^2-r^2)/(2l). Point mass at the centre: dA|_V/A = -G M/l: the fractional area deficit IS the Newtonian potential (checked against the exact-GR interior/exterior slice of a uniform star at compactness 1e-4 and 1e-6: relative agreement = compactness, i.e. next order). A mass shell on the boundary contributes nothing.
- Additivity (exact for a uniform ball): L_c^-2 = L^-2 + (8 pi G/3) rho_m; Lambda and matter enter ONLY through the total curvature, A_V = A_flat(V) Psi(u), u = l_f/L_c, Psi = 1 - u^2/5 - (3/175) u^4 - (23/7875) u^6 - ... . So Lambda is one more contribution to the curvature; it is not a source with its own scale.
- Non-linear threshold g_*(x) (second-order term = first-order term, boundary Newtonian acceleration g = G M/r_b^2 in units of H): 116.6, 58.1, 18.8, 10.6, 5.70, 3.94, 2.25, 1.29, 0.749, 0.430, 0.220, 0.094, 0.030, 0.0052, 0.00017 at x = 0.05, 0.1, 0.3, 0.5, 0.8, 1.0, 1.3, pi/2, 1.8, 2.0, 2.2, 2.4, 2.6, 2.8, 3.0. Small balls: g_* l = (35/6) c^2, i.e. 2GM/l = 35/3, beyond any physical compactness (Buchdahl 8/9): the linear equilibrium is accurate up to the collapse limit. g_* is a strictly decreasing bijection onto (0, infinity) (g_* = 0.05, 0.3, 1, 10 H at x = 2.519, 2.112, 1.682, 0.525); it equals H/Z at x = 2.262 = 0.720 pi, a radius that is none of the declared ones (nearest, sqrt(8 pi/3), is 22% away; with a post-hoc list the nearest, 3 pi/4, is 4% away, unremarkable: 37% of 60 decoy targets are at least as close).
- Mass = Lambda crossover (Q5): 8 pi G M xi_c = A_flat(V) - A_dS(V), xi_c = L tan(x/2): g_eq -> H^2 R/5 for small x (0.19999 at x = 0.01), with a single maximum 0.1629 H at x = 1.311 and a value 0.1562 H at the equator. At R = 10 kpc, H_0 = 70 km/s/Mpc (illustration only): 3.2e-16 m/s^2 versus cH/Z = 1.2e-10, ratio 2.7e-6. A length-dependent crossover, not a fixed acceleration.
- Structure: A_V is a polynomial in (M/R, R/L) with non-negative powers; g/H = (M/R)/(R/L), so a fixed g/H = q enters as q^k lambda^k (lambda = R/L <= 1): an O(1) function of g/H alone never appears. The equilibrium has no place for a fixed acceleration in the R << L regime.
- Puzzle link, stated plainly: g = a0 at compactness 1 occurs at l = c^2/(2 a0) = Z L/2 (the puzzle's r_s, since g_N(r_s) = kappa), the same statement as the record's r_s > L, not new information.

## What is NOT established
- Only the geometric side and the CFT first law are exact. Non-conformal matter (the paper's extra scalar delta X, which the paper flags as a conjecture and which later work examined; not opened here) and the state side beyond first order (relative entropy is not fixed by the geometry) are not treated. The vacuum IR entropy S_IR(V; L), which would be needed for any Lambda-selecting principle, is not computed (scheme-dependent).
- The non-spherical check is a first-order conformal-sector test; TT tensor perturbations are argued (not scripted) to drop out because the first-order functionals only see the SO(3)-scalar part about the centre.
- The Newtonian non-linear analysis uses a uniform-density ball (exact closed form); the second-order coefficient is profile-dependent (a compact core adds a self-energy term); I did not scan profiles.
- Whether a MOND a0 should be identified with any of Q1-Q3 (thermal or kinematic accelerations) is not decided; only Q3, Q5, Q6 are accelerations relative to free fall.
- Nothing here says why kappa = 1/2. A principle that gave a rational coefficient 4 in G rho_Lambda = 4 a0^2 is neither supplied nor excluded: the equilibrium supplies 8 pi G = 2 pi x 4 (modular temperature x Bekenstein-Hawking quarter) and then only geometry.
