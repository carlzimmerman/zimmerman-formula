Read Can2501.08619v2 PDF page 14 with pdftotext; all six middle-ensemble central values and errors match INPUTS.json. The native momentum weights integrate constant and linear functions exactly. The publication's fit/systematics and missing sea loops are not reproduced or bounded here.
2. Checked that Tr Q=0 does not set Tr Q^2 to zero, and a same-sea-loop covariance can remain in an individual proton while canceling in p-minus-n. This proves an allowed missing contribution, not its numerical size or nonzero expectation.
3. Independently expanded E_L(lambda_L)-E_0(lambda_0) into an intrinsic same-theory difference plus the retuned flat baseline. The extra coefficient cancels identically when the reference uses lambda_L. Applying a total metric derivative to the parameter path is not the physical stress. The torus result is not transported to S4.
4. Re-derived the topology identities from differentiating a common regulated Z with metric-independent integer Q. The mixed derivative includes I_t; dropping it would fail the equality of action mixed derivatives. Checked the Gaussian fixed-Q saddle sign, its H^4 stress baseline, and the conditional H^5 topology-sensitive correction. The theta-independent normalization is invisible to those normalized measurements. This is an information limitation, not an allowed nonlocal counterterm for fixed QCD.
5. Designed an independent moment-system check for the finite-radius observables. It caught the first hand arithmetic error (stress polynomial at E=2 equals 28). Original inputs and failed run were preserved; v2 passes 23 checks. Actual-stress convergence only needs a finite o(H) remainder, while the partition-function conversion additionally needs a differentiated remainder. Both require fixed microscopic parameters across radii and genuine QCD data not supplied here.

The main unresolved dependency is dynamical, not algebraic: the unconditioned curved-space QCD metric functional and its full matched charge response. Flat Compton data and topology cumulants are adjacent observables. No remaining unknown was set by agreement with alpha or the observed vacuum scale.
