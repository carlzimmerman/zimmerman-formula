# Fine structure puzzle

This programme seeks a physical derivation of Thomson-limit alpha without fitting its measured value. [TARGET.md](TARGET.md) defines success. **Alpha and the proposed full QCD ratio remain uncalculated.**

The current assessment is **FSP-009**: [non-Born proton and unconditioned vacuum report](qcd_nonborn_vacuum/REPORT.md), [checkpoint](checkpoints/FSP-009.md), [live status](STATUS.md), [continuation](HANDOFF.md), [evidence pins](CHECKPOINT.json).

New results include a complete finite leading-HB pi-N non-Born photon band, an infrared coefficient filter and full-trace coordinate moment, a contact-complete unconditioned sphere estimator, and an isospin test of a proposed vacuum/proton Ward closure. They are scoped partial calculations. The physical proton response and curved-vacuum expectation values still need actual matched QCD data.
