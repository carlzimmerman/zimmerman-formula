# FSP-N primary source checks

Checked 2026-10-18, America/New_York. No full copyrighted source is copied into this repository. External sources below were accessed through web retrieval; no locally retained full-text hash is claimed.

1. Michele Del Zotto, Jonathan J. Heckman, Piyush Kumar, Arada Malekian, Brian Wecht, *Kinetic mixing at strong coupling*, Phys. Rev. D 95, 016007, published 30 January 2017, [DOI](https://doi.org/10.1103/PhysRevD.95.016007), [accepted manuscript](https://link.aps.org/accepted/10.1103/PhysRevD.95.016007). Authentication: title/authors/DOI from manuscript first page; extraction: Section 2, Eqs. (2.5)-(2.8), kinetic matrix in a charge basis. Translation: K=Im(tau)/(4 pi); CP-even electric terms only. Application: verified setup for FSP-N; no claim that this paper proves N2-N5. This is established notation, not new physics.

2. Joshua Newey, John Terning, Christopher B. Verhaaren, *Schwinger vs Coleman: Magnetic Charge Renormalization*, [arXiv:2407.13823v2](https://arxiv.org/html/2407.13823v2), 21 November 2024. Authentication: arXiv HTML version banner and author header. Extraction: Eqs. (5)-(7), electric and magnetic couplings run inversely with invariant product; the 4 pi convention assigns the integer/half-integer factors to their dimensionless magnetic charge. Application: verified that Dirac quantization is compatible with running rather than fixing its magnitude. Scope: perturbatively controlled effective descriptions discussed by the source; no universal strong-coupling beta function imported.
