# Fine structure puzzle

This programme seeks a physical derivation of Thomson-limit alpha without fitting its measured value. [TARGET.md](TARGET.md) defines success. **The full physical QCD ratio and alpha remain uncalculated.**

Current assessment: **FSP-010**, [hard matching and interacting closed-vacuum report](qcd_hard_vacuum/REPORT.md), [checkpoint](checkpoints/FSP-010.md), [live status](STATUS.md), [continuation](HANDOFF.md), [evidence pins](CHECKPOINT.json).

Full physical proton and smooth curved-QCD expectation values remain missing. Source calibrations, finite model scope, higher matching, review restrictions and failed attempts are explicit.
