4. NEW DYNAMICAL REQUIREMENT FROM THE ACTUAL ACTION
For an interface r=R(t) with no singular surface reservoir:
  [J^r] - Rdot[J^t] = 0,
  J^mu=n^mu rho_Q-lambda P^mu/Q.
Use the full QX17 current. The conserved rho_Q and the full relativistic energy density are not interchangeable.
QX17 E2 sets lambda_in=0 for an exactly stationary inner state aligned with the Killing flow. A stationary interface then requires J_out^r=0. Positive polarization-free inward dust cannot satisfy that condition. This is a restricted exact-current obstruction, not a no-go for moving interfaces or polarized exteriors.
For a moving interface with that stationary interior, the required exterior flux is

This multiplier must also satisfy E2 and the field/stress equations; it is not a freely adjustable sink.
