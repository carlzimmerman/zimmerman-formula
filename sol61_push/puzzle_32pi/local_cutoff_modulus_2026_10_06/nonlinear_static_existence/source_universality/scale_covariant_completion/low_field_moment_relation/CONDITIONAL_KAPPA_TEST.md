# Conditional test of the empirical kappa relation

This is a corollary of the audited source bound and the conditional symmetric covariant dictionary. It does not derive kappa or select32pi. It applies to the same spherical auxiliary response, subject to an admitted covariant extension, the chosen UV normalization, and the vacuum-density convention. Full cosmology and tensor health are unresolved.

In spatial dimension n>=3 let Omega be the unit-sphere area, Gn=8pi(n−2)G_EH/[(n−1)Omega], chi_n=(n−1)/[2(n−2)]. The conventional mass-density vacuum relation is Lambda=8pi G_EH rho_Lambda/c². If the empirical condition a0=kappa c sqrt(Gn rho_Lambda) is imposed, it requires

Lambda c⁴/a0²=8pi G_EH/(kappa² Gn)=2Omega chi_n/kappa².

The candidate's conditional dictionary is Lambda c⁴/a0²=chi_n Cresp, so the required response moment would be Cresp=2Omega/kappa². Combining this with the already proved lambda Cresp<pi²/16 and A²=7lambda/8 gives

lambda<kappa² pi²/(32Omega),
A<kappa pi sqrt(7)/(16sqrt(Omega)).

At n3, Omega4pi, this becomes A<kappa sqrt(7pi)/32. For the supplied kappa=1/2, the necessary source-deficit bound is A<sqrt(7pi)/64 and lambda<pi/512. These are strict necessary inequalities, not parameter predictions or sufficiency tests. A changed kappa changes them explicitly; the target number has entered only as an empirical hypothesis being tested.

A is the asymptotic radial source observable lim[y→0] y^(−1/4)[1−g/(a0sqrt(y))], not a constant-cutoff fit. This offers an extra force-law test if the missing full-theory conditions are established. The construction currently leaves lambda free, so satisfying the bound would not force the target relation. Taking rho to be total density instead would require a different time-dependent cosmological dictionary; the empty coincident-vacuum derivation does not support that replacement. No hbar appears and all units are defined before specializing to four spacetime dimensions.
