Primary-source check: processing stage matters
Shipman et al., arXiv1709.04327v1, sections3.2–3.3:
https://arxiv.org/html/1709.04327v1
Reference subtraction is part of Level1 processing. DBS and fastDBS difference
reference/science phases in doRefSubtract; a dedicated OFF can be removed in
doOffSubtract. Completed Level1 is already processed in that respect.
The preceding Level0.5 integrations can be regenerated interactively.
Therefore 'start with Level1 and stop before doRefSubtract' is not a sufficient
recovery procedure. Need access before the relevant operations, or a verified
retained independent product carrying the missing signal. The paper supports
a route to lower-level recovery; it does not certify this dark-signal response.

Exact information-loss control
Let y be four calibrated raw phase values in REF,ON,ON,REF order. The simplest
ABBA difference is D=(-1/2,+1/2,+1/2,-1/2). A line contributing the same
amplitude A to every phase has response vector a=(1,1,1,1), so D a=0.
For ANY subsequent linear operation T, T D a=0. Regridding, averaging,
stacking or more integration cannot reconstruct this discarded component
from those differences alone. This is a linear-algebra statement about the
specified equal-response case, not a claim that every real instrument phase
must have equal response.

If the actual response is (a_ref,a_on,a_on,a_ref), the retained signal is
(a_on-a_ref)A. The science response must therefore be derived for primary
mirror, optics/chopper, feed, loads, receiver and actual observing sequence.
It is not fixed merely by saying the source is target-independent, nor by
comparing a sky chop angle with an assumed emitted angular width. Different
phases can have different optical transfer, but that needs a calculation.
Frequency-switch phases also change LO mapping and need their own frequency
transfer operator; the ABBA scalar example is not silently applied to all modes.

A line injected AFTER subtraction survives by construction even when its
physical pre-subtraction counterpart lies in the exact nullspace. That test
can validate a downstream line finder, not the end-to-end archival sensitivity.
A useful injection must enter the separate pre-subtraction phases with the
computed relative amplitudes and spectral/LO mappings, then pass through the
actual calibration, subtraction and baseline steps. Excluded responses must
remain failed controls rather than being reintroduced after the filter.

Absolute recovery needs identifiable calibration as well
With unreferenced phases, source signal and unknown channel response/baseline
must be distinguishable. If the admissible nuisance model has an arbitrary
free amplitude in every spectral channel, any narrow line can be absorbed
into that nuisance space; its amplitude is not identifiable. A restricted,
calibrated baseline and independent mode/LO/time/phase checks may retain it.
The source acknowledges strong baselines, but hours alone give no validated
nuisance projection or false-positive control. This does not prove it is
impossible; it identifies the next load-bearing analysis.

Quantified transfer target, not an observed response
Let eta be additional retained POWER fraction relative to the source's S50
forecast, holding its noise model fixed. Since signal power scales as eps^2,
 eps_min(eta)=eps_min(1)/sqrt(eta).
At541.7GHz the source primary reach becomes7.78e-11 for eta=.01,
7.78e-10 for eta=1e-4, and7.78e-9 for eta=1e-6. To reach the supplied
4e-9 converter-window threshold at the same assumed noise requires
 eta > (7.78157e-12/4e-9)^2 =3.78455e-6.
This is a useful acceptance target for a transfer calculation, not evidence
that eta has that value. If eta=0 no finite statistical integration restores
sensitivity. If absolute reprocessing adds noise/systematic floors, they must
also enter the target. The prior CE054 species/response/mass caveats remain:
a portal forecast is not by itself a whole-framework detection or null test.
