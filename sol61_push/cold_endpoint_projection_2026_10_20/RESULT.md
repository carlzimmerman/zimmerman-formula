## Independent test of our actual reference endpoints

This packet does not execute or rerun CFG925. It uses the exact source mass profiles from CFG918 `bb9b20525`: canonical, catalogue B0, G1, C core, phiK=1/lambda_c=1 diagnostics. Draco/Sextans use saved source escape endpoints; Fornax/Leo I use the prior guarded >=2R receiver snapshots. Source JSON copies are byte-pinned in `inputs/` and traced to their original paths by `sources.json`.

Project the spherical potential generated by the source's Plummer stars, truncated retained component, C core with scale 104 pc and cutoff R, and two receiver shells. No extra application of the modified law is made. Masses and shell radii are held fixed. This is a static equilibrium-moment diagnostic, not a construction of a distribution function or an achievable trajectory.

For normalized tracer nu(r), projected aperture A, and its enclosed light fraction L_A, isotropic Jeans and projection give

    sigma_ap^2 = (4 pi / (3 L_A)) integral_0^infinity
                   nu(r) g(r) r^3 W_A(r) dr,
    W_A(r) = 1                              for r <= A,
             1 - [1 - (A/r)^2]^(3/2)       for r > A.

For a Plummer tracer of scale a, x=r/a and X=A/a, this becomes

    sigma_ap^2 = G/(a L_A) integral_0^infinity
                   x (1+x^2)^(-5/2) M_enc(a x) W_X(x) dx.

At infinite aperture it is the global luminosity-weighted virial moment, independent of anisotropy for a steady spherical tracer with vanishing boundary-pressure term. The finite half-light aperture here assumes beta=0. Source elliptical geometry, observed member weighting, binaries and uncertainties are not fitted.

## Conditional C-profile stock ceiling

Keep the baseline stars/tether and normalized C shape fixed. Every receiver shell lies at r >= R. Moving receiver mass into that C core increases enclosed mass pointwise; the projection weights are nonnegative. Thus putting **all available free stock** into the C core, with no receiver left, gives an optimistic global upper ceiling for every member of this core-plus-outer-shell family.

For Sextans the fixed baseline contributes 5.453896 (km/s)^2 and the reference core contributes 42.162802 (km/s)^2 at mass 25.104737 million solar masses. Consequently:

    Core-only equivalent for global sigma=7.9: 33.913021 million solar masses
    Available free cold stock:                 25.395764 million solar masses
    Core-only equivalent / available:          1.33538
    Global sigma with ALL free stock in C:      6.93581 km/s

The 33.913021-million-solar-mass number excludes receiver gravity. It is a core-only equivalent, not a minimum core mass when receivers contribute. Because C maximizes the response per unit free mass over this family, it also gives a lower bound on total required free stock. The original run_003 field name incorrectly called this a minimum core mass; `semantic_correction.json` supplies correctly named values without rewriting the raw completed run.

This ceiling already spends the outflow receiver. No collision mechanism can repair that particular global/profile mass mismatch merely by reallocating the same stock between this core shape and outer shells. A more concentrated/different inner profile, changed supply, changed observational inference or another branch requires a new declared calculation. The two-population Sextans stock issue from the earlier packet remains an additional, separate conditional concern.

At finite aperture the inference changes. For example, the existing Sextans endpoint predicts 8.417 km/s inside R_e rather than 6.900 globally. That makes aperture selection a prerequisite for inferring a new core/outflow partition. It does not authorize replacing the 1.15% escape fraction with a larger number while retaining the old energy/angular-momentum ledger.
