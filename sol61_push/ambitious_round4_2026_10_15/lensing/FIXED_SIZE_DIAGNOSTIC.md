# Fixed-size and common-size post-data follow-up

After the four-size diagnostic yields nominal p=.00652, test the same
self-consistent Plummer source at fixed physical radii 0, 5, 10 and 20 kpc,
each shared by all four bins. This set was independently suggested by root
before receiving that result. Also test one common fitted radius in [0,.3] Mpc
with one extra nuisance (nine total, nominal 51 dof). These are descriptive
post-data profile diagnostics, no primary selection or revised closure test.
Fixed runs retain four masses and four NNLS biases with the previous four
starts, independent least-squares, actual cold-stock edge and full covariance.
Common run uses four starts. The projected density and exact stock controls
are inherited from the pinned extended-profile result; direct evaluation of
the environmental template at fitted edges must agree within .5 chi².
Compare zero-size against the refined baseline within .01 chi².
