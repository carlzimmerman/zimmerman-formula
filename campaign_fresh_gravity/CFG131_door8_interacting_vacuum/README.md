## Bottom line

**A scoped no-go.** Under H1-H4 (GR; Lorentz-invariant vacuum T = -rho_L g; Q^mu = Q(rho_L, rho_c) u_c^mu; one cold perfect-fluid congruence; baryons coupled only through gravity) the door either FAILS G1 and G2 or is INERT in the halo. Gates: **G1 FAIL, G2 FAIL, G3 pass only trivially (reaction zero) and FAIL on energy beyond x_cap = 6.29, G4 FAIL, G5 pass as stated.**

## What was derived (sympy, on explicit metrics)

1. **Covariant equations (D1).** nabla T_c = +Q u, nabla T_vac = -Q u. Because a Lorentz-invariant vacuum has nabla_mu T^{mu nu} = -nabla^nu rho_L, the exchange forces **d_mu rho_L = Q u_mu**: the vacuum is uniform on the hypersurfaces orthogonal to the cold fluid and N = -rho_L'(t)/Q. With the fluid's Euler equation this gives **c_s^2 = (rho + p) Q_rho/Q**; for dust, Q_rho != 0 forces rho_c to have no spatial gradient. For Q = xi rho^n rho_L^m the forced EOS is p = n rho/(1-n) + C rho^n. At linear order in Newtonian gauge the residual is exactly **Q_rho (drho + rho' v) = Q (dp + p' v)/(rho + p)** (Q_Lambda drops out): for dust, delta rho_com = 0. Control MUTATE=2 (vacuum given a spatial gradient) breaks the dust theorem.
2. **Background (D2).** In CFG43's action E_T reads Mp2 Lambda' = 0 for any rho(n; Lambda) (re-derived), and Lambda' = dl/dT0 for any explicit T0 term: **Q != 0 needs explicit T0 dependence, which breaks the HT shift symmetry; Lambda is then a dynamical field, not a global constant.** For the only cold-safe entry, Q = xi H_L rho_L (a function of Lambda only), closed form a0(z)/a0(0) = 1/(1 + xi sqrt(rho_L0/3)(t_z - t0)/2), checked against the integrated background to 1e-14. **The flat a0(z) law survives only for |xi| < 0.0275** (1% at z <= 5); at |xi| = 0.3 a0(2.5) is 10% off. Reported (not gated) theta_* proxy: D_m shifts by 0.029% per 0.01 of xi.
3. **Growth (D3).** Sub-horizon: delta_c' = -theta - a Gamma (1 - n) delta_c (Gamma = Q/rho_c, n = rho Q_rho/Q), Euler unchanged (Q u carries no force), solver validated against CFG43's 0.140 / 0.099 / 0.080. (R1) dust with Q_rho != 0: cold source vanishes, total growth ratio 2.7e-3. (R2) the Q-consistent fluid needs c_s^2 <= 1.7e-8 (k = 0.5), 1.0e-9 (2), 4.2e-11 (10), 4.6e-12 (30) for 5% growth to z = 0 (1.5e-7 ... 4.3e-11 at z = 10), while the target requires c_s^2 = V_f^2/2c^2 ~ 2e-8 (1e9 Msun) to 6e-7 (1e12): **4.3e3 above the bound at k = 30**. (R3) Q = Q(Lambda) alone leaves growth within 5% for |xi| < 0.106 (dilution + background shift). (R4) with the target's own EOS the growth ratio is 0.877 to 0.002 at k = 0.5..30; restricted to the target's own density range and read at z = 10 it is still <= 0.16 at k = 30 (values below zero mean an oscillating Jeans regime).
4. **Locality (D1, deliverable 4).** Exact hypothesis: Q depends on rho_L (uniform on the fluid slice) and the local rho_c only. Then p(rho_c) is one function in every halo at one epoch. The target's required p at fixed rho is not: **p_req proportional to M^(1/2) (deep) ... M^1 (Newtonian)**, so between 1e9 and 1e12 Msun it differs by 32-272x (point mass, exact), 32-353x (exponential sphere, h = 2 kpc), 27-48x (h scaled with M^(1/3)); the pass line is 1.10. Control MUTATE=1 (EOS as a function of rho * r_M(M_b(<r)), the enclosed mass hand-fed) collapses the point mass exactly (ratio 1.00), but NOT the exponential sphere (15.9, 9.6), because p depends on the mass outside r (CFG44's far-shell theorem). **A5: in a stationary halo (rho_t = 0, no net flux) the energy equation forces Q = 0**; Q can act only in time-dependent phases, which is a formation-history statement and is not computed here.
5. **G3 (D4).** The baryon equation contains no Q: non-gravitational reaction = 0 (a pass that costs nothing). The heating component of Q^mu is zero. Rest mass the target needs beyond the cosmic share (Omega_c/Omega_b = 5.36) exceeds all the vacuum energy in the baryons' Lagrangian volume (Omega_L/Omega_b = 13.9) beyond **x* = 20.2** (f = 1.70 at x = 30), and Lambda is uniform on the fluid slice so a0 would fall by sqrt(1 - f): circular. For x <= 6.29 no conversion is needed (Q does nothing); beyond it the demand is ~1e6-1e8 times the orbital energy (independent of r_ta).
6. **G4.** New constants: xi (amplitude, untied), C (EOS integration constant), and n if Q_rho != 0 (tuned below 5e-12). None tied to kappa or Lambda.
