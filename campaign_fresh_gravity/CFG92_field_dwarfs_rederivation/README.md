**Causes of the differences (post hoc, after reading the CFG58 .out; no frozen number changed).** (1) Error recipe: CFG58 uses np.std with ddof = 0 and takes the Upsilon floor from the endpoints {1, 4}; the frozen spec used ddof = 1 and {1, 2, 4} (from CFG91's reading). This explains the whole sigma difference, mainly on the alt footing. (2) Omega_m: CFG58's switch-off masses need Omega_m = 0.3134 (hunt_lib's OM_M); the frozen CFG91 value 0.3153 gives the 1% offsets. **With both fixes** (Omega_m = 0.3134, ddof = 0, endpoint floor): L -0.60 / -0.85 sigma, S -3.47 / -2.69 (CFG58 -2.70, to 0.01 sigma), S in L's error -1.43 / -1.27, statistic-C S +1.02 / +1.12 (CFG58 +1.02 / +1.13; the S offset differs in the frozen run because the frozen spec put no collapse-mass floor in that error). The statistic-C data-side reading (regressor y nu(y), MW 6.0e10 and M31 1.2e11 host masses, distance_gc / distance_m31, rhalf_physical, log M_b) was fixed against a non-CFG58 target (`k_contrarian_dwarfefe.out`, six printed numbers reproduced); nothing about L or S was tuned.

**Which dwarfs dominate.** Five have f_ex = 0 and S = L exactly (Sgr dIrr at M_b 2.35e7, just above the switch-off; Leo A, WLM, IC 1613, NGC 6822); eight sit below it and drop by 0.046 to 0.205 dex (their median goes from L +0.051 to S -0.090). The five above sit at -0.12 under both L and S, so the S median is a mix at the boundary, not a uniform shift; it is set by Aquarius, UGC 4879 and Sgr dIrr, and leave-one-out moves the change from 0.042 to 0.097 dex. Dropping Antlia B changes little (S -0.107, -3.29 sigma).

**Sensitivities (field dwarfs, S offset with sigma in S's own error).** Error recipe: -3.39 (frozen), bootstrap -3.94, Upsilon propagated into the halo -1.96, further variants -2.05; alt with Upsilon propagated -1.75 / -1.89; Upsilon_V = 1 with the halo propagated -1.37. **Under any propagated-Upsilon recipe the significance is -1.75 to -2.1 sigma; the S offset itself stays -0.085 to -0.119 dex: robust in size, not in significance (the same pattern CFG91 found for the LVD).** Concentration: Duffy 200c full -0.085 (-2.10 / -2.21 sigma), relaxed -2.64 / -2.33, Duffy 200m applied to a 200c mass (the inconsistent A1 row) -4.03. Kernel: P2 -0.094 (-3.10 / -2.39). Estimator: the k_contrarian estimator (2/9 nu G M_b / r) gives S -0.084 to -0.086 (-1.99 to -2.12 sigma). The Moster clamp never touches the 13 dwarfs (smallest M_* 2.7e5). Statistic C: Moster clamp moves Delta slope from +0.006 (clamp 1e10) to +0.027 (1e8), S +1.27 to +0.82 sigma; Duffy 200c full Delta slope 0.004; the FG001 estimator doubles it to 0.027; it passes under L and S in every row and is weakly constraining (slope error 0.047 against a Delta of at most 0.03).

**Finding not in CFG58 (post hoc, `post1_crossings.py`).** S switches off only within a window: for M_* = M_b/2 it is off from 2.3e7 to about 2.2e11 and f_ex turns on again above that; for M_* = M_b the window is 5.6e7 to 8.4e10. This is CFG35's massive-spiral failure, so 'S = L for every population above 2.3e7' holds only for the populations CFG58 scored (M_b up to about 1e10).
