# CFG575 FROZEN CRITERIA — outer Milky Way HI velocity dispersion decides CFG574

(owner chat 10-09, "yes find the outer disc HI dispersion"). Committed alone BEFORE any literature value is read.

CFG574 required dispersions (primary, gas at the observed flaring, A = 1, R = 10–30 kpc):
 RM-φ/RM-v 6.80–6.91 / 6.90–7.01 km/s (canonical/alt); PD 8.97 / 9.29 km/s; Newtonian baryons alone 5.77 km/s.

What counts as the measurement: a published effective (thermal + turbulent) HI vertical/line-of-sight velocity
dispersion for the Milky Way disc gas at R ≈ 10–30 kpc, from the source text/tables (fetched, never recalled),
as a single value or a radial profile averaged over 10–30 kpc, with its stated uncertainty σ_m. If several
independent measurements exist, each is scored separately and all are reported; none is dropped.
 If no uncertainty is stated, σ_m = 1.0 km/s is assigned (declared now).
 Multi-phase decompositions: the mass-weighted effective dispersion is used if the paper gives one; otherwise
 the warm-phase (WNM) value, with the cold phase reported but not scored.

Decision per measurement s ± σ_m (using the footing-averaged requirements RM 6.9, PD 9.1, Newton 5.8 km/s):
 z_X = |s − X| / σ_m.  RM FAVOURED if z_RM ≤ 2 and z_PD > 2; PD FAVOURED if z_PD ≤ 2 and z_RM > 2;
 NOT DIAGNOSTIC otherwise. Newton-only is reported (z_N) but not a candidate.
Overall: the call shared by all scored measurements; mixed calls → CONFLICTING (reported as such).
Disclosed: a σ that varies with R trades against the dark component (CFG574 assumed constant σ); a measured
gradient is reported and flagged; non-thermal (magnetic/cosmic-ray) pressure is not modelled. κ fitted; cold
energy's mass required; not theory closed.
