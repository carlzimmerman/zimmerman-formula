# CFG917 ADDENDUM A1 (2026-10-20, POST HOC): the frozen K3b tested a wrong premise; replaced by K3b′

Committed before any Part B number of T1x, T2x or NC2x was computed. FROZEN_CRITERIA.md (0289e4ad4) is not edited. Every pair is
reported BOTH ways: the class as frozen and the class under this addendum, labelled.

**What happened.** The first Part B run (NC1x vs NCS0, normal mode) failed gating test K3b: "the CMB-marginalised fiducial-correction
values equal Σ_L M_b(L) X_L^FFP10 to ≤ 2% per band" — the actual ratio M·X_FFP10 / F_b runs from 0.60 (band 1) to 0.995 (band 9). As
frozen, a failed gating test makes the class NOT DIAGNOSTIC, and K3b is a property of the Planck files only, so it fails for every pair.

**Seen before this addendum:** NC1x Part B, MUTATE and normal outputs (all other K tests PASS, MUTATE bites; the class-rule value is
CONSISTENT), Part A for NC1x, T1x and T2x, and the diagnostics below. No Part B number of T1x, T2x or NC2x.

**Mechanism (diagnostics on the files on disk, post hoc, scripts in the scratch area; reproduced by `cfg917_amendment_A1.py`):**
- The NON-marginalised PS1 dataset's fiducial correction equals the full linear-correction windows (TT, EE, TE, PP columns) applied to
  the FFP10 lensed CMB spectra plus FFP10 PP to 1e-4 in every band: FFP10 is the correction's fiducial and the windows are read correctly.
- The CMB-marginalised dataset keeps only the PP column of those windows; its constant is F_marged = M_PP·X_FFP10 + M_CMB·(C_FFP10 − C_ref),
  i.e. the CMB-spectrum part of the correction is frozen at a CMB reference spectrum C_ref of the package's construction and absorbed into
  the constant (F_PS1 − F_marged = M_CMB·C_ref is 0.3% below M_CMB·C_FFP10 in band 1). K3b omitted the second term. This is the package's
  definition of the CMB-marginalised likelihood, not an implementation error here.
- The likelihood code reproduces the package's own unit-test values end to end: −2 ln L = 8.3724 vs 8.368 (CMB-marginalised, K3e) and
  8.7094 vs 8.705 (with CMB spectra, PS1 dataset, A_planck = 1).

**Replacement K3b′ (gating, data-only, no run enters):** (i) the PS1 fiducial correction = the full correction windows applied to the
FFP10 lensed CMB + PP spectra, ≤ 2% per band; and (ii) this lane's likelihood code reproduces the package's PS1 unit-test value 8.705
(CAMB 1.6.6 at the unit-test parameters with halofit "mead", exactly as the package's test; code-test input only, as K3e) to ≤ 0.15.
Nothing else changes: model, data, statistic, robustness set, classes, other K tests and MUTATE are as frozen.

**Disclosed consequence.** The CMB-marginalised constant carries a CMB reference spectrum from the package's (ΛCDM-based) construction.
It is shared by both arms (a constant offset in every bandpower), so it moves absolute χ² of F and S0 alike; it is added to the ΛCDM
dependence list.

(`cfg917_A1_classes.out/json`); the frozen per-pair JSONs are not rewritten.
