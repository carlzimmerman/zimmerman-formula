# Overnight lessons, 2026-09-28 to 09-29: what the audits found and what caught it

Process only; no physics claim. Every item is traceable to its commit or ledger row. Nothing here says the theory is closed.

1. **README claims that the code does not support.** CFG55's README says nu_mono and L ~ D^2; the numbers come from the RAR kernel and M_JAM ~ D (CFG76). CFG61's README says M_true = M_gal(1+f); the code shifts grid nodes, so the f_hot ladder does not reproduce (CFG77). CFG49 said 'acceptable at m2 <~ 1e-16' where its own H3 prints zero passing values; CFG41 called a 27% over-prediction 10%. *Safeguard:* independent re-derivations with a frozen spec and an in-place re-run (CFG73, 76-78, 84-86); the README-versus-output audit (AUDIT-L, AUDIT-P).
2. **Kernel mislabels.** Several lanes use the exponential RAR kernel while their text says nu_mono (CFG64, confirmed by CFG76). *Safeguard:* the kernel-robustness lane (CFG64) and a kernel note on each affected README.
3. **A silent sample bug.** h50 looks up 'NGC720' in a dict keyed 'NGC0720', dropping NGC 720 and NGC 821 (CFG76). *Safeguard:* an independent sample count from the raw table, compared with the lane's.
4. **Run-order dependence.** CFG69's MUTATE output read a results file that only the main run writes. *Safeguard:* `CFG69_run_all.sh` (main first), a README sentence, outputs regenerated in order.
5. **Frozen criteria missing, late or shared.** CFG44's gap-2 frozen file was untracked and reused an ID; CFG48/63/71 froze in the same commit as their scripts; CFG57's script was untracked after its freeze. *Safeguard:* freeze committed alone before the script (CFG61/62/67/68/79-81), a git-log ordering audit, and an append-only ledger with numbering checked before each push.
6. **Circular comparators.** CFG32's g_obs is Humphrey's fitted NFW+stars model; CFG34's stars come from M500_HSE; CFG63's C2e is circular by construction. *Safeguard:* circularity quantified rather than asserted (CFG84: form matching plus a cancellation; CFG85: the stellar-level test).
7. **Post-hoc rows and controls.** CFG61's 3.7 sigma chi2 row, CFG69's R3 and CFG40's MUTATE factor were added or changed after a first run. *Safeguard:* each labelled post hoc and reported beside the frozen result; failed controls kept (C5, N1b, T5a, C1e, P2, K2).
8. **Controls that cannot fail.** MUTATE exit codes are uninformative when the main run also exits 1 (CFG53/55/61/68); CFG78's MUTATE exits 0; the CFG69 gate-fail control was not met. *Safeguard:* a 'does the control have bite' check per lane, and the reading rule that an unmet control is reported, not repaired.
9. **The verifier did not check what it claimed.** `verify_chain.sh` ignored 'error' lines (42 unknown names slipped through). *Safeguard:* hardened and tested with a bogus name; false-statement mutations of each Lean module.
10. **Stale conclusions.** CFG42's 'closes the largest failure', CFG45's '6/7', CFG59's binding pair, CFG52/54's canonical-only bottom lines. *Safeguard:* supersession pointers, the STANDING and PAPER37 corrections, and `PAPER37_audit.py`, which pins every quoted number to a committed source (548/548; it caught the stale Lean count).
11. **A verdict stronger than its acceptance level or its inputs.** 'No universal phi' holds only at 1 sigma per population (CFG75); the SLUGGS sigmas hold at a fixed globular-cluster slope gamma = 3 that the disk data cannot test (CFG76, CFG82). *Safeguard:* state the acceptance level and the fixed input next to every verdict.
12. **Coordination.** Ledger truncation by an overwrite pattern, lane-number collisions, another session's working-tree edits. *Safeguard:* read-assert-append-verify for the ledger, `ls | grep CFG` before each push, and never committing another session's modified files.
