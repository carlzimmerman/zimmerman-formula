# CFG77 -- independent re-derivation of the KiDS-1000 early/late colour-split chi2 (CFG61, CFG67)

**Question (frozen before any headline number: `CFG77_FROZEN.md`).** Does CFG61's early-minus-late chi2 for the colour-blind law (28.1 / 7, p = 2.1e-4), the f_hot ladder (28.1, 18.2, 10.0, 4.8, 4.1 at f_hot = 0, 0.25, 0.5, 1, 1.5) and CFG67's LCDM control (6.5 / 7) reproduce from independently written code (own lensing projector, kernel, turnaround solver, stacking; kernel nu_mono; canonical and alt footings)?

**Result: the headline numbers reproduce exactly; the f_hot ladder does not reproduce to its printed digits.**
| quantity | CFG61 / CFG67 | CFG77 |
|---|---|---|
| law chi2, canonical / alt | 28.1 / 7 | 28.074 (p 2.13e-4) / 28.075 |
| LCDM control chi2, Ahat | 6.5 / 7, 0.79 | 6.535 (p 0.479), 0.789 +/- 0.164 |
| LCDM with early and late swapped | 124.1 | 124.16 |
| Sersic law chi2 / all-15-bin law chi2 | 20.9 / 124 | 20.92 / 124.29 |
| absolute K1 chi2, law (early, late) / LCDM | 51.9, 12.6 / 29.6, 27.9 | 51.9, 12.6 / 29.5, 27.9 |
| f_hot = 0.25 / 0.5 / 1 / 1.5 | 18.2 / 10.0 / 4.8 / 4.1 | 17.61 / 10.58 / 4.08 / 5.09 (within about 1 chi2 unit) |
| f_hot = 2 / 3 / 4 | 10.4 / 26.9 / 58.4 | 11.8 / 38.3 / 78.3 (diverges) |

**Cause of the ladder difference (post hoc).** The CFG61 README says M_true = M_gal (1 + f_hot); the CFG61 code instead shifts the M_* grid node by a whole number of 0.05-dex steps and takes that node's profile with its own gas fraction and edge, so the effective mass ratio is below 1 + f (the cold-gas fraction falls steeply with mass) and f_hot is quantised. Implementing that reading gives 28.06, 18.04, 9.69, 4.50, 4.50, 12.51, 32.44, 69.71 at f_hot = 0, 0.25, 0.5, 1, 1.5, 2, 3, 4: close through f_hot = 1.5, a residual of up to about 11 at f_hot = 4, not chased. Two other readings (hot gas as an extra point mass on an unchanged law; the pair radius taken from M_true) do not reproduce it at all. The best f_hot is about 1 to 1.5 (minimum chi2 about 4.1), but the law is acceptable (p > 0.0027) already from f_hot of about 0.25 to 0.5, so 'needs at least about 1 to 1.5 times stellar plus cold mass' is qualitatively fine and quantitatively soft.

**What drives the result (the useful part).**
1. **The law chi2 is a pure data statement.** The law's predicted early-minus-late difference on the seven 1-halo bins is tiny (|D_L|/sigma_D < 3.3e-3; the law at fixed g_bar gives the same Delta-Sigma for any mass). The zero-model chi2 (D_obs^T C_D^-1 D_obs) is 28.085 against the law's 28.074, so 28.1 means 'the released early and late profiles differ at fixed g_bar' and would hold for ANY colour-blind model. The test does not discriminate among colour-blind models.
2. **The M* floor and the IMF rescales do not enter the law chi2** (early M* +/- 0.1 dex moves it by 0.02; x0.7 or x1.5 by at most 0.03); they matter only for LCDM (chi2 5.45 to 11.50 over the same range; Ahat error 0.164 statistical, 0.48 with the floor). The isolation cut and lens mix do not enter it either (sub-samples by z and mass give 28.06-28.08); real isolation and satellite contamination cannot be re-cut from the file and are untested.
3. **What it does depend on.** The K1 bin set (seven bins 28.07/7; bins 6-14 41.65/9; bins 8-11 alone 12.2/4, p = 0.016; the contribution is concentrated in bins 11, 12 and 14, and dropping bin 11 or 12 leaves about 20/6). The error model: the released covariance is essentially diagonal (cross-class correlation about 0.003) and contains no systematic terms (intrinsic alignments, satellites, photo-z, colour-class contamination); inflating all errors x1.2 gives 19.5 (p = 6.7e-3), x1.5 gives 12.5 (p = 0.086), x2 gives 7.0 (p = 0.43). **The 3.7 sigma is therefore fragile to modest unmodelled scatter.** The colour proxy differs between the lens file (rest-frame u-r > 2.0) and the data (GAaP u-r >= 2.5), which cannot affect the law chi2 but can affect LCDM.

**Controls (6 of 6 pass).** K1 covariance (solve = Cholesky = inverse = 30x30 transform to 1e-8; 15-bin split 119.93 / 69.07 against 119.9 / 69.1); K2 projector (SIS k/(4R) to 6.5e-12, NFW against Wright and Brainerd to 6e-6, point mass exact; K2 first failed because the agent's own reference formula was incomplete, fixed and all re-run); K3 the law's Delta-Sigma at fixed g_bar is mass-independent (2e-7 at g = 1e-13); K4 grouped stacking against exact per-lens on 400 random lenses (1e-6; a full-sample coarser grouping gives the same 28.074); K5 swapping early and late (law 28.07 to 28.10, LCDM 6.54 to 124.16); K6 MUTATE (early M* and M_gal x2): LCDM moves 6.5 to 55.8 and the law only 28.074 to 28.001, as declared. numpy prints spurious divide-by-zero and overflow warnings in the T C T^T matmul (an Accelerate quirk); the result matches the other three routes.

**Scope.** The agent did not exec or import CFG61/CFG67 code; it read FP1_static_sector.py (nu_mono), the a0 footings, the Dutton-Maccio and 200m-to-200c recipe and the Mandelbaum table to build its own versions, and afterwards two lines of CFG61's R4 code and its `stack` docstring to diagnose the ladder. The result is a non-rejection of the pipeline; the law's failure of this split reproduces, and it is a failure any colour-blind model shares. Nothing here says the data favour the framework. kappa = 1/2 is FITTED.

Run in `CFG77_kids_rederivation/`: `python3 cfg77_run.py` (about 6 min, rc 0); post-hoc diagnostics `cfg77_cov_attack.py`, `cfg77_fhot_alt.py` ... `cfg77_fhot_alt4.py` (each writes its .out). Re-run in place; output identical to the agent's apart from timing.

## Referee correction (round 2; appended, the text above is unchanged)
- 'The law chi2 is a pure data statement any colour-blind model shares' is too strong. What CFG77 shows is that the law's chi2 equals the zero-model chi2 (28.085 against 28.074) because its predicted early-minus-late difference at fixed g_bar is negligible (the law's deep regime, shared by the bare MOND law). Halo models in which lensing mass grows with M* -- colour-split or colour-blind Moster -- do fit (6.5/7 and 6.9/7, CFG67), so the difference is B-specific relative to that comparator; it is fragile to modest unmodelled scatter (errors x1.5 give p = 0.086), and the 3.7 sigma is a reported post-first-run chi2 row. 'A failure any colour-blind model shares' should read 'a failure any model with a negligible predicted difference shares'.

## Portability and control-exit-code notes (from the equations chat's re-run of CFG75-99; appended, no result changed)
- **Absolute input paths.** The script reads its inputs through a hard-coded absolute path into the live repository tree, so a clean checkout at another location fails until the path is derived from `__file__` (or the repo root); the fix is pending the user's permission to edit the scripts (a batch edit was declined), and the numbers are unaffected.
- **Git-ignored inputs.** The script needs the git-ignored `real_research/data/lensing_rar/` inputs (the Brouwer+2021 RAR tables under `brouwer2021_rar/` and the lens catalogue `lr_lenses.npz`); they are on the author's disk and are not in a clean checkout. Nothing was fetched.
