**Why.** CFG829/846: at the dwarfs' g_bar (10^−13.3–10^−11.9 m/s²) red (gas-poor) isolated lenses sit +0.20 dex above the law,
blue ones on it. Path 1 of the Codex review (running as CFG848) predicts relaxed STRUCTURE carries the excess, not colour.
B21 provides both splits of the same isolated sample: colour (u−r 2.5) and Sérsic index (n = 2).

## Statistic (CFG829's loader and amplitude, unchanged)
- A ± σ_A over the law in the window, canonical a0, ν_e, for: blue, red (colour bins); disc-like n < 2, spheroidal n > 2 (Sérsic bins).
- Splits: Δ_colour = A_red − A_blue, Δ_Sérsic = A_sph − A_disc, each with σ = quadrature of the two σ_A.
- **STRUCTURE CARRIES IT** if Δ_Sérsic ≥ 3σ AND Δ_Sérsic ≥ Δ_colour.
- **COLOUR CARRIES IT** if Δ_colour ≥ 3σ AND Δ_colour > Δ_Sérsic + 1σ (combined).
- **BOTH / DEGENERATE** if both splits ≥ 3σ and within 1σ of each other (the two labels overlap too much to separate).
- **NO SPLIT** otherwise. Alt footing reported.
- Caveat stated in advance: colour and Sérsic classes overlap heavily in the same galaxies; B21 gives no cross-classified bins, so
  this lane can rank the two labels but cannot fully separate them.
