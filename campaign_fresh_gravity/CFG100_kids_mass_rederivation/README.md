# CFG100 -- independent re-derivation of CFG110 (KiDS: does the lensing signal at fixed g_bar depend on lens stellar mass within a colour class?)

**Question (frozen: `cfg100_FROZEN.txt`, sha256 4c89e883..., before any run; also the script docstring).** Do CFG110's headline numbers reproduce from independent code: B's mass-independence chi2 = 22.2 / 14 (p 0.075), colour-split LCDM 25.2 (p 0.033), the colour-blind Moster rejection 105 / 14, and the power row R0 = 8.8 (below the threshold 9)? And is 'B gets mass-independence right' more than a non-detection? **Independence limits (declared):** the per-lens KiDS sums come from `cfg110_perlens.npz`, the on-disk product of CFG110's staging pass (git-ignored under `real_research/data/lensing_rar/`; the agent did not re-stage from the 17 GB shear catalogue); control K1 checks that per-(patch, class, bin) sums reproduce the June file (3e-11) but cannot see a mis-assignment of pair sums between lenses of the same patch and class. It read the ESD normalisation lines (KG and the jackknife formula) of `agentK_jackknife_stack.py` by grep; it did not open, run or import any CFG110 script, .out or JSON, so the comparison is against the README numbers only. Run with `ZF_REPO` set to the repository root; the scripts contain no hard-coded paths.

The omnibus test detects LCDM-size dependence only 41% of the time and half-size only 11% (Neyman-Pearson equal-error rate for B versus LCDM 7%). Amplitude fits (D - D_B = A (D_shape - D_B); statistical error only): colour-split LCDM A-hat = 0.33 +/- 0.34 (one-sided 95% upper limit 0.89; A = 1 disfavoured at 2.0 sigma; with M* +-0.1 dex A-hat 0.21, limit 0.64-0.69, 2.7-3.0 sigma); Moster 0.02 +/- 0.11 (limit 0.20). **Wording tests declared before the run:** W1 (B not rejected, p > 0.01) true; W2 (data exclude LCDM-size dependence) true; **W3 (data exclude half of LCDM-size dependence) FALSE**; 'B gets mass-independence right' was allowed only if W3 held, so it is not allowed. What the data support: B is not rejected and mass dependence at LCDM's size is disfavoured at about 2 sigma (statistical); half-size dependence is not excluded. Where the power sits: against LCDM the late class carries 6.2 of lambda = 8.8 (70%), no single bin dominates (dropping any one leaves lambda between 6.8 and 8.6; bins 9 and 10, late class, larger radii, carry the most), and LCDM predicts a negative late-class D in all seven bins (-4 to -10; not diagnosed); against Moster the early class carries 67 of 86.7 (78%), in the four largest-radius bins. Detectable amplitude at 80% power: LCDM shape 1.45 (omnibus) and 0.95 (1-dof); Moster 0.46 and 0.30. Pair-weighted model stacks (weights from the data's own WW): chi2_B unchanged 22.2, LCDM 26.5 (p 0.0225), Moster 97.3, and lambda(L-B) rises to 10.35 (above the 9 threshold); both models still pass.

**Sensitivity.** Error inflation x1.2 / x1.5 / x2: B 15.4 (p 0.35) / 9.9 / 5.6; power against LCDM 0.28 / 0.18 / 0.11; Moster p 6e-10 / 2e-5 / 0.024 (marginal). Mass-split edges (the splits are not independent, so the range is a fragility measure): median (main) B 22.2 (0.075), LCDM 25.2 (0.033); q33/q67 22.2 (0.075) / 21.7 (0.084); q40/q60 28.5 (0.012) / 20.5 (0.12); q25/q75 25.7 (0.029) / 38.4 (0.0005); median -0.1 dex 31.6 (0.005) / 27.1 (0.019); median +0.1 dex 21.8 (0.082) / 35.4 (0.001): **B's p ranges 0.005 to 0.08, and the B-versus-LCDM ordering flips with the split**; Moster is rejected everywhere (chi2 55-105). Bin sets: the data are driven by late-class bin 9 (D = +9.6 +/- 3.9); dropping it gives B 13.85/12 (p 0.31) and LCDM 6.6/12 (p 0.88), so LCDM then beats B; dropping bin 8, 13 or 14 puts B at p 0.03-0.04 on 12 dof; the four highest-g bins alone: B 9.0/8, LCDM 5.7/8, Moster 30/8.

**Controls.** All 9 pass on the main run and 3 of 3 on MUTATE: K1 sums; K2 partition, medians, K1 bins; K3 projector; K4 deep-regime independence; K5 grouped versus exact per-lens; K6 covariance algebra; K7 null (200 random halvings: mean chi2 13.77 against 14); K8 swap (B 22.20 to 22.21; LCDM 25.2 to 44.8; Moster 105 to 90.6); K10 power machinery. MUTATE (early-class M* and M_gal x2): B 22.20 to 22.22 (alt 22.198 to 22.215), Moster 105 to 397, LCDM 25 to 57. Both runs exit 0 (the checks assert the expected changes), so the exit code does not discriminate the control. numpy prints spurious matmul warnings (the Accelerate quirk CFG77 also saw); K5, K6, K10 confirm the results are unaffected.

**What the agent would attack.** (1) The wording: 'B gets mass-independence right' should read 'B is not rejected and LCDM-size mass dependence is disfavoured at about 2 sigma'; quote the 1-dof amplitude (A-hat_L = 0.33 +/- 0.34) as the sharper statistic, not the omnibus p = 0.075. (2) The result is non-discriminating between B and colour-split LCDM: both are within p >= 0.005 for every reasonable split, their order reverses with the edges or by dropping bin 9, and R0 = 8.8 against the threshold 9 is razor-thin (pair weights give 10.35). (3) Only the colour-blind Moster rejection is robust (through the bin set and error inflation up to x1.5); it is not robust in size to the stellar-mass calibration (49 to 230) or to M200c versus M200m (79 versus 105), and it rests on the Moster mapping as coded, a shared dependency. (4) The jackknife error model has no photo-z, intrinsic-alignment or satellite terms; the null (mean 13.77, sd 5.69 against about 5.3 expected) shows only that statistical noise is calibrated. (5) Shared inputs: the staged per-lens product is untested beyond sum level, the model stacks use M_gal weights, and the M* calibration dominates LCDM's amplitude.

Nothing here says the data favour the framework; kappa = 1/2 is FITTED.
