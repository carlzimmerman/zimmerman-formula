# CFG221 — the frozen decision rule for the pooled z > 3.5 two-sided test, and its operating characteristics on mocks

- **Criteria:** `FROZEN_CRITERIA.md` = 46df63032 + Addendum 1 70fff09bb (a MARGINALISED gas-calibration prior declared from the literature spread, and the CFG234 / CFG220 planning inputs) + Addendum 2 cde8112c9 + Addendum 3 5398e74b9 (a prior-width sweep, frozen after the noise-free control failed and before any power table was read). Every one was committed before the rule or the mocks were run on anything. **κ = ½ is FITTED, NOT DERIVED.** Nothing here says the data favour a framework.
- **The rule (v1, as frozen):** class-A detections only, outermost MEASURED radius; per cell (2 kernels × 2 footings) and law a *marginal bootstrap* of the discs in which the shared gas offset τ_k ~ N(0, σ_k²) (σ_dust = σ_CO = 0.30, σ_[CII] = 0.40 dex) is redrawn in every resample; DISFAVOURED-under / -over / NOT from the marginal 95% CI of the median δ; FLAT-SEPARATED or RIVAL-SEPARATED only if the status holds in all four cells and after dropping any one disc.
- **Run:** `cfg221_decision_rule.py` (172 cells × 100 mocks, about 3 minutes on 16 cores; `MUTATE=1` runs the response control), `cfg221_prior_width.py` (Addendum 3: the noise-free diagnostic and the sweep), `cfg221_bootstrap_size.py` (post hoc), `cfg221_plot.py`. **Controls: C1 PASS, C4 PASS, MUTATE PASS, C2 FAILED (reported below).**
- Mocks: the six CRISTAL detections' z, radius and baryon errors at R_out (CFG219's template), resampled to N; truth generated with (ν_mono, canonical), the other three cells being mismatched by construction; REAL = the 0.25 dex per-disc scatter CFG220 measured (an extra 0.21 dex on log D). **Sign convention:** c is the true offset of the MEASURED gas mass (measured = true × 10^c), so c = −0.3 means the measured gas is 2× too low and the baryons are under-counted.

## Bottom line

- **The frozen rule can support the flat law but essentially cannot support the rival; it is one-sided in practice.** REAL scatter, true offset c = 0, P(correct separation) at N = 6 / 13 / 20 / 30 / 36 / 50: **flat truth 0.24 / 0.71 / 0.91 / 0.94 / 0.96 / 1.00; H(z) truth 0.08 / 0.10 / 0.13 / 0.12 / 0.13 / 0.07.** With c drawn from the prior: flat 0.27 / 0.57 / 0.70 / 0.80 / 0.78 / 0.77, H(z) 0.08 / 0.19 / 0.21 / 0.25 / 0.23 / 0.26. Without the extra scatter (OPT) the rival side is still ≤ 0.21 at every N.
- **NOT FEASIBLE up to N = 50** by the frozen definition (P(correct) ≥ 0.8 for both truths at c = 0): the best min over the two truths is 0.13.
- **Why the rival side fails, in numbers.** In the noise-free mock with H(z) true the flat law's δ is +0.30, but its marginal CI lower edge is only +0.00 to +0.07 dex above zero in the cells printed by the diagnostic; a shared baryon-mass offset moves δ_flat by 0.73 per dex (0.70 to 0.87 across the six discs) against 0.59 (0.58 to 0.65) for δ_rival, because the flat law is tested at higher g_bar/a₀, nearer the Newtonian regime, so its marginal half-width (about 0.24 dex) is wider than the rival's (about 0.19) for the same prior. Any noise then tips one of the four cells or one of the leave-one-out fits below 0. With flat true the rival's upper edge sits at −0.14 to −0.26, so the flat side has margin.
- **False separation is controlled (C1 PASS):** the WRONG-separation rate is at most 0.01 at c = 0, ±0.30 and c from the prior, for every N, both truths, both scenarios. Outside the prior it is still small: at c = +0.60 (measured gas 4× too high) the rival-true mocks wrongly return FLAT-SEPARATED 5 to 7% of the time.
- **The noise-free control C2 FAILED:** with no measurement noise, no extra scatter and c = 0 the correct separation occurs in 6 of 12 (truth, N) cases in the main run (6 of 12 again in the diagnostic on a fresh stream, where FLAT truth passes at every N and **H(z) truth fails at every N**) (in the diagnostic one cell reads NOT-DISFAVOURED at N = 6, 13, 30 and the leave-one-out fits fail at N = 20, 36, 50). This is the same thin margin, not an arithmetic error: C4 (the machinery reproduces CFG220's headline cell to 8e-17) and the MUTATE control pass.
- **How well must the gas calibration be known? (Addendum 3 sweep, REAL, c = 0; min over the two truths):** σ scale 1 (0.30 dex): best 0.14, not feasible. **Scale 0.5 (σ_dust = σ_CO = 0.15 dex): FEASIBLE at N = 50 only** (flat 0.96, rival 0.82; at N = 13 / 20 / 36: rival 0.47 / 0.56 / 0.74), false separation controlled. **Scale 0.33 (0.10 dex): not feasible (best 0.68 at N = 36)**: the power then saturates at 0.6 to 0.8 because the four-cell requirement meets the kernel/footing spread (three of the four cells are mismatched to the generating law), a floor the calibration cannot lower. **σ_required = 0.15 dex on the gas mass, with about 50 outer-radius class-A discs.** That is half the on-disk spread of adopted conversions (0.29 dex).
- **Real-data ILLUSTRATION (the six CRISTAL detections at table R_out; not blind, no verdict, σ_dust = 0.30, B = 10,000): NO-SEPARATION in all four cells** (flat NOT-DISFAVOURED, rival NOT-DISFAVOURED with upper edges +0.05 to +0.13), consistent with CFG220.
- **Sensitivities:** REAL27 (0.27 dex total scatter, CFG234's route scatter): flat truth 0.97 at N = 36 (c = 0), rival 0.08. MISMATCH (truth generated with P2, alt): flat 0.96 at N = 36, rival 0.07. Extra pair flat vs horizon (REAL, c = 0): flat truth 0.91 at N = 13 and 0.98 at N = 20, horizon truth 0.33 and 0.37; at c = −0.30 (gas under-counted) the horizon truth reaches 0.79 and 0.78. **Post hoc bootstrap size** (`cfg221_bootstrap_size.py`, B = 2000 against the frozen 500, K = 100): flat 0.90 / 0.99 / 1.00 and rival 0.11 / 0.18 / 0.15 at N = 20 / 36 / 50 at the frozen width; at scale 0.5 the rival side is 0.64 / 0.83 / 0.86: the picture does not change.

## What this means

- As frozen, a NO-SEPARATION verdict from this rule is uninformative about worlds in which the rival is true (it returns NO-SEPARATION about 87% of the time there), while FLAT-SEPARATED would be informative (a wrong FLAT-SEPARATED is under 1% inside the prior). The rule is a test that can only disfavour the rival H(z) a₀(z) if the flat law is true; it does not have the power to disfavour the flat law.
- Making the z > 3.5 test a fair two-sided test needs the shared gas calibration known to about 0.15 dex on the gas mass (multi-tracer gas masses whose conversion errors are independent, dust plus CO plus [CI], would give σ/√K) and about 50 class-A discs with velocities out to R_out; the kernel/footing spread then sets a floor near 0.6 to 0.8 for a rule that demands all four cells.
- A more symmetric rule would be a NEW frozen version, committed before any real value beyond the six CRISTAL detections is read (this version's results are kept). Options not run here, only named: a one-sided marginal bound, a primary-cell verdict with kernel/footing as reported robustness, B = 10,000 in every run. Each would be judged by the same controls, C2 in particular.

## Limits and disclosures

- The operating characteristics describe THIS rule on THIS template (six CRISTAL-like discs resampled, one tracer class, R_out geometry), not any real sample.
- K = 100 mocks per cell: probabilities carry a binomial error of about ±0.05 (the non-monotone rows of the sweep are within it); the frozen B = 500 adds Monte Carlo noise to the CI edges (sensitivity above).
- The extra scatter (0.21 dex, total 0.25) comes from six real discs and is uncertain by about ±30%; the calibration widths are declared, with the from-memory ranges marked unverified in Addendum 1.
- C2 failed and is reported as it is: it is a control of the rule, and it fails because the rule is conservative, not because of arithmetic.
- The illustration on the real discs is not blind (CFG220 analysed them) and enters no verdict.

## Addendum 4 — v2, the SECONDARY rule: results (criteria `FROZEN_CRITERIA_V2.md`, e0a9be1b4, committed before v2 was run on anything)

**Outcome, against the frozen controls (`cfg221_v2.out`, 88 cells x 100 mocks, B = 10,000, 1,648 s on 16 cores):** C2 PASS (10/10), C4 PASS, **C1 FAIL**, **C3 (MUTATE) FAIL**. v2 is a SECONDARY rule with these operating characteristics and nothing more; **v1 governs any headline and both verdicts are always shown side by side.** The orchestrator's stop rule was "if v2 also fails C2, record that and stop": v2 passes C2, so it stands as a recorded secondary; no v3 is iterated.

- **C2 (noise-free, c = 0) PASS:** v2 returns the correct separation at every N in {6, 13, 20, 36, 50} for both truths (FLAT truth -> rival under, flat not; H(z) truth -> flat over, rival not); all four cells agree and the leave-one-out survives in every one of those ten. This is the control v1 failed (6 of 12).
- **Power at REAL scatter, c = 0 (P(correct separation), N = 6 / 13 / 20 / 36 / 50):** FLAT truth v2 0.81 / 0.98 / 0.98 / 1.00 / 1.00 (v1 0.24 / 0.71 / 0.91 / 0.96 / 1.00); H(z) truth v2 0.39 / 0.51 / 0.73 / 0.69 / 0.85 (v1 0.08 / 0.10 / 0.13 / 0.13 / 0.07). FEASIBLE (P(correct) >= 0.8 for both truths at c = 0) at **N = 50** (v1: not feasible up to 50). The wrong-separation rate at c = 0 is at most 0.04.
- **C1 false-separation control FAILS:** the frozen bound is a wrong-separation rate <= 0.094 at c = 0, +-0.30 and PRIOR for every N and both truths; the worst is **0.15 (H(z) truth, c from the prior, N = 50)**. For the H(z) truth the wrong (FLAT-SEPARATED) rate is 0.13 / 0.12 / 0.10 / 0.13 / 0.10 at c = +0.30 and 0.06 / 0.06 / 0.08 / 0.13 / 0.15 with c drawn from the prior (N = 6 ... 50). For the FLAT truth it is <= 0.03. The shared gas-calibration offset does not average down with N, so the rate does not fall as N grows; a rival-true world whose shared gas mass is over-estimated by about 0.3 dex (a factor 2) is read as FLAT-SEPARATED about 10 to 13% of the time, and 10 to 15% at the prior width.
- **Outside the prior the rule can be confidently wrong:** at c = +0.60 (gas 4x too high) the H(z) truth is wrongly read FLAT-SEPARATED 0.44 / 0.43 / 0.57 / 0.68 / 0.84 (N = 6 ... 50) and essentially never correctly (0.00 to 0.01); the FLAT truth keeps only 0.54 to 0.65 correct at c = -0.60 and 0.15 to 0.56 at c = +0.60.
- **C3 (MUTATE: D x 1.5 into the noise-free FLAT-truth mock) FAILS:** the primary cell still reads flat NOT-DISFAVOURED / rival under (FLAT-SEPARATED) at every N, because the marginalised calibration prior (sigma_dust = 0.30 dex on the gas mass) lets the free gas offset absorb a +0.18 dex shift. The post hoc size scan (`cfg221_v2_mutation_size.py/.out`, reported only) shows what happens beyond that: **x2 and x3 make v2 read the OPPOSITE separation (RIVAL-SEPARATED: flat over, rival not) at every N**, x5 and x10 read NO-SEPARATION (both over). v1 reads NO-SEPARATION at x2, RIVAL-SEPARATED at N <= 20 and NO-SEPARATION at N = 36 and 50 for x3, and NO-SEPARATION at x5 and x10. **A gross error beyond the calibration prior therefore reads as the rival separated for both rules; the rule checks the propagation, not robustness to a gross systematic.**
- **Reported robustness (REAL, c = 0, of the mocks with the CORRECT v2 separation):** FLAT truth: all four cells agree in 66/81 (N = 6), 92/98, 92/98, 99/100, 100/100 (N = 50) and the leave-one-out survives in 54/81, 96/98, 97/98, 100/100, 100/100; H(z) truth: cells 33/43, 45/53, 66/75, 63/71, 78/86 and leave-one-out 14/43, 43/53, 63/75, 62/71, 77/86. At N = 6 a separation is not robust to dropping one disc (H(z) truth 14 of 43).
- **Sensitivities:** OPT (smaller scatter, c = 0): FLAT 1.00 at N = 13 and 36, H(z) 0.80 / 0.97. MISMATCH (truth from P2, alt): FLAT 1.00 (N = 20) / 0.98 (N = 36), H(z) 0.56 / 0.70. Prior width scale 0.5 (sigma_dust = sigma_CO = 0.15 dex), c = 0: FLAT 0.89 / 0.94 / 0.97 / 0.99 and H(z) 0.81 / 0.91 / 0.98 / 0.95 at N = 13 / 20 / 36 / 50; with c from the (narrower) prior H(z) 0.68 / 0.80 / 0.94 / 0.84, wrong rate 0.02 to 0.07.
- **Illustration on the six real CRISTAL detections (R_out, not blind, no verdict, sigma_dust = 0.30, B = 10,000): v2 NO-SEPARATION in all four cells** (flat NOT-DISFAVOURED, rival NOT-DISFAVOURED), the same reading as v1 and CFG220.

**What this adds and what it does not.** v2 is a more symmetric test than v1 (the rival-true side is reachable: 0.85 at N = 50 against v1's 0.07), it buys that with a one-sided 5% bound and a single primary cell, and the price is that it is not false-separation controlled against a shared gas offset of 0.3 dex or more in the rival-true direction (C1 fails). Reading a v2 verdict therefore requires the gas calibration to be known to better than the prior width, which is the same requirement CFG219 / CFG220 / Addendum 3 found (about 0.15 dex on the gas mass); with the prior at 0.15 dex the wrong rates fall to 0.02 to 0.07. A description of THIS rule on THIS template (six CRISTAL-like discs resampled to N), not a claim about any real sample; K = 100 mocks per cell (binomial error about +-0.05); kappa = 1/2 is FITTED, NOT DERIVED; no sentence here says the data favour any law.
