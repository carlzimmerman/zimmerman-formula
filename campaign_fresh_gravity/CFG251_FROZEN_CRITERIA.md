## 1. Definitions

- **The target** (door-11 gates, erratum 1): g_tot = ν(g_N/a₀) g_N, with a₀ = κ c √(G ρ_Λ). Equivalently, for spherical baryons, CFG44's C(r) = ρ_c r³ g_tot = (a₀/4π) M_b(<r). For a point mass (x = r/r_M, r_M = √(GM/a₀)) the dynamical mass is M_dyn/M_b = √(1 + x²), and the dark part is M_c = M_b(√(1 + x²) − 1).
- **Compaction:** whatever the passage leaves behind. To count, it must produce the target around baryons.
- **One time:** each place (reading i) or each system (readings ii and iii) is crossed once. After the crossing the medium is gone from it, and only a stored imprint remains. Gate T3 asks what stores it.
- **One direction:** the passage has a direction n̂, unless a reading declares the imprint isotropic. In that case the reading must say that it has dropped the directional content.
- **The medium** has no rest mass and is not a particle (door-11 addendum 2). It may still carry energy and stress, and each reading states what gravitates.
- **The cold component (T4, Ω_c h² = 0.1200)** stays as in candidate B unless a reading passes G2 without it (door-11 addendum 2).

## 2. Readings (scored separately, never pooled)

**(i) A cosmic front.** One front sweeps the universe once, from one direction n̂, at speed v_f relative to comoving observers.
- The compaction is set where and when the front crosses matter, from the matter present at that moment.
- Sub-cases on the medium's role, scored separately:
  - **(i-own):** the compaction is the ONLY source of extra gravity, as the owner's picture is stated.
  - **(i+T4):** the cold component is kept as in candidate B (door 11's default), and the front supplies only the law's galaxy-scale phantom.
- Sub-cases on speed:
  - **(i-L):** v_f ≤ c, causal.
  - **(i-S):** v_f > c, superluminal. The limit v_f → ∞ is a constant-time slice, i.e. initial data on a slice.
- **Declared passage epoch.** The primary front is the earliest one allowed: it starts at t = 0. MUTATE=1 puts the passage at z_pass = 1.

**(ii) A per-system passage at formation.** Each bound system is crossed once, at its formation (collapse or virialisation), from one direction, and the imprint is set then.
- **(ii-flat):** the imprint uses a₀ = κ c √(G ρ_Λ) at that epoch. Because ρ_Λ is constant, this means no dependence on the formation epoch.
- **(ii-epoch):** the imprint depends on the formation epoch. That dependence is a new declared function, and G4 prices it.
- If "formation" is read as the system's first turnaround, (ii) is the same as (iii-a). If it is read as any collapse, (ii) is the same as (iii-b). Each identity is stated, not re-scored. (ii) is scored on its own only at T4.

**(iii) Set once at first decoupling from the Hubble flow, then frozen** (the owner's addition 1).
- **(iii-a), primary.**
  - A system receives its compaction once, when that system itself first turns around from the Hubble flow. That is B's switch criterion T3(i), Δ(<r) ≥ Δ_ta(z) (`CFG4_README.md`).
  - A system that forms inside an already turned-around parent never decouples from the Hubble flow on its own, so it receives none.
  - An accreted system keeps what it received.
- **(iii-b), variant.** A pass happens at ANY collapse, including collapses inside an already turned-around parent: tidal-dwarf formation, star-cluster formation, star formation.
- **Three sub-readings of the AMOUNT,** scored separately under H3:
  - **(A1) literal freeze:** the amount is keyed to M_b(<r) at the system's turnaround and is never updated;
  - **(A2) advected:** the compaction is carried by the crossed baryons and moves with them;
  - **(A3) label only:** the pass fixes only WHICH systems own a compaction. The amount follows today's baryons through B's law.
