  Sums per (patch p, class c, bin k):  S[p,c,k] = sum over lenses.  ESD(subset, k) = sum_p WG / sum_p WW / KG,  KG = 1.98847e30/(3.0857e16)^2  [Msun/pc^2].  Cross ESD_x = sum WX / sum WW_all / KG (the
  cross uses the all-source weights, no separate cross weight is staged).  K1 = the 1-halo bins where the lens-median R = sqrt(G Mgal/g_centre) of BOTH classes is < 0.3 Mpc (expected {8..14}, 7 bins).
  Data vector for a null: D = ESD(early) - ESD(late) on K1 (7 numbers).  Near/far statistic: D_nf = D_near - D_far (7 numbers).  Each class's cross profile: ESD_x(c, K1) (7 each).
  Whole-sample cross: ESD_x over all lenses, all 15 bins.
COVARIANCE.  Leave-one-patch-out, N = 50: for each statistic vector v the sample v_(-p) is formed from the sums with patch p left out, ESD recomputed; C = (N-1)/N sum_p (v_(-p) - mean)(v_(-p) - mean)^T;
  Hartlap h = (N - n - 2)/(N - 1), n = length of the vector (7 -> 40/49; 14 -> 34/49; 15 -> 33/49); chi2 = h v^T C^-1 v with n dof; p-value = chi2 survival function with n dof.  Errors quoted: sqrt(diag C), no h.
AMPLITUDE (my reading; CFG110's R2b definition is not known to me).  PRIMARY V1: A = log10[ sum_{k in K1} w_k ESD_early,k / sum_{k in K1} w_k ESD_late,k ] with fixed weights w_k = the full-sample
  sum over all lenses (both classes) and all patches of WW_all,k (the same w for near, far, all and for every jackknife sample); central value from the full sample; error = jackknife sqrt((N-1)/N sum (A_(-p) - mean)^2).
  Variant V2: each class's K1-pooled ESD, A = log10[(sum_K1 WG_e/sum_K1 WW_e)/(sum_K1 WG_l/sum_K1 WW_l)].  Dilution (per class): A_dil = log10[sum w ESD_far / sum w ESD_near] with the same w (V1) and the V2 analogue.
  Far share of pair weight: sum_K1 WWf / sum_K1 (WWn + WWf) per class.  If V1 and V2 differ from CFG116's digits in different ways, both are reported; V1 is the reproduction line.
POWER ROW R0 (printed first, before any cross-shear or near/far null number).  Ingredients: D_t = the all-source early-late tangential difference over K1.  Two readings:
  R0-A (the null's own covariance, the correct power computation): lambda_x(eps) = eps^2 D_t^T P_x D_t, P_x = h C_x^-1, C_x the jackknife covariance of the cross difference; lambda_nf(eps) = eps^2 D_t^T P_nf D_t, C_nf the
    covariance of D_nf (a near-source-only systematic carrying eps of the tangential split shifts D_nf by eps D_t).
  R0-B (the reading of CFG116's frozen sentence 'from the tangential jackknife covariance'): lambda = eps^2 D_t^T h C_t^-1 D_t with C_t the covariance of the tangential early-late difference (= eps^2 x the all-source split chi2).
  eps = 0.25, 0.5 (and 1.0, and 0.10, 0.75 for the A rows).  'Expected chi2' = 7 + lambda; the printed CFG116 numbers (9, 2.2, ~3) are matched to lambda or to 7 + lambda -- BOTH are printed and which one matches is reported.
  Power = P(ncx2(7, lambda) > chi2 critical for alpha = 0.01, and 0.05).  1-dof amplitude-fit power: shape s = D_t, residual r, A_hat = s^T P r/(s^T P s), sigma_A = (s^T P s)^-1/2, one-sided 95% upper limit
  A_hat + 1.645 sigma_A; detectable eps at 80% power, alpha = 0.01: omnibus 7 dof (root of ncx2 power) and 1 dof ((z_0.995 + z_0.8) sigma_A).
