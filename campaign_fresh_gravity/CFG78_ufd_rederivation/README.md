# CFG78 -- independent re-derivation of CFG46's binary-corrected ultra-faint result

**Question (declared before the first run).** Does CFG46's result reproduce from independently written code? The bare law's median offset +0.295 +/- 0.163 (1.81 sigma) at f = 0, +0.206 (1.26 sigma) with f free, +0.171 (0.99 sigma) at f = 0.7, and the sum rule's -0.151 (-1.17 sigma), on the eight scorable Arroyo-Polonio+2026 ultra-faints.

**Result: it reproduces (all medians to 0.0005 dex, all errors to three decimals, alt-footing medians +0.275 / +0.186 / +0.150), with the weakness that the error recipe is inherited.** The agent read the whole CFG46 script, so agreement on the errors (bootstrap, measurement draw and a floor in quadrature) confirms the code, not the recipe. Kernel: the exponential RAR (CFG64 says it agrees with nu_mono to 3e-9 for y <= 0.1), not nu_mono re-implemented. Stars only, Upsilon_V = 2, half the baryons at r = (4/3) r_half, sigma^2 = g r/3. The rule number is an independent implementation of the CFG35/CFG7/h48 formulas (Moster inversion clamped at 1e9, Dutton-Maccio NFW, x_e = 0.40, own LCDM top-hat solve).

**Controls passed.** Newtonian limit (machine precision) and deep-MOND limit (2e-16) in closed form; hand-sorted median = numpy on 1000 arrays; the exact bootstrap over all 8^8 resamples (std 0.1239 / 0.1115 / 0.1172 for f = 0 / free / 0.7) against the 2000-draw MC (within 0.2%) and a 2e6-draw MC (within 0.01%); the MUTATE shift identity (every offset and median moves by exactly log10(0.5), 1e-12). **Leave-one-out:** no system drives the median (largest shift 0.012 dex). **Weights (reported only):** inverse-variance medians move by at most 0.013 dex; the unweighted means are 0.05 to 0.10 dex higher (+0.365 / +0.284 / +0.248).

**Disclosed defect:** the MUTATE run exits 0, not 1: its mutation checks were written as 'must not reproduce' (which they satisfy) and no check was made to fail the exit code. H1 and H2 already fail in the main run (as in CFG46), so they cannot show that the control has bite; only the reproduction check and H3 (the rule, -0.452 = -3.5 sigma under MUTATE) have bite. Cosmetic: dead code (`if False`) in the MC loop.

**What the agent would attack.** (1) The bootstrap and the measurement draw are added in quadrature though the bootstrap already contains measurement scatter (a double count), and a 0.076-0.077 dex floor comes from the Upsilon_V range. (2) The significance is set by the median; the offsets are luminosity-ordered (Boo I ~ 0, Car II / Hyd I / Leo V +0.15 to +0.28, Ret II / Seg 1 / Wil 1 +0.4 to +0.65), which looks like a luminosity or Upsilon_V systematic, not a flat offset; untested. (3) The rule's -0.151 is a clamp artefact: 7 of 8 systems get the clamped collapse mass 1e9, so the rule's floor is 0.013 here against CFG42's 0.133; with 0.133 the rule's total error is about 0.185 and z about -0.8, so -1.17 sigma understates the uncertainty. (4) The binary correction is model-dependent (a solar-neighbourhood distribution on single-epoch data), the three f columns are correlated, and the 8 systems are a subset of the paper's 12.

**Scope.** An internal check that CFG46's arithmetic is right; not evidence for or against the framework. Both the law and the rule sit within about 1.8 sigma of zero on these eight systems and cannot be separated. kappa = 1/2 is FITTED; nothing here says the theory is closed.

## Portability and control-exit-code notes (from the equations chat's re-run of CFG75-99; appended, no result changed)
- **Absolute input paths.** The script reads its inputs through a hard-coded absolute path into the live repository tree, so a clean checkout at another location fails until the path is derived from `__file__` (or the repo root); the fix is pending the user's permission to edit the scripts (a batch edit was declined), and the numbers are unaffected.
- **Exit codes.** The main run and the MUTATE run both exit 0 with empty failure sets (disclosed above); the informative signal is the reproduction check and H3 (the rule), not the exit code. The script header's 'MUTATE exit 1 intended' does not hold.
