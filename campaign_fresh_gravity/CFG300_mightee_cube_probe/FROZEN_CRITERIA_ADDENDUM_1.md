# CFG300 — FROZEN CRITERIA, ADDENDUM 1 (written before any cube voxel was read; one design correction, no change to the targets, cuts, measurements or hand estimates)

**MUTATE=1 as frozen is badly designed for T1.** The criteria say the line window is shifted by +300 km s⁻¹ and that no target should then have a ≥ 5σ detection. The line window is ±(W50/2 + 50) km s⁻¹; for T1 (W50 = 392) that is ±246, so a +300 km s⁻¹ shift leaves the window at [54, 546] km s⁻¹, which still overlaps the line (the emission spans about ±196 km s⁻¹): the expectation could fail for a reason that is my design, not the pipeline. **Correction (before the first data run): the window centre is shifted by +(W50_cat + 150) km s⁻¹ for each target, i.e. by the velocity half-width of the cutout** (T1 +542, T2 +317, T3 +251 km s⁻¹), which puts the window in the line-free edge channels for every target. The expectation (no ≥ 5σ detection for any target) is unchanged. The synthetic SELFTEST (S5) was run with the same rule. MUTATE=2 is unchanged.
