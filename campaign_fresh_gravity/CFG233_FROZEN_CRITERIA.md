**Consequence stated in advance (for the README):** the statistic uses D_obs = V_c^2/V_bar^2 and g_bar = V_bar^2/R_e, i.e. delta = log g_obs - log g_bar - log nu(g_bar/a0). Every model choice in V_bar (gas scaling, M* zero point) and in V_c (pressure term, inclination) enters as a z-dependent shift, and the test cannot tell such a shift from a z-dependent a0. Algebra (frozen, checked by MUTATE M6): with g_bar -> k g_bar at fixed V_c, delta -> delta - (1 - s) log k, with s = -dlog nu/dlog y between 0 (Newtonian) and 0.5 (deep MOND), about 0.3-0.4 at the sample's typical y. With V_c^2 -> p V_c^2 at fixed V_bar, delta -> delta + log p (exactly, g_bar unchanged).

## 5. Definitions frozen (the README does not fix these; declared before any number)

- **Sample:** rows with finite z, R_e, V_c and 0 < f_DM < 1; n and exclusions counted.
- **Quantities:** D_obs = 1/(1 - f_DM); g_obs = V_c^2 / R_e (V in m/s, R in m); g_bar = (1 - f_DM) g_obs; y = g_bar / a0_L(z); flat a0 = A0_f, rival a0 = A0_f E(z), Omega_m = 0.315.
- **delta_L = log10(D_obs / nu(y_L)),** nu in {nu_mono (primary), P2}; footings canonical (decides) and alt (reported).
- **Theil-Sen slope:** median of (delta_j - delta_i)/(z_j - z_i) over all pairs with z_i != z_j (the scipy convention); no intercept or CI from scipy; own code.
- **Bootstrap:** resample the 100 galaxies with replacement, N = 10,000, seed 233 (main) and 234 (stability); CI = percentile 2.5 / 97.5; sigma = SD of the bootstrap slopes. (A BCa variant is reported beside it, never substituted.)
- **z-scores:** (obs slope - expected slope) / sigma, sigma the bootstrap SD of the observed slope, exactly the README's construction; the referee's alternative (joint bootstrap of obs minus expected, the expected slope recomputed on each resample) is reported beside it.
- **Expected slopes:** for each truth law T, invert g_obs_i = g_bar_i nu(g_bar_i / a0_T(z_i)) for g_bar_i by bracketed root-finding (monotone for both kernels), set D_i = g_obs_i / g_bar_i, and compute delta_L with that D and g_bar under each measuring law L; Theil-Sen slope vs z.
- **Halves:** split at the median z; the low half is z <= median (ties stay low).
- **Levels:** median delta with a bootstrap 95% CI; label = "over" if the CI is above 0, "under" if below, "consistent" if it contains 0.
- **Variant (d):** g_bar,geom = the radial acceleration at R_e of a razor-thin exponential disc of mass M_bar and R_d = R_e / 1.678: g = (2 G M / R_d) y^2 [I0(y)K0(y) - I1(y)K1(y)] / R_e with y = R_e / (2 R_d) (Freeman); D_ind = g_obs / g_bar,geom; delta = log10(D_ind / nu(g_bar,geom / a0_L)).
- **RC41 identification:** RC41 IDs with "_" replaced by " ", exact string match to RC100 `name`; the three unmatched are listed.
- **Errors used in the mocks and in the systematics (declared, data-informed):** sigma(log M_bar) and sigma(f_DM) are the medians of the RC41 table's own `logMbar_lo/hi` and `fDM_lo/hi` over the 38 matched galaxies, computed in the run and printed; V_c error 5% (declared, no per-galaxy value exists in the table); intrinsic scatter of log D about the law: the value that makes the flat-truth mock's total scatter of delta equal the observed scatter of delta_flat (declared calibration, and 0.10 dex reported as an alternative).
- **Gas model (attacks a, b):** M_bar = M*(1 + mu(z)). The table gives only M_bar, so M* = M_bar / (1 + mu_auth(z_i)) with mu_auth declared two ways: **(G1)** the OLS fit of log10(M_gas/M*) on z from the 38 matched RC41 galaxies (their own `logMgas`, `logMstar_SED`), evaluated at every RC100 z; **(G2)** the surrogate mu = 0.25 + 0.35 z, clipped to [0.1, 1.3]. G1 is primary; G2 is a sensitivity. Offsets applied to the true gas: mu_true = c * mu_auth * 10^(t (z - z_med)), grid c in {0.25, 0.5, 1, 2, 4} x tilt t in {-0.30, -0.15, 0, +0.15, +0.30} dex per unit z (25 cells); "plausible band" = c in [0.5, 2] and |t| <= 0.15. Propagation at fixed V_c and fixed M*: k = M_bar,assumed / M_bar,true (the analysis's assumed baryon mass is the table's, the true one is M*(1 + mu_true)); the re-decomposed quantities are those that the true M_bar would give: g_bar,true = g_bar,table / k and f_true = 1 - (1 - f_table)/k; rows where f_true falls outside (0, 1) are counted and excluded, and the count is reported per cell.

## 6. The attacks (frozen procedures, pre-declared N and seeds) and what pass / fail mean

**(c) The expected-slope computation.** Re-derive s_R and -s_F from the definition (section 5) for: kernels nu_mono, P2 and the simple kernel nu = 1/2 + sqrt(1/4 + 1/y) (sensitivity, labelled); footings canonical and alt; and the definitional alternative in which the observed g_bar is held and the law's g_obs re-predicted (hold-g_bar). Then: (c1) dependence on the g_bar distribution and mass range: s_R and -s_F in M_bar terciles, in g_bar terciles, and for the sample restricted to g_bar < 3 a0 and < a0; plus the analytic deep-MOND limit (0.5 dlog E/dz on this sample's z) as the ceiling; (c2) the uncertainty of the slope difference: joint bootstrap (N = 10,000, seed 233) of (obs slope - expected slope) with the expected slope recomputed on each resample, against the README's constant-expected version; (c3) noise propagation: Monte Carlo (N = 4,000, seed 233) redrawing z (sigma_z = 0.01), f_DM (RC41-median error), V_c (5%), R_e (5%) and recomputing both the observed and the expected slopes; report the SD of (obs - expected). Correlated errors: D_obs and g_bar share (V_c, f_DM); analytic check that d delta / d f = (1 - s)/((1 - f) ln 10), i.e. the shared error reduces, not doubles, the sensitivity (a naive independent-error treatment overstates it by a factor of about sqrt(1 + s^2)/(1 - s)).
- **Pass/fail meaning:** the README's expected slopes **hold** if s_R and -s_F reproduce within 0.005 and the joint-bootstrap z-scores stay within 0.5 sigma of the README's; the 5.5 / 4.9 sigma is **not robust to the expected-slope definition** if any of {P2, simple kernel, alt footing, hold-g_bar} changes either tension by more than 1 sigma. State which.

**(d) The sign of the unexplained negative flat slope (62 non-RC41).** (d1) Reproduce -0.055 [-0.099, -0.007] and the rival's -0.112. (d2) Selection: the slope in the 62 under M_bar cuts (log M_bar >= 10.0, 10.3, 10.6), z-range trims, f_DM windows, g_bar < 3 a0; KS tests of the (log M_bar, log g_bar, R_e, sigma_0) distributions of the 62 vs the 38 by z-tercile, as a proxy for z-dependent completeness (the actual selection function of the sample is not in the table). (d3) RC41 definition: repeat with the RC41 set identified by (z within 0.01 and log M_bar within 0.05) instead of by name, to see if the split moves. (d4) Regression-to-the-mean / EIV: (i) the slope of delta on log g_bar and on log M_bar (Theil-Sen, N=10,000) and the partial z-slope of delta after removing its dependence on log g_bar (Theil-Sen of the delta residuals on z), which tests a kernel-shape-times-g_bar(z) origin; (ii) flat-truth mocks on the 62 galaxies (their real z and g_obs) with the section-5 errors and three declared selection rules: none; keep only mocks with observed g_bar inside the observed range; drop f_DM_obs < 0.01; N = 4,000, seeds 233 and 234. Analytic hand check: with noise eps in log g_bar the delta shift is -(1 - s) eps, so a z-slope arises only if E[eps | z] != 0, i.e. only through selection on an observed quantity or a z-dependent mismatch of the prior mean; the regression on log g_bar (not on z) has attenuation -(1 - s) sigma_eps^2 / (var(x) + sigma_eps^2), which I report but which is NOT the z-slope.
- **Pass/fail meaning:** the negative slope is **explained** (labelled selection/EIV) if a declared mechanism gives a mock slope <= -0.027 in >= 50% of mocks; **partly explained** if it gives one in [-0.027, -0.010); otherwise **unexplained (kept)**. Also stated: whether the sign belongs to the analysis inputs (gas tilt, pressure) rather than to a0, using the break-even table of (a).

**(e) The frozen decision rule: null, near-boundary and honest-error tests.**
1. *Sensitivity map:* all combinations of z_lo in {0.61, 0.8, 1.0}, z_hi in {2.52, 2.3, 2.0}, f_DM window {all, [0.05,0.95], [0.10,0.90]}, g_bar cut {all, < 3 a0, < a0}, M_bar cut {none, >= 10.3, >= 10.6} (243 cells), each cell with bootstrap N = 2,000 (seed 233) for both laws; the class W-flat/W-rival/W-none/W-mixed per cell; report the class counts, the cells where the class differs from the primary, the smallest n (cells with n < 15 are marked and excluded from the shares).
2. *Leave-one-out* (100 fits, bootstrap N = 1,000 each, seed 235): slope range, class counts; *leave-out-influence:* the 5 galaxies whose removal moves the flat slope most (named), and the slope with all 5 removed.
3. *Bootstrap over discs:* N = 10,000 (seed 233, stability seed 234): share of resamples with flat slope > 0, share with rival slope > -0.030; BCa CI beside the percentile CI.
4. *Permutation null:* shuffle z (N = 20,000, seed 236): two-sided p for each slope and each of the four z-scores' null distribution (the tails of the observed statistic).
5. *Honest total significance:* the rival tension recomputed with a total sigma = sqrt(sigma_boot^2 + sigma_sys^2), sigma_sys from a Monte Carlo (N = 20,000, seed 233) over declared Gaussian priors: gas tilt t ~ N(0, sigma_t) with sigma_t in {0.05, 0.10, 0.20} dex per unit z (0.10 is the declared central value), V_c tilt q ~ N(0, 0.02) dex per unit z, M* zero-point tilt tau ~ N(0, 0.02) dex per unit z, pressure scale s ~ U[1, 3]. Reported: the SD of the modified observed slope, the total tension, the probability that the tension exceeds 3 and 4 sigma, and the same for the flat side.
- **Pass/fail meaning:** the headline "rival disfavoured at 4.9-5.5 sigma" **survives** if the tension with the central prior is >= 4 sigma and the sensitivity map has W-flat or W-none in >= 70% of the cells (the rival never in W-rival); it is **weakened** between 3 and 4 or 50-70%; it **FAILS** below 3 sigma or below 50%. The W-flat label (rested on +0.002) **is not stable** if the class differs in >= 40% of the map cells or in >= 30% of the leave-one-out fits (stated as such whatever the primary cell shows).

## 7. Controls and MUTATE (each flips a load-bearing cell; exit 1 when the control bites)

Main run exit 0 (C1-C4 pass; the headline rows are reported against their pass lines). Each MUTATE writes `<name>_MUTATE_<k>.out/.json`, never overwriting a main output.
- **C1:** a synthetic galaxy placed exactly on each law (D from the law's inversion) returns delta = 0 (1e-9) under its own law and the analytic s_F / s_R under the other.
- **C2' (replaces CFG215's C2):** name-matching count (38) and the RC100 vs RC41-1D column comparison (reported).
- **C3:** delta_flat + 0.2 (z - z_med) shifts the Theil-Sen slope by exactly +0.2 (1e-9).
- **C4:** the re-implemented nu_mono agrees with the imported object to 1e-9 (else the imported one is used and the difference printed).
- **M1 (inject a known slope):** D_obs x 10^(0.2 (z - z_med)); both laws' slopes must move by +0.2 plus the kernel response (flat >= +0.19); the class must leave W-flat. Bites if the class changes (exit 1).
- **M2 (shuffle z):** permute the z labels of the 100 rows (seed 233), keeping (f_DM, V_c, R_e) and the table's rows intact but E(z) for the rival evaluated at the shuffled z; both observed slopes must fall inside 2 sigma of 0 and the rival's -0.092 must vanish; class W-none. Bites if the rival slope is no longer < 0 with its CI (exit 1).
- **M3 (swap the laws):** evaluate "flat" with a0 E(z) and "rival" with the constant a0; the reported flat slope must become about -0.092 (CI < 0) and the class W-mixed. Bites if the class flips (exit 1).
- **M4 (remove RC41):** the 62 non-RC41 rows only; the flat slope's CI must move below 0 (about -0.055) and the class must become W-mixed. Bites if the class flips (exit 1).

- **M6 (inject a gas tilt):** g_bar x 10^(-tau (z - z_med)), f_DM' = 1 - (1 - f) 10^(-tau (z - z_med)) at fixed V_c, tau = +0.15 dex per unit z; the flat slope must shift by -(1 - s_bar) tau within 30% (about -0.10) and the class must change. Bites (exit 1). This is the control for the propagation algebra of attack (a).
- **M7 (remove the 'D and g_bar are one f_DM' coupling):** recompute g_bar from the table's M_bar (variant d) but keep D_obs from f_DM (a mixed, non-physical pairing); the slopes must differ from the primary by more than 0.03 (the coupling is what makes the delta insensitive by the factor 1 - s). ## 9. What would count as disagreement with CFG216
