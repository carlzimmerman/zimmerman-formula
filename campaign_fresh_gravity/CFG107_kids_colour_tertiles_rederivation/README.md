**Differences and causes.** (1) **Power 4.8:** the alternative that gives 4.8 is beta_true = (A_E - A_L)/(u_E - u_L) with A from the two-class ESD amplitudes (-0.128, +0.052), which is what CFG115's code does; the agent's primary reading used the step-fit s_E - s_L (4.465). Other variants: no Hartlap factor 5.21; class-mean colour 4.33; half the class difference 1.12; truth equal to the fitted gradient slope 7.44. Algebraically lambda = beta_true^2/sigma(beta_w)^2 with sigma(beta_w) = 0.1233; the 1-dof power at alpha = 0.05 is 0.56 for 4.8 (0.56 for 4.47); the slope detectable at 80% power is 0.346 dex/mag, 1.33 times beta_true. The conclusion (below 9) is unchanged. (2) **Colour-split LCDM 77.6:** CFG115 normalises its L model to a class-mix reference (the class stacks weighted by class pair weights); B and Moster use all-lens stacks. Using the class-mix reference the post-hoc script gives 77.7 and the free-offset value stays 21.1. A shift of about -0.006 dex in the model amplitudes moves the row between 22.7 and 77.7: **the zero-offset jackknifed-reference rows measure model normalisation against a near-null covariance direction, not physics** (supports CFG115's R6). (3) **A wording error in CFG115:** its Disclosures say the zero-offset rows with a fixed reference become B 36.2, L 21.1, Moster 12.2; those are the free-offset values. The agent's fixed-reference zero-offset values are B 38.8, L 21.1, Moster 12.3; only the free-offset statement holds for B. (4) R6 checks: every free-offset chi2 is identical under the jackknifed and fixed references to 3e-13 (exact algebra); errors differ by definition (the fixed reference gives 0.085 0.082 0.044 0.037 0.032 0.032); the jackknifed-weights variant gives essentially the jackknifed reference (condition number 3194); the pseudo-inverse row reproduces CFG115's post-hoc delta chi2 (0.183 against 0.19). (5) **K4a control FAILED as frozen:** the BFGS leg agrees with the normal equations only to 1.95e-6 against the frozen 1e-8 (the algebraic legs agree to about 1e-14 and a post-hoc BFGS on the whitened problem to 1e-14: an optimiser limit, not physics; reported as a failed control; the other 11 pass). (6) The mass-matching attack as frozen: cells with fewer than 20 lenses dropped gave weights up to 35-64 and an undefined (non-positive) L1 numerator, so a post-hoc common-support matching (labelled) was substituted. (7) The radial attack: the inner-bin log amplitude is undefined; a post-hoc linear-ratio amplitude is reported instead. The first main-run attempt crashed in the mass-matching attack row (`cfg107_run_attempt1_crashed.out`).
