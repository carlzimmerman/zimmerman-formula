# CFG302 — FROZEN CRITERIA: raw HI widths and fluxes (and, where possible, rotation) re-measured from the MIGHTEE-HI DR1 r1p0 spectral cubes, compared with the catalogue's busy-function values

**This file is committed before any spectrum has been extracted.** Owner direction (2026-10-02): "keep going with the MIGHTEE cubes lane" and "we must use empirical evidence raw and unfiltered". The cubes are the four local L2 r1p0 clean_conv_contsub sub-cubes (SARAO DOI 10.48479/jkc0-g916, CC BY-NC 4.0; sha256 manifest beside them); no download is made by this lane. The catalogue is the MNRAS supplementary table in `data_assembly/mightee_hi_catalogue_2026-10-02/`.

> **A raw-measurement check, not an a₀ measurement.** No a₀ number is computed. At z ≤ 0.093 nothing here can separate FLAT from a₀ ∝ H(z). κ = ½ is FITTED. No verdict words beyond the map entries in section 4.

4. CFG300's README, frozen criteria and code (its W50 rule, its beam-area convention 1.1331 θ²/pix², its first-order velocity v = c(ν_c − ν)/ν_c, its noise findings: the ≥ 5σ tails are not Gaussian).

## 1. Sample and flags
**Sample (fixed by code):** catalogue rows with all five flags = 0 (low_confidence, blended, confused, bad_ellipse, contaminated) and 0.02 ≤ z_HI ≤ 0.093: **188 sources**. **Control targets outside the sample:** CFG300's T1 (catalogue row, for C-T1) and T3 (reported only). T2 is in the sample.
**Flags, computed from the headers and the catalogue before any measurement:**
- **BEAMFLAG**: the line window W contains a channel with an invalid beam entry (BMAJ outside [50″, 120″]). Measured with the sub-cube's median valid beam, reported, **excluded from the primary statistics** (the flux scale needs the beam).
- **STITCH**: W spans a sub-cube junction. Included.
- **EDGE / NAN**: any aperture pixel off the image or non-finite in W. Excluded from the primary statistics, reported.
- **TRUNC**: W leaves the frequency coverage (none expected). Excluded, reported.
- **NBFLAG**: another catalogue source (any flags; all 293 rows) within 2.5 θ on the sky with |Δv| < V_w + W50_nb/2. **Included** in the primary statistics (raw, unfiltered); a secondary statistic excludes them.
The **primary set** = sample minus BEAMFLAG, EDGE, NAN, TRUNC.

## 2. Grid, beam and velocity
- **Global channel** g = 0 … 4054, ν_g = 1290.123036077 MHz + g × 26.12484126 kHz; every sub-cube's frequency axis must sit on this grid to 1 Hz (C-GRID). In a 55-channel overlap the channel is taken from the sub-cube in which it is farther from the spectral edge (g ≤ 1000k + 1027 from sub-cube k, else from k + 1).
- **Positions:** the catalogue RA/Dec, converted to pixels with each sub-cube's own celestial WCS (TAN, astropy).
- **Beam:** per channel θ = BMAJ read as arcsec whatever TUNIT says; A_beam = π BMAJ BMIN / (4 ln 2) / (8″)² pixels.
- **Velocity:** v = c (ν_c/ν − 1), ν_c = the catalogue freq_MHz; this is the velocity in the galaxy's rest frame (positive = receding), so our widths are physical rest-frame widths (to first order identical to CFG300's convention). The catalogue does not state its width convention; the CSV also gives (1 + z_HI) × W for an observed-frame comparison. A convention mismatch would move the median width ratio by ± log₁₀(1 + z) ≈ ± 0.025 dex at the median z; this lane does not decide the convention.

## 3. Measurement (frozen; no tuning after the first look)
1. **Aperture:** a circle of radius **R_ap = 1.5 θ_src** (θ_src = the median valid BMAJ over the W channels, ≈ 113″ ≈ 14 pixels; diameter 3 beams; a point source puts 99.8 % of its flux inside), centred on the catalogue position; a pixel is in iff its centre is within R_ap. **Aperture spectrum** S(g) = Σ_ap I / A_beam(g) [Jy]. No baseline subtraction, no mask, no clipping.
2. **Windows:** **W** (line window) |v| ≤ V_w = max(1.5 W50_cat, 300 km s⁻¹). **L** (line range) |v| ≤ W50_cat/2 + 50 km s⁻¹. **O** (off-line window): the width of W, centred at v_O = +(2 V_w + 100) km s⁻¹ (low-frequency side), or at −(2 V_w + 100) if the + side leaves the coverage; undefined if neither fits. **Noise band N**: V_w + 100 < |v| ≤ 3 V_w + 1100 km s⁻¹ inside the coverage, minus O.
3. **Noise:** σ_ch = 1.4826 × MAD of S over N (about its median); **f_corr** = σ_8² / (8 σ_ch²), σ_8 = 1.4826 × MAD of the sums of non-overlapping 8-channel blocks inside contiguous runs of N (f_corr = 1 and a flag if fewer than 10 blocks). For a window X of N_X channels, σ_S(X) = Δν σ_ch √(N_X f_corr).
4. **Flux:** **S_win** = Δν Σ_W S(g) [Jy Hz] (primary); S_L over L (secondary). **Detection statistic** S/N_L = S_L/σ_S(L); **detected iff S/N_L ≥ 5.**
5. **Widths (non-parametric, peak-relative):** S over W smoothed by a 3-channel boxcar (CFG300's choice, ≈ 17.5 km s⁻¹); P = its maximum over W; for f = 0.5 (W50) and 0.2 (W20), outside-in: from each end of W move inward to the first channel ≥ f P, interpolate linearly between it and its outer neighbour; W_f = v_hi − v_lo. If the end channel of W is itself ≥ f P the crossing is edge-hit and W_f is undefined. **Width-defined iff detected and both W50 crossings are found** (W20 carries its own flag).
6. **Errors:** 300 noise realisations (seed 302): S + n_j over W, n_j a run of N_W consecutive values of the concatenated noise band (random start, wrap-around: real noise with its correlation and tails); the error is half the 16–84 % range of the defined realisations; the defined fraction is reported (below 0.5 → MC-unstable, reported only).
7. **Size screen:** moment-0 map M0 = Δν Σ_L I over a box of ± 5 θ (clipped to the image); σ_M0 = 1.4826 × MAD over the annulus 3θ–5θ; footprint = the 8-connected component of M0 ≥ 3 σ_M0 containing the brightest M0 pixel within θ of the position (if that pixel is ≥ 3 σ_M0); major axis from the M0-weighted second moments; extent D = (max − min projection) + 8″; D_dec = √(max(D² − θ², 0)); **beams across = D_dec/θ** (CFG300's definition; generous, because the 3σ isophote of a bright point source spans more than a beam). Also **FWHM_eq** = 2 √(A₅₀/π), A₅₀ the 8-connected half-maximum area of M0 around the same pixel (for C-BEAM).
8. **Resolved rotation:** every detected source with beams across ≥ 6 gets a position–velocity extraction. **The catalogue carries no optical position angle, so the axis is the HI moment-0 principal axis** (a disclosed departure from "the optical major axis"). Strip one θ wide, bins θ wide along the axis; per bin the spectrum over W summed over the strip pixels in the bin / A_beam; the bin velocity = the intensity-weighted mean v over the channels where the bin spectrum is ≥ 3 σ_bin (σ_bin by MAD over N); **RC-capable iff ≥ 3 bins with a velocity on each side, S/N_L ≥ 10 and |Spearman ρ| ≥ 0.8** (CFG300's rule). If no source reaches 6 beams the map entry is "no resolved rotation at r1p0" and the PV code is exercised only by self-test S3.

## 4. Comparison statistics and map entries (over the primary set)
- **Widths:** R_W = log₁₀(W50_ours / W50_cat) over width-defined sources: median, robust scatter s_W = 1.4826 MAD, mean, std; **outliers** |R_W − median| > 3 s_W (listed by ID); **pull outliers** |W50_ours − W50_cat| > 3 √(σ_ours² + σ_cat²) (listed). Secondary: without NBFLAG; Spearman of R_W against z and against S/N_L; W20 reported (no catalogue W20 exists).
- **Fluxes:** over ALL primary-set sources the median of q = S_win/S_cat (linear: non-detections and negatives included) and its robust scatter; over detected sources with S_win > 0, R_S = log₁₀(S_win/S_cat): median, s_S, outliers (> 3 s_S), pull outliers |S_win − S_cat| > 3 √(σ_S² + σ_cat²). Secondary: S_L; without NBFLAG.
- **Map entries (the only verdict words):** WIDTH-SCALE **AGREES** iff |median R_W| ≤ 0.03 dex, else **DIFFERS** (narrower / wider). FLUX-SCALE **AGREES** iff |median R_S| ≤ 0.05 dex, else **DIFFERS** (lower / higher). WIDTH-SCATTER and FLUX-SCATTER **CONSISTENT WITH THE ERRORS** iff pull outliers ≤ 10 % of the compared sources, else **NOT CONSISTENT**. "Resolved rotation curves at r1p0: n."

## 5. Controls (each can fail; check() rows)
- **S1** (synthetic, no voxel): the width rule on a noise-free channelised double-horn (box of width 150 km s⁻¹ with a 25 % parabolic trough, Gaussian edges σ_e = 8 km s⁻¹) returns W50 within 3 km s⁻¹ of the fine-grid truth. **S2**: a synthetic point source (76″ beam, 8″ pixels) in a zero block gives aperture flux / truth in [0.99, 1.005]. **S3**: the PV code on a synthetic 8-beam disc (flat 200 km s⁻¹, i = 60°, 75″ beam, Gaussian noise) finds ≥ 3 bins per side and |ρ| ≥ 0.8 with the receding side on the side the disc was built to recede.
- **C-INT**: the four files' sizes and sha256 match `FETCH_MANIFEST.jsonl` (the MUTATE run checks sizes only). **C-GRID**: section 2's grid holds for all four sub-cubes.
- **C-OFF (line-free control, offset in velocity)**, over the O windows of the primary set: (a) |S/N_L| ≥ 5 in ≤ 5 % (sources with a catalogue neighbour within 2.5 θ inside O's velocity range are listed and not counted); (b) the robust std of S/N_win in O is in [0.75, 1.33] (the noise model calibrates); (c) the median S/N_win in O is within ± 0.5 (no baseline offset).
- **INJ (synthetic HI in real noise):** for each primary-set source, the S1 profile shape with box width W50_cat and integral S_cat is injected as a point source (Gaussian, per-channel beam, sub-pixel position) into the real cube block of its O window, and the full pipeline is run centred on O (its noise band excluding the real line window W). Pass iff (a) the median log₁₀(W50_rec / W50_true) over width-defined injections is within ± 0.03 dex; (b) the median log₁₀(S_win,rec / S_cat) over injections with S_win,rec > 0 is within ± 0.03 dex; (c) the robust std of (W50_rec − W50_true)/σ_W50 is in [0.4, 1.5]. W50_true is the fine-grid W50 of the injected profile. The injection detection rate is reported beside the main run's.
- **C-T1 (cross-instrument, r0p0 vs r1p0):** T1's W50 from this pipeline at its catalogue position is within max(25 km s⁻¹, 3 σ_ours) of CFG300's frozen r0p0 value **380.1 km s⁻¹**. Reported beside it: CFG300's unmasked aperture values (374.1, 380.9), the catalogue 392 ± 12, and T1's flux ratio against CFG300's 0.57 (masked r0p0), 0.76 (unmasked r0p0) and 0.85 (r0p5); T2 and T3 against CFG300 (not checks).
- **C-BEAM:** among the 20 detected primary-set sources of highest S/N_L, the median FWHM_eq/θ lies in [0.85, 1.6] (a true resolution finer than the header's ≈ 75″ would make unresolved sources look smaller than the beam; the flux scale depends on the beam area).
- **MUTATE=1** (the line window shifted off the line; separate outputs): the whole pipeline with its centre at v_O (the same O as above; noise band relative to O excluding only O). **M1** width-defined ≤ 5 % of the primary set; **M2** detected ≤ 5 %; **M3** T1's width collapses (undefined, or outside the C-T1 tolerance). In the MUTATE run M1–M3 replace the comparison rows.

## 7. Run order and outputs
`cfg302_raw_widths.py` reads the cubes through `np.memmap` (big-endian float32 at the header's data offset; the folder from the environment variable `MIGHTEE_R1P0_DIR`, default `../_external_data/mightee_hi_dr1` relative to the repository root); it never writes a cube-sized file. Main run → `cfg302_raw_widths.out`, `cfg302_raw_widths_results.json`, `cfg302_per_galaxy.csv`; `MUTATE=1` → `cfg302_raw_widths_MUTATE.out`, `cfg302_raw_widths_MUTATE_results.json`, `cfg302_per_galaxy_MUTATE.csv`. One run each; first runs kept; any code fix after a run is disclosed and the first output kept beside the corrected one. README last. The per-galaxy CSV is for CFG301 to use later as an independent-width variant; this lane does not run CFG301.

## 8. What this lane cannot say
No a₀ number; z ≤ 0.093 cannot separate the laws. The catalogue's width convention is not decided (± 0.025 dex). At a ≈ 75″ beam the 113″ aperture holds any HI within it (confusion; NBFLAG lists the catalogued cases only). The injection uses point sources and does not test extended emission. The noise tails are not Gaussian (CFG300); the MAD noise, the real-noise error realisations and C-OFF address this, they do not remove it. Widths are not inclination corrected (neither are the catalogue's).
