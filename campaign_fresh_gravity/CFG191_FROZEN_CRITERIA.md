## 5. Item (a): THE THEOREM -- frozen procedure and pass lines

Statement to test (premises P1-P6, written before derivation; disagreement if I find a premise CFG179 does not state):
- P1 Local single-argument law: the observed field of a system is g = F(z_tot) where z_tot is the total NEWTONIAN field at the point (units of a0), F : [0, inf) -> [0, inf).
- P2 Difference rule (universality of free fall): the internal acceleration of a subsystem in a uniform host field is the total observed field minus the host's observed field at the host's Newtonian field: g_int = F(z + z_e) - F(z_e).
- P3 "No EFE" means g_int = F(z) for ALL z, z_e >= 0.
- P4 Regularity: F monotone on the half-line (the observed field does not fall as the Newtonian one rises) OR measurable OR bounded on an interval; any one suffices. Differentiability is NOT needed.
- P5 Geometry: aligned (1-D) fields suffice for the scalar statement; the 3D-vector statement needs P3 for every direction pair.
- P6 F(0) = 0 (follows from z = z_e = 0).

Derivation to be carried out symbolically: P3 with z = z_e = 0 gives F(0)=0; Cauchy additivity F(x+y)=F(x)+F(y) on the half-line gives F(qx) = qF(x) for rational q; monotone (or measurable, or bounded on an interval) gives F(x) = F(1)x; differentiating P3 in z_e (only if F is C1) gives F'(z + z_e) = F'(z_e), F' constant, same result. Strict concavity with F(0)=0 gives STRICT sub-additivity, so the EFE residual has one sign (suppression) for every strictly concave F; P2 has F'(0+) = infinity.

Checks (main):
- A1 (sympy) the derivation above, printed step by step with the premise each step uses; F = c z satisfies P3 exactly, F = sqrt(z^2 + z) does not; residual r(z, z_e) = F(z + z_e) - F(z_e) - F(z) at the six declared points {0.01, 0.1, 1} x {0.1, 1} is negative at every one, values printed to 12 digits from a closed form and from mpmath at 40 digits. PASS: all six negative and the two evaluations agree to 1e-12.
- A2 (numeric) r < 0 strictly on a 200 x 200 log grid z, z_e in [1e-3, 1e3] for P2 and for three more strictly concave kernels (z*nu_RAR(z), z*nu_simple(z) with nu_simple = (1 + sqrt(1 + 4/z))/2, and z*nu_mono if its closed form is unambiguous in the record; otherwise not run and said so). PASS: max r < 0 on the grid for every strictly concave kernel; r = 0 to 1e-15 for F = 2z (control).
- A3 (vector) G(x) = F(|x|) x/|x| (P2). 200,000 random pairs (a, b) in R^3 (magnitudes log-uniform in [1e-2, 1e1], directions uniform incl. exactly parallel, anti-parallel, perpendicular). Symbolic step: continuous + additive on R^3 => R-linear; + rotational covariance => G = c*Id (Schur); without isotropy, any linear map A survives (anisotropic linear laws).
