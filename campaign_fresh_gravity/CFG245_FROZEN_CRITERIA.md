**Key physics settled in triage.**

**(i) Does a mass-conserving relaxation have a local-field target at all?**
- The target density `rho_ph = div[(nu - 1) grad Phi_N]/(4 pi G)` is a function of the 2-jet of the Newtonian potential Phi_N of the baryons (value of |grad Phi_N| and its gradient, and rho_b through the Laplacian). It is local in FIELDS, not in the source integral. (Phi_N itself is the Poisson integral of rho_b; "local" here means Phi_N is taken as given, as the ChainCert theorem does.)
- **Positivity (spherical, P2; hand derivation).** With y = g_N/a0 and nu = sqrt(1 + 1/y): `rho_ph = rho_b (nu - 1)^2/(2 nu) + M_b(<r)/(4 pi r^3 y nu)`, non-negative for every non-negative rho_b. For a point mass it is `M_b/(4 pi r_M^3 x sqrt(1+x^2))`, equal to CFG44's `a0/(4 pi G r sqrt(1+x^2))` (`CFG44_fluid_target/README.md:8`). **Non-spherical:** QUMOND phantom density can be negative (memory, unverified); not decided by hand; G0.3 computes the negative fraction on two masses and a thin disc.
- **Mass divergence.** For a point mass `M_ph(<r) = M_b (sqrt(1+x^2) - 1)`, which grows linearly in r at large x (`M_ph -> sqrt(M a0/G) r`; for M_b = 1e10, 1e11, 1e12 Msun that coefficient is about 2.6e9, 2.6e10, 8.2e10 Msun/kpc). There is no finite total: **a conserved fluid with a finite supply cannot reach the pure local-field target.** A mass-conserving class needs a closed domain D and a supply cap S (`M_target(<r) = min[M_ph(<r), S]`); D and S are NON-LOCAL labels. This is the second non-local object (the first is ownership). Declared in section 2, scored in Gate A.
- **Target is not the CFG44 target for extended baryons (hand derivation, P2, spherical).** `C_loc = rho_ph r^3 g_tot = C_44 [1 + 2 pi r^3 rho_b g_N (nu - 1)^2/(a0 M_b(<r))]`, `C_44 = (a0/4 pi) M_b(<r)`. In the deep regime inside a uniform sphere the factor is 2.5 (agrees with the referee line for nu_mono on extended profiles, `CFG44_fluid_target/README.md:39`); outside the baryons and for a point mass it is exactly 1. So the shared G1 target (the enclosed-mass charge) is the law's own phantom only for a point mass; for extended baryons "the law's dark density" in the owner's local-field form differs from it by up to a factor of about 2.5. Consequence: the exponential-sphere rows are scored against BOTH targets (G0.2) and the binding verdicts use the point-mass sample first, as CFG244 did (`CFG244_FROZEN_CRITERIA.md:106,111`).

**(ii) What "relaxes at rate Gamma" means as an equation, and which versions the class includes.**
- **Excluded from the class (creation form):** `d rho_c/dt + div(rho_c v) = Gamma (rho_ph - rho_c)`. It creates mass wherever rho_ph > rho_c and destroys it where rho_ph < rho_c, so it violates the rest-mass ledger (CFG243 `README.md:76`; CFG131 `README.md:15`: f = 1.70 at x = 30, x* = 20.2) and, with a Lorentz-invariant vacuum, forces `d_mu rho_L = Q u_mu` (CFG131 `README.md:11`). Scored only as the labelled variant V-CREATE (section 3), post hoc, never pooled.
- **Included (primary class, R-FLUX; mass-conserving by construction):** the SAME right-hand side written as the divergence of a mass flux J, with J a function of fields only:
  `d rho_c/dt + div(rho_c v) + div J = 0`, `J = (Gamma/4 pi G) (g_law - g_tot)`,
  where `g_law = nu(|g_N|/a0) g_N`, `g_N = -grad Phi_N` (baryons only), `g_tot = -grad Phi_tot`, `Phi_tot` the potential of baryons plus the cold fluid. Then `div J = Gamma (rho_c - rho_ph)` (using `div g_law = -4 pi G (rho_b + rho_ph)` and `div g_tot = -4 pi G (rho_b + rho_c)`), i.e. exactly the relaxation law, but as a flux: total mass in a domain changes only by the flux through its boundary.   In spherical symmetry `4 pi r^2 J_r = -Gamma [M_ph(<r) - M_c(<r)]` (inward when the fluid is under-massive): the cumulative mass inside r relaxes as `d M_c(<r)/dt|_relax = Gamma [M_target(<r) - M_c(<r)]` with `M_target = min(M_ph, S)` on the closed domain D (zero flux at the boundary; mass outside D untouched).

## 3. The gates, their ORDER, and the exact pass lines

**ORDER (part of the freeze): G0 (definitions and controls), T, C, A, E.** G0 is cheap arithmetic and a 3D finite-difference control; it stops the lane only if a control FAILS (the class is then UNDEFINED, not PASS). T is next because it needs only committed arrays and one exponential, so it is the cheapest decisive gate, and because the state it produces is the input of C and A. C uses committed per-cluster numbers. A is a closed-form ceiling plus a rearrangement of committed products. E is the energy ledger and a symbolic linearisation. A is after C because A's supply cap S matters only if Gamma is large enough to survive T.
**STOP RULE:** stop at the first binding FAIL among T, C, A, E and name it. Later gates are still COMPUTED, as POST-HOC EXTRAS (file names carry `_POSTHOC`, outputs say so, no verdict depends on them), because their frozen estimates below are to be compared. A gate that cannot be defined sharply is UNDEFINED, not PASS, and does not stop the lane but blocks a class PASS.

**Conventions for every gate.** Both footings, always computed; a verdict needs the same category on both footings, otherwise the more cautious category is reported. Kernel P2 primary; nu_mono as a labelled second kernel scored against ITS OWN local target (its point-mass C_loc/C_44 = 1.46 at x = 1 per `CFG44_fluid_target/README.md:39`) and reported against C_44 only; if the two kernels land in different categories the more cautious is reported. Tolerance 10% on C(r) as in CFG44/CFG118/CFG244 (`CFG244_FROZEN_CRITERIA.md:111-112`). Noise guard as CFG244: a bin or x counts as a failure only beyond the larger of the shell-bootstrap sigma and |R_5k - R_20k| (`:114`). Sample: the four baryon masses 1e9, 1e10, 1e11, 1e12 Msun, q = 0.05, 0.1, 0.2, point cores primary, exponential spheres reported.

### Gate T -- TIMESCALE (is the relaxation fast enough, and what does partial relaxation predict?)

**The frozen simple relaxation model (order-by-order in Gamma tau).** With the passive cumulative bound mass `M_inf(<r)` from the committed CFG244 products (read-only; if the cumulative bound array on CFG244's 0.1-dex grid is not in `CFG244_A_infall_bound_sims.json`, compute it with CFG244's own code imported read-only, no new simulation settings), the relaxation is linear-exponential at each r:
`M_c(<r; tau) = M_target(<r) + e^(-Gamma tau) [M_inf(<r) - M_target(<r)]` (R-FLUX-2),
