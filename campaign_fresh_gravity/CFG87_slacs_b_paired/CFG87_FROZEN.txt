  DH = max(h'(y), 0.05 H_P/(y+Y_P)); H_M = h(y_0) + cumulative trapezoid (in linear y) of DH; nu_mono(y) = 1 + interp(log10 y, grid, H_M)/y, y clamped >= 1e-14.  (My h' is analytic, theirs a 1e-6 finite difference.)
  Footings a0 = 9.36e-11 (canonical) and 1.13e-10 (alt) m/s^2 (hunt_lib values).  Constants G = 6.674e-11, kpc = 3.0857e19 m, Msun = 1.989e30 kg, arcsec = 1/206264.806 (hunt_lib / h53; shared inputs).
  Static spherical law, no EFE, no halo: M_tot(r) = nu_mono(g_N/a0) M_b(r), g_N = G M_b(r)/r^2.
  LENS: stars = spherical de Vaucouleurs (Sersic n=4, b_n Ciotti-Bertin 2n-1/3+4/(405n)+46/(25515 n^2)), 2-D mass fraction EXACT regularised gamma(2n, b x^(1/n)), 3-D enclosed fraction Prugniel-Simien
  (p = 1-0.6097/n+0.05463/n^2) regularised gamma(n(3-p), b x^(1/n)), x = r/R_e; R_e = Re(V) or Re(I) [arcsec] x D_A(z_l) (Auger flat Om=0.3, h=0.7; the other band if one is missing).  Phantom
  M_ph(r) = (nu-1) M_b(r) projected through a cylinder of radius R_E with an infinite line of sight TRUNCATED at r_max = 3000 kpc (h53's default) -- BASE; the untruncated cylinder (r_max = 1e7 kpc) is a reported variant.
  I project by the exact identity M2D(R) = M(r_max) w(r_max) + int_0^{theta_max} M(R/cos t) cos t dt, theta_max = arccos(R/r_max), w = 1 - sqrt(1-R^2/r^2), evaluated by Gauss-Legendre on
  t in [0, pi/3] and on u = ln(r/R) in [ln 2, ln(r_max/R)] (integrand M e^-2u / sqrt(1-e^-2u)).  Boost B(alpha) = 1 + M2D_ph(<R_E)/(M_* M2D_star(R_E/R_e)), M_* = alpha M_Salp (Auger logMs); kappa-bar(alpha) = alpha F_s B(alpha)

  DYNAMICS (h9's convention): nu_mono(y) M_* = M_JAM with y = G M_*/(2 r_1/2^2 a0) (half of M_* inside the 3-D half-light sphere, M_dyn(<r_1/2) = M_JAM/2); alpha_dyn = M_*/M_Salp,ATLAS3D (brentq log M_* in [3,14.5]).

PAIRING DEFINITION.  B (4 cells) and LCDM (every cell) are evaluated on the SAME bootstrap resamples: N_B = 2000 resample pairs (ic, il) are drawn ONCE (numpy default_rng(87); ic = 187 calibrator
  indices with replacement, il = 70 lens indices with replacement; both models' fit AND median are computed on that (ic, il), each model dropping any drawn object it could not solve).  Within each resample
  D^b = Delta_B^b - Delta_L^b; the paired error is std_b(D^b); the point estimate is D = Delta_B - Delta_L on the full samples; z_pair = D/err_pair (statistical only; a Salpeter zero-point offset d between
  Auger and ATLAS3D moves B's and LCDM's Delta by exactly -d each (identity; verified by re-solve for both), so D is d-invariant and the 0.10 floor is not added to D).  A secondary PER-LENS paired estimator
  (median_i[(la^B_i - fit_B(x_i)) - (la^L_i - fit_L(x_i))], same resamples) is reported in the base cell.  Unpaired comparison: err_unp = sqrt(errB^2+errL^2).  Shuffle control: pairing resample b of B with
  resample b+1 of LCDM must give an error within 10% of err_unp.

CELLS.  LCDM cells = CFG86's 54 declared: halo multiplier {1/3,1,3} x tie {solved Salpeter (base), solved Chabrier-equivalent (s = median 10^(logMc-logMs)), fixed Chabrier-equivalent} x
  {z=0, z-consistent} x {Duffy full, Duffy relaxed, Dutton-Maccio}; extended context m in {0.1, 10} (not in the verdict).  Base cell = (1, solved_salp, z0, duffy).
  Per (B cell, LCDM cell): S_a: |Delta_L| <= 2 err_L;  S_b(paired): D > 2 err_pair;  S_b(unpaired): D > 2 err_unp;  W = S_a AND S_b(paired).  B cells: canonical V, canonical I, alt V, alt I;
  the PRIMARY B cell in each LCDM cell is the one with the SMALLEST D (worst case over B cells); each B cell is also reported alone and "all four B cells".
  VERDICT on 'B-specific statistically' over the 54 cells: ROBUST if W in >=90% of cells, CONDITIONAL if 50-90%, NOT SUPPORTED if <50%; report which axis levels flip S_a and S_b, and whether S_b (paired) ever flips.
