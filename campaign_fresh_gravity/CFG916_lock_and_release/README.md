CFG915's lead, quoted in the criteria: "latching plus a release of t when it is stripped from its host. That would have to leave

clusters."

## What was tested

H-LR combines two rules:
- **Lock.** CFG915's LC latching: f becomes t on exact settling. t has α_t = 0.
- **Release.** Latched t that is owned by a member and lies outside the member's King/Jacobi radius r_J in a host's field becomes f
  again. f is mobile at α_f ∈ {0.5, 1.0}.

The radius is computed from the law's effective masses (baryons + cold energy), with no new constant:

  r_J³/m(<r_J) = d³/[(3 − γ) M(<d)]

The epoch is pericentre (primary), with present position as the one alternative.

**Two latching readings were graded.** This was declared in the criteria, before any number.
- **LR-x** is CFG915's LC exactly.
- **LR-c** is a capped capture: a cell's t is raised only up to its phantom, so overfill is never latched by capture.

The reason, argued before any run (criteria §9): under exact capture, released cold energy that lands in a settled host is latched
again at once. Release then cannot remove cluster memory. LR-c is the smallest latching change under which release can act.
**Overall = best of the two readings.** That is two chances, and it is disclosed.

## What is and is not established

**Established, on the record's own numbers:**
1. **H-LR as posed (exact capture) does not remove cluster memory.** The host latches the released surplus again at once. M ≡ H-MM is
   CONTRADICTED by eRASS1/ACCEPT OUTER (Z −3.63 / −4.05, −4.83 / −5.19), and the release rule is inert (identity MUTATE arm).
2. **Release can only act if capture stops latching overfill (LR-c).** Then member release, with the record-native r_J, takes cluster
   outer profiles back to the plain law, which passes OUTER. MW settling is untouched. Satellite inner clumps survive except
   Sagittarius, the one satellite with no excess. No host effect is predicted beyond the record's.
3. **The Bullet core is the open item under both readings.** The sub's 200-kpc core is about 87–88% mobile before any release, so the
   test cannot pass at first order. Whether it is excluded depends on a pericentre distance the record does not have.

**Not established:**
- LR-c is a new rule, not derived. It needs the D-i baryon loss to come after exact latching.
- M's pass is static. It needs at least 1.6–3.3 Gyr since release on the alt footing (PH1).
- B needs a merger run.
- The cluster MID excess (×1.9) is untouched.
- α_t = 0 remains a posit against the record's push.
- κ is not derived; this is not "theory closed"; nothing here says the data favour the framework.
