- **G1.0 control:** prescribing the target as initial data reproduces it to 5e-6 (both profiles) and matches CFG44's `Bcommon.target_fields` to 3e-11: a choice, not a mechanism.
- **G1.1 steady flows:** steady irrotational flows with generous per-profile optimisation of (Mdot, the Bernoulli constant, a uniform source b): best sup |C/C_44 - 1| point mass class A 0.683, class B 0.674, exponential sphere 0.979 for both (line 0.10); the optimum is confirmed by an independent LSODA re-evaluation (the generous fits are best-found, not proven global minima).
- **G1.2 persistence:** the flow is geodesic whatever V, gamma or D-terms are added (T0.3a): the fall time over x in [0.3, 30] is 0.003-3.7 Gyr across masses 1e9-1e12, both profiles, both footings; 0 of 2624 shell cases survive 10 Gyr, so the first crossing is before 10 Gyr at every scored x.
- **G1.3 static identity:** the resting target dust accelerates inward at g_tot/g_law = 1.000; holding it static needs f_ext = g_tot; there is no stationary v = 0 state at all wherever grad Phi is nonzero (T0.3c: stronger than the frozen F6); the dust's gravity would have to be cancelled inside halos (s = 1) and restored at z >~ 10 (s < 0.025): Gap 1's owner switch.

- **G2 growth (two-fluid, z = 1100 to 10):** c_s^2,max at k = 30/Mpc, z = 10 is 4.2e-11 (gt_max = 8.5e-11); the halo-scale sigma^2/c^2 is 2.0e-8 to 6.8e-7, so the joint window is empty by a factor 1.6e3 to 1.6e4 (c_s^2,max/needed = 6e-5 to 2e-3); growth at the halo-scale c_s^2 is 0.012-0.025 against the 0.95 line; the switch test allows s <= 0.025 (s = 1 gives 0.073); for B, T0.4b derives d(a^3 eps)/dt = -a^3 dV/dt exactly, so a non-constant V is a homogeneous source.
- **G3:** the exact contact reaction is a_b = -grad(rho_c U'); at x = 0.3, 1, 3, 10, 30 |a_b|/g_law is 0.19, 0.31, 5.7, 1e6, 3e22 (line 0.10, never met; mass-independent); E_sup/((1/2) M_b V_f^2) is 67-1210 over 32 cases in both r_ta conventions (line <= 1); E2/E3 are cited from CFG50/48/70/72.

- **G5:** T0.6 derives c_s^2 = gt/(2 - 3 gt) (the recalled value, recomputed) with a **ghost** (negative kinetic term) for every 0 < gt < 2/3, and gradient instability for gt < 0 or gt > 2/3: no stable healthy gt exists; class D with c_T = 1: 0 healthy points of 234,834 in a (gt, s) scan; E1: the stiffness determinant is -rho_b eps U'^2 < 0 for any coupling and lambda_- is negative at every x in [0.3, 30] (e.g. -4.9e3 (km/s)^2 at x = 0.3); class A is frozen by the momentum constraint (no ghost, no instability). Solar System: rho_c(1 AU) = 7.5e-13 kg/m^3, 1.1e9 times the local halo density 6.8e-22 kg/m^3; no Cassini pass or fail is claimed for E (the frozen comparison against `CASSINI_QUADRUPOLE_CONSTRAINT.md` cannot be made: that file holds only the MOND quadrupole bound).
