# CFG60 -- Dispersion provenance: is the cold fluid's stress set by the enclosed baryonic mass through a dynamical mechanism?

Documentary analysis, 2026-09-28. Nothing in the repository was edited or committed; deepseek_push/, campaign_fresh_gravity_astra/ and fable_independent_2026/ were only read. No new physics and no combination hunting: every row cites a committed check or verdict by file and id, and `CFG60_audit.py` re-reads each one. kappa = 1/2 is FITTED; both a0 footings (9.3603e-11 / 1.1312e-10 m/s^2) apply and no classification below depends on the numerical value of a0. Nothing here says the theory is closed.

## The frozen question (declared before the table was built)

Does any committed construction give the cold fluid's velocity dispersion (equivalently its pressure or stress, C(r) = rho_c r^3 g_tot = (a0/4 pi) M_b(<r)) as set by the ENCLOSED BARYONIC MASS through a dynamical mechanism, as opposed to being initial data from collapse or a postulate? The answer is one of: YES (name the construction and its exact hypotheses), NO (with the exact hypothesis boundary of each excluded class and each surviving restatement), or UNDECIDED (list what was not run). A scoped NO is a valid answer.

## The rubric (frozen; each construction gets exactly one class)

- **D** derives the dispersion/stress dynamically from an action or field equations with no postulate of the target.
- **P** postulates the target (or its equivalent, e.g. beta = -(3/2) rho_b/rhobar_b, sigma_inf^2 = (1/2) sqrt(G a0 M_b)) and is otherwise consistent.
- **I** the dispersion is initial data (collapse history / formation), not set by the enclosed mass.
- **X** excluded by a committed script, with the exact hypothesis of the exclusion.
- **U** untested.

Two conventions I applied and state here so they are not hidden in the table. (1) A row is X only if a committed script or its stated verdict excludes it; where the source itself says PARTIAL (A16, A20) I classed by the failing frozen gate and said so in the row. (2) A row that is a stability or switch test with no dispersion mechanism built on it is U, not X (A22, A24). Evidence tags: "committed" means tracked in git at HEAD 883f3f045; "untracked" means `git status` shows `??`; "unreviewed" means an astra/deepseek result whose own result.json says `acceptance_state: unreviewed`; "[M]" means the map compiler used a memory note and did not reopen the script.
