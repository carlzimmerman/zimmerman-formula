# CFG274 — ADDENDUM 1 (written after the FIRST stage-A run and BEFORE any velocity column is loaded or any g_obs / D / s* of the eight discs is formed)

**Disclosure, stated first: the first stage-A run (`cfg274_stageA_firstrun.out`, kept) FAILED the frozen control C3** (g_bar of the eight discs against CFG227's committed S1 `g_bar` to 1e-6 relative): maximum deviation 4.6e-5. **Cause, checked before this addendum was written:** the committed `cfg227_points.csv` prints `g_bar` with five significant digits (for example `1.4597e-09`), so a relative deviation up to 5e-5 is the file's own rounding; **all eight of this lane's g_bar values, formatted with `%.4e`, equal CFG227's printed strings exactly** (007.1 1.4597e-09, 022.1 1.5657e-09, 041.1 4.9434e-09, 049.1 2.0142e-09, 065.1 2.7685e-09, 066.1 1.0434e-09, 071.1 7.0276e-09, 075.1 5.6623e-10). The frozen tolerance 1e-6 was a mis-specification of mine (it cannot be met by a five-digit file); the machinery is not in question. The check printed no value other than g_bar.

**Changes (no pass line of any scientific result is changed):**
1. **C3 is restated:** every g_bar, formatted with `%.4e`, equals CFG227's printed string for the same galaxy (an exact string match to five significant digits), and the relative deviation is at most 5.1e-5.
2. **The ILL-CONDITIONED rule (§4 / §6 of the criteria) is made explicit for a flagged lever:** the noiseless-world lever is computed from baryon shifts of ±0.03 dex at fixed g_obs; **a lever that cannot be computed because a 0.03 dex baryon change destroys the root (D = ν_mono(y) is only 1.01–1.11 here) counts as ILL-CONDITIONED** (the root is lost within a 7 % change of the baryon mass: the lever is unbounded for the purpose of the rule). The first run applied this reading already; this addendum records it.
3. **C6 (coverage) uses a declared fractional V error of 0.10** (the published V errors are not loaded at stage A, as §6 says); the Monte Carlo of C6 is conditional on the draw having a root (CFG229's convention), which is why the near-Newtonian rows fail it: the first run showed 68 % coverage of 0.00–0.43 and 95 % coverage of 0.48–0.99 for the eight rows (frozen expectation: fail by construction, reported).

**Hand estimates scored in the first run (kept as they fell):** HE1 misses on its last clause (049.1 and 065.1 are NOT the least ill-conditioned: compact discs have a high g at 2 r_e, y = 21 and 30; the least ill-conditioned are 075.1, y = 6.0, lever −11.5, and 066.1, y = 11), the y clauses hit and the lever clause is satisfied in the flagged sense of item 2; HE2 hits (8 of 8 ILL-CONDITIONED, 0 drawable); **HE3 misses** (the rooted-draw 68 % half-widths of the noiseless world are 0.41–0.44 dex for every row, not above 1 dex: conditioning on a root compresses the interval and biases it high).
