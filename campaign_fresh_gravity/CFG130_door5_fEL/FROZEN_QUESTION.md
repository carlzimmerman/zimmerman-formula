# CFG130, Door 5: does a non-negative f(E, L) exist for the CFG44 target? FROZEN QUESTION AND CRITERIA

Written 2026-09-29 BEFORE any script or number of this door was run. Nothing in this directory is committed or pushed by the writing agent; this file is commit-ready as it stands.

**Disclosure of what was read before freezing.** The menu of doors (TEN_DOORS_GATES_2026-09-29.md) was written knowing the target (its own statement). Before this file was frozen the author read CFG44's README and the outputs of B1, and saw that B1's check N6 already reports an isotropic Eddington f(E) >= 0 for the point-mass target and the compact exponential sphere, on a window of 5%..85% of the potential quantiles only, as a NON-load-bearing line. So the isotropic (beta = 0) reading is already partly known to be positive on that window; what is new here is (i) the full energy range, (ii) the anisotropic reading beta = -(3/2) rho_b/rho_bar_b, (iii) a general orbit-superposition test that does not depend on a closed-form inversion, (iv) the localisation of any failure, (v) the entropy-extremum question.

## The question (verbatim, from the orchestrator)

> For the CFG44 point-mass target (x = r/r_M, total potential of baryons + cold fluid with g_tot = sqrt(g_N^2 + a0 g_N) i.e. the P2 law) does a NON-NEGATIVE distribution function f(E, L) exist that (a) generates rho_c(r) = a0/(4 pi G r sqrt(1+x^2)) and (b) has the anisotropy beta(r) = -(3/2) rho_b/rho_bar_b (for a point mass beta is what?) or, for the general target, the Jeans-consistent beta? Method: use Eddington/Cuddeford/Osipkov-Merritt inversion or a general Abel-type inversion for the given rho_c(r) and beta(r) in the given potential; test positivity of f over the phase space, report the region where f < 0 if any; also test a maximum-entropy (Lynden-Bell) construction for whether the target is an entropy extremum under fixed enclosed baryon mass. Report which hypotheses (spherical, point mass, static potential) were used and which were not tested. Apply the gates' rules: MUTATE control that must change the headline, scoped no-go is valid, count constants (any new constant fails G4).

## Definitions fixed in advance

- Units a0 = 1, G M_b = 1 (so r_M = 1). The total potential is the one the target itself generates, Phi' = g_tot = u/r^2 with u = u_N + w, w' = a0 r u_N/u (CFG44 (T)); it is NOT re-solved self-consistently from f (the density is matched by construction; self-consistency is automatic because rho_c is the target's own).
- Point mass: M_b(<r) = M for r > 0, so beta = -(1/2) dlnM_b/dlnr = 0 for every r > 0 (the anisotropy is EXACTLY ZERO; the point mass makes the anisotropic question the isotropic one). The Jeans-consistent sigma_r^2 = V_c^2/2 is then the hydrostatic P/rho of CFG44 (S).
- Extended baryons: exponential sphere rho_b ~ exp(-r/h), h/r_M in {0.03, 0.1, 0.3, 1, 3} (dimensionless; the same constants at every mass, G1's "same constants" requirement is automatic because only h/r_M enters); beta(r) = -(3/2) rho_b/rho_bar_b(<r), from -3/2 at the centre to 0 outside.
- Three constraint sets for the orbit-superposition test:
  V1: rho_c(r) only (does ANY non-negative f(E,L) generate the density in this potential);
  V2: rho_c(r) plus beta(r) (the Door 5 question as asked);
  V3: rho_c(r) plus beta(r) plus sigma_r^2 = V_c^2/2 (CFG44's full "locally virialised" restatement; by Jeans, V3 is V2 plus the boundary condition P_r(inf) = 0).
- Exact reading of "(b)": for the point mass beta = 0; for the general target beta = -(3/2) rho_b/rho_bar_b.

## Methods fixed in advance

M1 Eddington inversion, point mass (beta = 0 exactly): f(E) = (1/(sqrt2 pi^2)) Int_0^inf rho''(Phi = E + t^2) dt, with rho'' = d^2 rho/dPhi^2 taken analytically, over the ENTIRE energy range spanned by r in [1e-6, 1e6] r_M (the potential is unbounded at both ends: -1/r at the centre, ln r outside). Positivity criterion: f(E) >= 0 with numerical certainty, i.e. any f(E) < -1e-6 x (the integral of |integrand|) counts as negative; sign changes are localised in E and mapped to the radius of the circular orbit at that E.
M2 General orbit-superposition (Schwarzschild-type) linear programme for any beta(r): orbits on a grid of (circular radius r_c(E), circularity eta = L/L_c), non-negative weights w_i, constraints per log radial bin, min-max relative residual eps* (HiGHS). Bin quantities are exact time-integrals along each orbit (turning points handled by the psi-substitution), not point evaluations.
   Classification at the finest level: FEASIBLE if eps* <= 0.02; INFEASIBLE if eps* >= 0.10 and eps* does not shrink under refinement; otherwise UNDECIDED. Resolution levels: L1 = 12 bins/decade, L2 = 24 bins/decade with a doubled orbit grid; window r in [1e-2, 1e2] r_M for the point mass and [1e-2 min(h,r_M), 1e2 max(h, r_M)] for extended profiles, plus a wider convergence window for the point mass.
   Localisation of failure: minimum-eps* over sub-windows, reporting the largest radial interval on which the classification is FEASIBLE.
M3 Controls of M2 (must classify correctly or the LP test is declared unreliable): C1 the isotropic Plummer sphere (known f >= 0) must be FEASIBLE; C2 a tracer of density r^(-1/4) in a Kepler potential with beta = 0 (a known negative isotropic f: isotropic Kepler cusps need slope >= 1/2) must be INFEASIBLE; C3 the Eddington f(E) of M1 and the LP of M2 (V2, point mass) must agree on the sign verdict.
M4 Maximum-entropy (Lynden-Bell) test. Interpretation (stated, the only one tested): maximise the Boltzmann/Lynden-Bell entropy S = -Int f ln f d^3x d^3v at fixed fluid mass and fixed fluid energy in the given (baryon + fluid) potential, the baryon enclosed mass fixed as the given external field; the stationary point is f = A exp(-E/sigma^2) (Maxwell-Boltzmann; the Fermi-Dirac exclusion-corrected family is the second candidate). Stationarity of the target requires ln f_T(E, L) affine in E and L^2 (L^2 is not a global constraint of a spherical system, so the coefficient of L^2 must vanish). Tests: (a) for the point mass, d ln f_T/dE against a constant over the energy range, and the best one-parameter isothermal and three-parameter Fermi-Dirac fits of rho_c(r) over x in [0.1, 30]: the target is an entropy extremum only if the best fit reproduces rho_c to 10% in that range; (b) for extended baryons, beta != 0 inside the baryons, but the stationary f depends on E alone (beta = 0), so the target is not an extremum of that entropy. Other entropies (Tsallis, Lynden-Bell with a collisionless-relaxation constraint on each shell's mass, entropies with angular-momentum constraints) are NOT tested.

## Criteria stated before the run (each a fail line unless said)

D1 Eddington (M1): point-mass target f(E) >= 0 on the whole range. FAIL if negative anywhere.
D2 LP (M2): FEASIBLE for V1, V2, V3 for the point mass and every h/r_M. FAIL where INFEASIBLE, reported as UNDECIDED where undecided.
D3 Controls of M3 all correct.
D4 Entropy (M4): the target is an extremum only if the fit criterion in M4(a) is met; a fail of the criterion means "not a Lynden-Bell extremum", which is a scoped statement about that entropy, not a no-go for the target.
D5 G4 constants: the door introduces no constant beyond kappa = 1/2 (a0) and Omega_c h^2. The only numbers are a0, G, M_b, the baryon scale h. Any tunable parameter added to make f positive (a cutoff radius, an extra potential, a temperature) would be a new constant and a FAIL of G4.
D6 What the door can and cannot pass: the existence of f(E, L) >= 0 is the kinematic realisability of the target, a NECESSARY condition for a collisionless-fluid mechanism. It gives no mechanism for the enclosed-mass dependence C(r) = (a0/4 pi) M_b(<r), so G1 (target reproduction BY a mechanism), G2 (CMB and growth), G3 (reciprocity and energy), G5 (well-posedness) are not tested by this door; the verdict on them is "not addressed", and the door cannot pass the gates as a mechanism whatever the outcome of D1 to D4.
D7 MUTATE (a control that must change the headline): the target is replaced by a Jeans-inconsistent, kinematically impossible one: (i) sigma_r^2 pinned at V_c^2 instead of V_c^2/2 in V3 (P_r doubled while rho and beta are kept), and (ii) the density of the point mass replaced by the Kepler-cusp r^(-1/4) form (with the same potential). If the normal run's headline is FEASIBLE and the mutated run returns INFEASIBLE, the control bites (the mutated run exits 1). If the normal run's headline is already INFEASIBLE, the control cannot flip it, and that is declared.

## Hypotheses to be reported at the end

Used: spherical symmetry, static potential, Newtonian limit, the potential is the target's own P2 total potential, collisionless (Vlasov) fluid, f(E, L) with no dependence on any other integral, beta prescribed as a function of r. Not tested: non-spherical baryons, time dependence or formation history (whether the DF is REACHED), stability of the equilibrium (radial-orbit and tangential instabilities), the fluid's phase-space evolution through recombination and linear growth (G2), reaction on the baryons (G3), a relativistic completion, non-P2 kernels (nu_mono), and any other entropy than the Boltzmann/Fermi-Dirac ones.

Nothing here says the theory is closed.
