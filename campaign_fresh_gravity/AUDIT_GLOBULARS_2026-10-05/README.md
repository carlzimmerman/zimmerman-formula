# AUDIT_GLOBULARS_2026-10-05: two-sided audit of the outer-halo globular data

**Audited:** `hunt_2026/h93_outer_halo_globulars` (the law over-predicts σ), `CFG332_globulars_three_routes` (class E = Newton is NOT a match at 2.83σ, and 0.27σ without Pal 3, unscored), and `CFG334_pal3_binaries` (BINARIES EXPLAIN Pal 3).
**Data:** `real_research/data/globular_clusters/baumgardt_gc_{parameters,veldisp_profiles}.tsv`; `deepseek_push/data2/{baumgardt_combined_table.txt, bhv4_parameters_2023.csv, bh2018_cds_table2.dat}`.
**Script:** `audit_globulars.py` (~50 s; output in `audit_globulars.out` and `_results.json`). It reads the raw tables directly and imports nothing from h93, CFG332 or CFG334. The only shared code is the frozen kernel `nu_mono`, used read-only. κ = ½, both footings, no downloads, no fitting. No frozen result has been edited.

## Bottom line
- **h93 (the law over-predicts the sparse globulars): robust in sign, overstated in size.** The over-prediction (1.8–2.5× in Pal 4 and Pal 14) is real in every recompute. The input chain is clean: measured photometry, MW baryons only, the right kernel and both footings. Two things inflate the significance:
  - the χ² width ignores velocity errors;
  - the 4.6σ rests mostly on Pal 4.

  With published errors the result is about 3.2–3.5σ, and it is below 2σ without Pal 4. One h93 slip (the fixed-ν Υ_req) runs the other way and **understates** the liability. Pal 14's input is also unsettled: Jordi gives 0.38 against the 0.71 used, and the cluster is tidally extended.
- **CFG332 (class E is near-Newton): not contaminated, but non-discriminating, and its frozen NOT is statistic-sensitive.**
  - Class E *is* Newton at SPS Υ. A "match" therefore shows only that Newton fits; it is not framework evidence.
  - With published errors, T falls to 1.58σ, which would be a MATCH-level number. The frozen 2.83σ NOT stands.
  - The unscored 0.27σ without Pal 3 is post hoc and should not be quoted as a result.
- **CFG334 (binaries explain Pal 3): overstated.** The verdict holds only because the simulated dispersions are unclipped. A standard 3σ clip drops it to PLAUSIBLE. Separately, Pal 3's 1.70 lacks a named primary source, and Baumgardt's own model does not fit it.
- **Contamination:** none. No ΛCDM- or Newton-derived quantity enters any scored statistic. The only Newtonian-model input (the MF slopes in route 2) is already tagged CONDITIONAL.
