# CFG72 -- the spatial light-cone version of CFG70's enclosed-mass exchange

**Question (declared before the first run).** CFG70 made the exchange causal in time. Does giving it a spatial light-cone (a retarded mediator with a finite speed), and extended baryons, change CFG70's verdict against CFG48 G4's pass lines (reaction <= 0.10 g_law; energy <= (1/2) M_b V_f^2, in both r_ta conventions)? And is the coupled fluid-plus-mediator operator stable?

**Model.** A nonlocal time kernel has no unique retarded reading, so this lane uses ONE completion: a local 1+1 "Gauss-law scalar mediator" phi(r,t) on the half-line with E = -d_r phi -> (g_b/N) M_b(<r), inside a Schwinger-Keldysh doubled-field action with the CFG70 fluid, probe and reciprocity partners. Characteristic speed c_m sqrt(1+beta), beta = c_f vt^2/N, set equal to c (beta = 1 is an untied coupling, flagged NEW). Static reaction F/vartheta = r_led - 1/lam_t; the contamination delta = lam_t r_led and the baryon-baryon force ratio f_bb = 1/(lam_t r_led) obey delta f_bb = 1, so this completion cannot suppress both. Derived and sympy-checked in the script.

**Results (one completion; a scoped result, not a no-go for every mediator).**
- **Q1 light-cone kernel: does not change CFG70's verdict.** In the coupled wave + fluid + probe simulation at chi = R_f/(c t_f) = 0.5, 0.05, 0.005 the late reaction equals r_led to 1e-10, so reaction/g_law is CFG70's (0.065 / 0.53 / 2.13 / 7.46 / 22.5 at x = 0.3 / 1 / 3 / 10 / 30, crossing 0.10 at x = 0.38) and the energy ratios are CFG70's (72.8 / 49.6 / 23.0 in CFG48's r_ta; 318 / 179 / 57 in B's). The transient is first order in chi (extrapolated, not simulated, to the physical chi it is 2e-3 to 1e-2 of the peak).
- **Q2 extended baryons: changes the figures, not the verdict.** The extended/point ratio of reaction/g_law spans 0.85 to 116; P1 passes in 0 of 45 cells and P2 in 0. The energy ratio moves 0.90 to 1.20 (the Freeman helper's monotone envelope saturates at 1.20 M_b, a helper artefact used as is). Sensitive to the profile scale (h = 2 kpc versus 0.5 r_M).
- **Q3 stability: growing modes under the declared operator (P4 fails), fragile.** Real growing modes in both readings at every bath time tau, converged from N = 60 to 120. Rates per Gyr for the pressure reading: 3.1e2, 33, 6.2, 0.79, 0.68, 0.082 at tau = r_e/c, 0.01, 0.1, 1, t_dyn = 1.18, 10 Gyr; for reading S: 4.1, 3.5, 1.75, 0.33, 0.28, 0.034. A fluid held at the target by a bath of time tau is unstable at about (0.3 to 0.8)/tau; an e-folding of at least a Hubble time needs tau of roughly 0.3 to 0.6/H0, in conflict with tracking the target within t_f. The mediator itself has no growth and a positive energy Hessian (no ghost); the ideal-gas control has none (1e-16). This rests on a 5/3 shell-gas operator, the bath forms and the position-slaved target; other operators are untested.
- P1 FAIL, P2 FAIL, P3 PASS as a structure (stencil dependence outside the cone 0; retarded Green function outside the cone 2e-18; reciprocity blocks symmetric to 1e-12; an elliptic stencil gives 0.25 so the check can fail), P4 FAIL.

**Controls.** The light-cone width -> 0 control reproduces CFG70's committed late-time reaction to 1e-13. MUTATE a (spacelike kernel) fails C1, C1r and R1; b (reciprocity partners dropped) fails R1; c (kinetic sign flipped) fails T0 and T3; 1 = all three; every mode exits 1. **Kept failures (the main run exits 1):** N1b misses its declared 1e-2 line for the open class (1.05e-2, O(chi)); T5a (a label-slaved bath would be stable) is refuted; T5c (label and S baths grow only from a density contrast of about 159 for S, not 46) is refuted. Two declaration errors disclosed in the docstring and not repaired: D4's "second-order retardation" implication is wrong for boundary-driven sources, and A_fluid's exactness claim for reading P was wrong. In the closed class the derived static exchange force at the CFG44 target is 6.8x (P) or 0.75x (S) the pressure force per node, so the target is not a static solution of the closed reciprocal action; the closed class was linearised only for the declared operator. A one-line pre-run check had suggested growth for the pressure bath.

**Reading.** Adding a spatial light cone and extended baryons does not rescue the exchange: retardation only reshapes the transient, so any retarded completion whose late-time limit is the static enclosed-mass functional returns the same reaction and energy. The added finding is a stability problem for a fluid held at the target by a relaxation bath, for the operator tried. Gaps 1 and 2 stay one identified object. kappa = 1/2 is FITTED; nothing here says the theory is closed.
