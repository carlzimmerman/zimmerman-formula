DATA AND ESTIMATOR

 Per (patch p, class c, bin k) sums S_X[p,c,k] for sample X: WG, WW, NN.  ESD_X(c,k) = sum_p WG / sum_p WW / KG, KG = 1.98847e30 / (3.0857e16)^2 [Msun/pc^2].
 K1 = bins where the lens-median R = sqrt(G Mgal / g_centre) of BOTH classes in the BASE sample is < 0.3 Mpc (expected 8..14; asserted).  G = 4.30091727e-9 Mpc (km/s)^2/Msun.
 D_X = ESD_X(early) - ESD_X(late) on K1 (7 numbers).
SAMPLES: base B = window 10 = all 181,477.  iso20 = flag f20 (no qualifying neighbour with |dchi|<20); iso30 = f30.  Nested by construction: iso30 in iso20 in B.
 Non-isolated at 20: N20 = B minus iso20 (has a qualifying neighbour at 10 < |dchi| < 20).  N30 = B minus iso30.  Disjoint shells: G0 = B minus iso20; G1 = iso20 minus iso30; G2 = iso30.
COVARIANCE: leave-one-patch-out, N = 50: C = (N-1)/N sum_p (v_(-p) - mean)(v_(-p) - mean)^T for each statistic vector v (ESD recomputed from the sums without patch p).
 Hartlap h = (N - n - 2)/(N - 1) with n the vector length (7: 41/49; 14: 34/49; 15: 33/49).  chi2 = h v^T C^-1 v, n dof; p from the chi2 survival function; sigma-equivalent = norm.isf(p/2).
 Quoted errors sqrt(diag C), no h.
AMPLITUDE A_W (CFG96's definition as I read it): A_W = (D_10^T C_10^-1 D_W) / (D_10^T C_10^-1 D_10) with C_10 the FULL-sample jackknife covariance of D_10 held fixed (the Hartlap factor cancels);
 sigma_A = sqrt((N-1)/N sum_p (A_W(-p) - mean)^2) with A_W(-p) = (D_10(-p)^T C_10^-1 D_W(-p)) / (D_10(-p)^T C_10^-1 D_10(-p)).  Variant V2 (reported only): C_10 recomputed... NOT used.
H1 (as CFG96; MUTATE must fail): p(zero-model, K1, window 20) < 0.0027 AND |A_20 - 1| <= 2 sigma_A(20).  Reported R1: the same at window 30.
 R2: per window N, early fraction, median log10 Mgal per class.  R3: D_W / D_10 per K1 bin.  R4: zero-model chi2 on all 15 bins (Hartlap 33/49).

ATTACK ROWS (reported; no pass line except where stated)
 A2 DIFFERENCE OF SPLITS (correct covariance).  For W in {20, 30}:
   (a) nested: r = D_W - D_10 (7 numbers, jackknifed directly): chi2 (7 dof, Hartlap 41/49), p; 1-dof shape fit r = (A-1) D_10 by GLS, A-1 +- sigma with P = h C_r^-1 (analytic (s^T P s)^-1/2) and the jackknife sigma of A (H1's).
   (b) disjoint: r = D_iso_W - D_non_W (non_W = B minus iso_W), 7 dof chi2, and the 1-dof fit r = delta * D_10: delta = s^T P r / s^T P s, sigma_delta = (s^T P s)^-1/2, P = h C_r^-1.
   (c) per class: the ESD difference E_iso - E_non for early and for late (7 dof chi2, p).  A satellite excess should make E_non(early) > E_iso(early).
   (d) K1 pair-weight shares w_iso(class) = sum_K1 WW_iso / sum_K1 WW_base.
 A1 POWER.  Contamination model: the base split contains a contaminant piece c = eps D_10 (eps = fraction of the base split carried by satellites of unmodelled hosts); the stricter window removes
   a fraction eta of the contaminant signal (all of it from the removed set N_W); w_iso = pair-weight share of iso_W (early class, K1-pooled).  Then, to first order,
     A_W = 1 - eps [1 - (1 - eta)/w_iso],     delta = D_non-D_iso shape amplitude (sign: non minus iso) = eps [eta/w_non - (1 - eta)/w_iso],   w_non = 1 - w_iso.
   eta = w_non is random removal (no discrimination, zero shift).  Power of (i) H1's A condition (fail if A_W < 1 - 2 sigma_A): Phi(shift/sigma_A - 2), shift = eps[1-(1-eta)/w_iso];
   (ii) the 1-dof delta test (one-sided, alpha = 0.05): Phi(delta_true/sigma_delta - 1.645); (iii) the 7-dof omnibus test on r (alpha = 0.05): non-central chi2 with lambda = delta_true^2 s^T P s.
   Grid eps in {0.25, 0.5, 0.75, 1.0} x eta in {0.6, 0.75, 0.9, 1.0}, window 20 and 30.  Minimum detectable eps at 80% power (one-sided alpha 0.05, 1 dof): eps_min = (1.645 + 0.842) sigma_delta / |eta/w_non - (1-eta)/w_iso|.
   Upper limit: the observed delta -> 95% upper limit on eps for each eta.  Conversion to a satellite fraction: if a fraction f_s of early lenses are satellites whose extra signal is xi x the early class's own K1 ESD,
   eps = f_s xi <ESD_E>/<D> (pair-weight-weighted K1 means); reported for xi = 1 as f_s = eps <D>/<ESD_E>.
 A3 DOSE-RESPONSE: the disjoint shells G0, G1, G2: for each, D_G, its amplitude relative to D_10 (GLS with C_10 fixed, jackknife sigma), and a joint chi2 (2 dof) that the three amplitudes are equal (jackknife covariance of the 3-vector of amplitudes); the amplitude vs the shell's mean window.
 A4 COMPOSITION MATCH: weights on G0 lenses so that its (class x 8 log Mgal quantile bins of the base within class x 5 uniform z bins 0.1..0.5) counts match iso20's; delta and 7-dof chi2 of D_iso20 - D_G0(weighted).
 A5 ISOLATION CRITERION: only the three dchi windows are staged (10, 20, 30); the 3 Mpc radius and the 0.1 M* threshold cannot be varied.  Reported: composition (R2) and the dose-response (A3); C1b's lens-lens proxy.

   reaches p = 0.0027, 0.05, 0.15.
