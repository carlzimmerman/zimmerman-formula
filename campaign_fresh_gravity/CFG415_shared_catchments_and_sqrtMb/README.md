# CFG415: two doors from the OpenAI release. Door 1 INCONSISTENT; door 2 INCONSISTENT by the frozen rule (proxy-limited)

Criteria in FROZEN_CRITERIA.md. Script `cfg415_doors.py`; MUTATE outputs are in the `_MUTATE` files.

**Door 1 (shared turnaround catchments as "unsettled" fluid, inspired by 373): INCONSISTENT.**
- The median shared fraction is **0.17 / 0.15 for groups** against **0.96 / 0.96 for clusters** (canonical / alt).
- The data ordering has groups carrying about 2× clusters' excess per baryon. Shared catchments put far MORE shared mass in clusters, because cluster spheres contain many group-scale peaks.
- So shared catchments cannot be what makes groups' excess larger.
- It could still feed a cluster-only unsettled share, but that is not tested here.

**Door 2 (settled phantom tracks √M_b, i.e. BTFR slope 4; from 374 via DeepSeek): INCONSISTENT by the frozen rule.**
- The slope is 3.43 ± 0.14 (N = 104 flat-curve SPARC galaxies).
- **Caveat:** the frozen proxy M_b(<R_last) = V_bar² R/G is not the total baryonic mass. It misses gas beyond R_last and uses fixed Υ, which flattens the slope at low mass.
- The record's published-mass BTFR analyses (Lelli+2019 style) give slopes near 3.8–4. So this is a proxy failure, not evidence against √M_b tracking.

**Reading.** Neither door opens. Door 2 restates the BTFR and needs total baryonic masses to test properly.

κ = ½ is fitted. The cold fluid is still required.
