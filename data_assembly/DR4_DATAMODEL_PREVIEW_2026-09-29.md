Purpose: a list of CANDIDATE DR4 tables and columns for the manifest template of `prep_2026/gaia_dr4_prep/dr4_ready_1/PLAN.md` (WP5). Nothing here replaces reading names on release day (Amendment 15(d)); every row carries a "confirm on release day" flag.
Method: web pages read on 2026-09-29 through a page summariser (so wording is the summariser's, not checked against the pages verbatim), plus one HTTP HEAD request. **No file was downloaded.** Facts carry their URL; anything from memory is marked "(from memory, unverified)". Nothing frozen (`PREREGISTRATION_DR4.md`, `AMENDMENT*`, `*_HASH.txt`, `dr4_ready_1/`) was touched.

## 1. DR4 tables named on the ESA page (URL for all rows in this section: https://www.cosmos.esa.int/web/gaia/dr4)
| table | ESA description (summariser) | size stated |
|---|---|---|
| `gaia_source` | "Sources considered to have both high-quality astrometry and high-quality photometry", a subset of ~2 billion of ~2.8 billion processed sources | ~2 billion |
| `all_source_astrometry` | astrometric parameters "for nearly all sources", exceptions: crowded-field and SEAPipe-only sources | ~2.8 billion |
| `all_source_photometry` | G and, where applicable, BP/RP photometry for nearly all sources, except `crowded_field_source` and `gaia_source_environment` | |
| `all_source_rvs` | radial velocities, line broadening, Grvs magnitudes from the RVS | 312 million |
| `all_source_flags` | "a selection of flags of interest for each source published" | 2.8 billion |
| `crowded_field_source` | sources from the crowded-field image analysis pipeline | 19.7 million |
| `gaia_source_environment` | astrometry and photometry of sources detected by the SEAPipe in the surroundings of `gaia_source` sources | 217 million |
| `sso_source`, `epoch_astrometry`, `epoch_photometry` | Solar-system sources; astrometric time series for all sources in the main astrometric processing (129.6 billion records); photometric time series per FoV transit (121.8 billion) | as stated |
| `nss_acceleration_astro`, `nss_two_body_orbit`, `nss_resolved_pair`, `nss_multiplicity`, `nss_multiple_orbits`, `nss_masses` | acceleration models (3.4 M sources); orbital two-body (5.9 M); resolved physically bound pairs (22.8 M); all pairs involving a source (229 M pairs); >2-body orbits (16,681); masses (4.3 M) | as stated |
| `ap_chem`, `ap_class`, `ap_rvs`, `ap_xp` | abundances from mean RVS spectra (35.8 M); classification and astrophysical parameters from DSC/OA/UC (1.8 B); from mean RVS spectra (35.8 M); from mean BP/RP spectra (999.9 M) | as stated |
| `total_galactic_extinction_map`, `total_galactic_extinction_map_opt` | monochromatic extinction at 542.9 nm on HEALPix cells (67.1 M cells); an "optimum" version at HEALPix level 9 (3.1 M cells) | as stated |
| `vari_*` tables | variability classifications and class tables | not needed here |
The page does **not** document `ruwe`, `ipd_frac_multi_peak`, `radial_velocity` or any extinction column of an individual table.

| **cut 13 DR3 stand-in for crowded fields** | DR3 has no such table in the main release pages read; `crowded_field_source` first appeared in the Focused Product Release (https://gea.esac.esa.int/archive/documentation/FPR/chap_datamodel/sec_dm_focused_product_release/ssec_dm_crowded_field_source.html): sources from Service Interface Function images of very dense regions, nominal-catalogue sources excluded, columns include `source_id`, `ra`, `dec`, `parallax`, `parallax_error`, `phot_g_mean_mag`, proper motions, quality metrics | same table name appears in DR4 | YES: DR4 columns may differ from FPR |

## 3. What the draft data model zip could settle (needs the owner's go)
It is described by ESA as the draft data model and is 2.8 MB. It would list every DR4 table and column (names, types, descriptions), which is exactly what WP5's manifest template needs. Candidate outputs: the column lists of `gaia_source`, `all_source_astrometry`, `all_source_flags`, `all_source_rvs`, `all_source_photometry`, `crowded_field_source`, `gaia_source_environment`, the `nss_*` tables and the `ap_*` tables. Amendment 15(d) says names are read on release day and names only, so the draft's column names would remain candidates until confirmed then.
