# FROZEN CRITERIA: rotation curves from the KMOS3D cubes at z >= 1.9 (data front, 2026-09-30)

Written and committed BEFORE any velocity, dispersion or line-flux value was extracted from these cubes. Inputs read so far: file names, FITS header geometry (pixel 0.2 arcsec, 2048 channels, flux/noise/exposure/PSF extensions, PSF image 21 x 21 at the same scale), the KMOS3D main catalogue on disk (`kmos3d_phibss/kmos3d_catalog.csv`, 785 rows), the SINS Table 1 positions and the published SINS Table 6 (used only for the control below), and counts (192 catalogue rows with Z >= 1.9, 180 unique K-band cubes on disk). No cube pixel value has been read. The SINS AO lesson (ADDENDUM_1 of `sins_cubes/`): the frozen method must model the real noise, so the noise scaling below is empirical from the start.
**No acceleration, a0, g_bar or RAR is computed in this stage.** KMOS3D publishes no kinematics table (the data page lists cubes and two catalogues only), so there is no published per-galaxy KMOS3D velocity to compare with; the controls are injection, an independent published comparison on the 5 galaxies shared with SINS, and the catalogue's integrated dispersion.

## Sample
All catalogue rows with Z >= 1.9 whose cube is on disk (K band; the 3 H-band rows are included). Galaxies sharing a cube (`FLAG_ADDGALDET` = 1) are fitted at their own catalogue position. Nothing is dropped after a result is seen; each galaxy gets a flag. Input-side quality class (from the catalogue only): `highSN` if HAFIT_FLUX_HA / HAFIT_FLUX_HA_ERR >= 10, else `lowSN`.

## Method (fixed): 3-D forward model of the Halpha + [N II] cube, fitted to the data (no smoothing, no strip extraction)
1. **Model.** Thin exponential disk, scale length r_d = RHALF / 1.68 (HST H-band half-light radius in the catalogue), inclination from the catalogue axis ratio Q with intrinsic thickness q0 = 0.2 (cos^2 i = (Q^2 - q0^2)/(1 - q0^2), i capped at 85 deg), arctan rotation curve V(r) = (2/pi) V_a arctan(r/r_t), constant intrinsic dispersion sigma_0, rotation sign by position angle. Free parameters: centre (x0, y0) within +-0.4 arcsec of the catalogue position, PA, V_a, r_t (0.02 to 3 arcsec), sigma_0 (10 to 250 km/s), systemic velocity (+-400 km/s of the catalogue Z), total Halpha flux, [N II]6583/Halpha ratio (0 to 1.5, [N II]6548 = 1/3 of 6583). Inclination and r_d are NOT fitted.
2. **Beam and line spread.** The model is built on a 0.05 arcsec grid, convolved per channel with the cube's own PSF image (resampled to the model grid), then rebinned to the 0.2 arcsec pixels. Line spread function: Gaussian of sigma_LSF = c / (2.355 R) with R = SPEC_RES from the catalogue, added in quadrature to the intrinsic dispersion.
3. **Noise.** Per-galaxy empirical scale factor: the robust rms (1.4826 MAD) of the flux in line-free channels (beyond +-2500 km/s of Halpha and not masked) divided by the median noise-cube value in the same channels, applied to the whole noise cube. Channels where the noise cube exceeds twice its median (sky lines) are masked. Fit window +-1800 km/s around Halpha (1 + z); a local linear continuum per spaxel is fitted jointly (linear, solved analytically each step).
4. **Optimiser.** Bounded least squares (scipy `least_squares`, trf) on chi^2 with the scaled noise, from a fixed set of 8 starting points (PA in 45-degree steps with V_a = 150 km/s, r_t = 0.5 arcsec, sigma_0 = 60 km/s, centre at the catalogue position); the lowest chi^2 is kept. Uncertainties from the Jacobian, inflated by sqrt(chi^2_red) when chi^2_red > 1. No priors beyond the bounds.
5. **Outputs per galaxy.** V_a, r_t, sigma_0 and errors; V(r) at r = 2.2 r_d (V_2.2), at r = R_e (= RHALF) and at the last radius where the model Halpha surface brightness exceeds the noise-weighted detection (r_max); i; PA; chi^2_red; a convergence flag; the integrated model line sigma. Flags: `lowSN`, `edge` (best fit at a bound), `badchi` (chi^2_red > 3).
6. **No asymmetric-drift or further beam correction after the fit** (the beam is inside the model); V(r) is the intrinsic circular-rotation law of the model, the product the later a0 lanes will use must carry the model-dependence caveat (an arctan shape is assumed).

## Controls and pass lines (fixed now)
- **C1 (independent published comparison, 5 galaxies).** KMOS3D galaxies at the same position (within 1 arcsec) and the same redshift as SINS AO targets: K20-ID6 (GS4_33639), K20-ID7 (GS4_29868), GMASS-2303 (GS4_40218), GMASS-2363 (GS4_42930), ZC410041 (COS4_08515). Compare the fitted V_2.2 with the published SINS V_rot of Table 6 (Forster Schreiber+18, `sins_ao_table6_kinematics.csv`). PASS if at least 4 of 5 agree within 30% (the SINS value itself is quoted 20-30% uncertain; n = 5 makes this a weak control, reported as such).
- **C2 (injection, with the galaxy's real PSF and noise).** Pick, by a deterministic rule (the 12 highSN K-band cubes with Z >= 2 sorted by catalogue ID, taking indices 0, 15, 30, ... of that list), inject an arctan disk with V_a = 200 km/s, r_t = 0.4 arcsec, sigma_0 = 60 km/s, the cube's own RHALF and Q, a random PA, Halpha flux set so the integrated S/N equals the catalogue value of that galaxy, and noise drawn as white noise at the empirical noise level. Run the identical fit. PASS if the median recovered V_2.2 / true V_2.2 is between 0.9 and 1.1 and the rms scatter of that ratio is below 0.2.
- **C2b (mutate: wrong rotation-curve shape).** Same, but the injected curve is flat with r_t = 0.1 arcsec (sharp) and slow-rise (r_t = 1.2 arcsec, V_a = 300 km/s). Report the bias of V_2.2 for both; PASS if both are within 20% in the median. This measures how much the assumed arctan shape matters.
- **C3 (stability).** Refit all galaxies with q0 = 0.1 instead of 0.2 and with the alternative start set (PA offset by 22.5 degrees). Report the fraction whose V_2.2 changes by more than 20%; stable if the fraction is below 20% among `highSN`.
- **C4 (integrated line width, descriptive).** Model integrated sigma against the catalogue HAFIT_SIG (aperture fit of the same cubes; not independent), fraction within 25%; no pass line.
- **Stage verdict:** the method is VALIDATED only if C1, C2 and C2b all pass. If any fails the profiles are released as NOT VALIDATED, as for the SINS cubes. If C3 fails the V_2.2 uncertainties carry the larger of the two fits.

## Outputs and reporting
`kmos3d_cubes/` CSVs (per-galaxy fit table, injection results, control results) with sha256; code committed before the full run; results reported plainly including failures. Any change to this method after seeing results goes into a dated addendum with its reason, the failing run stays committed, and the C1 and C2 pass lines do not move. A local-sample control (the same pipeline on the KMOS3D z ~ 0.9 YJ cubes, where kinematics are better resolved) is NOT part of this stage and would need its own criteria.
