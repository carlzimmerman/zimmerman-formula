## 1. The theorem (T*), stated before any number

### 1.1 What "closing" kappa means, precisely

Let `C_1 .. C_n` be the theory's **independent, mass-independent, G_lambda-charged** constraints —
each one returning a value or an interval for `kappa`. Define the **kappa window**

    W  =  INTERSECT_i  [kappa_i^- , kappa_i^+]

**T_WINDOW: `W` is a single point, and that point is `1/2`.**

If T_WINDOW holds, kappa is DERIVED and the derived number is that point. If it fails, the lane must
say which of the two ways it failed: `W = EMPTY` (the theory is over-constrained — no kappa satisfies
it) or `|W| > 0.0411 dex` (under-determined; kappa stays FITTED). The allowance **0.0411 dex** is the
record's footing separation (FINAL-16, FINAL-17), pre-registered here unchanged.

### 1.2 The one candidate that would deliver it

Section 2 proves (exactly, by dimensional rank) that **the mass-independent G_lambda-charged ring of
the theory is generated by the single number `kappa`**. So *every* mass-independent "derivation" of
kappa is a statement of the form `F(kappa) = 0` for some function `F` built from the theory's O(1)
constants — i.e. a **choice of value** for kappa, dressed in other variables. The unique member of
that class that (a) lands on `1/2`, (b) uses only `(G, c, rho_Lambda, a_0)`, and (c) has a *named
physical reading* for both the length and the dimensionless factor, is:

> ### T* (the Lambda-Jeans surface-gravity closure)
>
> **The law's saturation value is the surface gravity of the vacuum's own Jeans sphere:**
>
>     a_0  =  c^2 / (2 lambda_Lambda) ,        lambda_Lambda  :=  c / sqrt(G rho_Lambda)
>
> where `lambda_Lambda` is the unique length built from `(G, c, rho_Lambda)` whose **light-crossing
> time equals the gravitational free-fall time** of the vacuum (equivalently, the vacuum's Jeans
> length at sound speed `c`), and the `1/2` is the **surface-gravity factor** `kappa_surf = c^2/(2R)`
> of the sector's saturated logarithmic branch `Phi = C ln r` (GF2; the branch that already yields
> `sigma^2/v_flat^2 = 1/2`).
>
> **If T* holds, `kappa = 1/2` exactly, and the kappa question is CLOSED.**

Note what T* is NOT. It is not FINAL-19's column (`kappa = sqrt(2 pi) = 2.5066`), not FINAL-18's fold

### 1.3 What T* must survive

For T* to be a derivation and not a rewriting, **both** of its two ingredients must be forced:

* **the factor `1/2`** must be a genuine surface gravity, i.e. `lambda_Lambda` must be a **horizon
  radius** of some configuration of the theory (that is what `c^2/(2R)` means);
* **the length `lambda_Lambda`** must be selected by the theory over the other natural vacuum lengths.

The lane tests each separately, because a failure of either is fatal to T* independently.

## 2. The census (why T* is the only candidate) — proved here, not asserted

Weight-0 generators and their (L, M, T) dimension vectors:

    G      = ( 3, -1, -2)
    c      = ( 1,  0, -1)
    rho_L  = (-3,  1,  0)

This 3x3 matrix has rank 3 (det = -2), so `(G, c, rho_Lambda)` is a **complete basis of the dimension
space**: the weight-0 subring contains **no** nontrivial dimensionless quantity. Adding the single
charged generator `a_0 = (1, 0, -2)` gives 4 generators against 3 equations, hence a **one-parameter**
family of dimensionless quantities, and one checks `a_0 = c sqrt(G rho_Lambda)` as dimension vectors,
so the family is generated by

    kappa = a_0 / (c sqrt(G rho_Lambda))          <-- the ONLY one.

Adding a mass `M_b = (0,1,0)` makes it two-parameter; the invariant is `M_b / kappa` (at fixed
`rho_Lambda`), which is exactly why the halo sector is blind to the split between "how much baryon"
and "how big `a_0`" (this is J1 restated in the dimension ring). A **mass-independent** constraint
must eliminate `M_b`, leaving `kappa` alone.

**Consequence (the blocker, in one line):** the mass-independent sector's entire dimensionless content
is the single number `kappa`. Nothing in it can *return* a value for `kappa`; anything that appears to
is a rewriting. A derivation must therefore import a **charged equation from outside the halo sector**,
and the only such equations on the record are the four already-graded ones (fold, column, capacity,
epoch) plus T*.
