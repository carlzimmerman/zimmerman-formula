## 2-minute arithmetic

**Bullet 1 (y-gate partition entropy -> s^2_W = 0.2312):**
Two-channel electroweak partition with weights g^2, g'^2:
  p = g^2/(g^2+g'^2) = (e^2/s^2) / (e^2(s^2+c^2)/(s^2 c^2)) = c^2_W = 0.7688.
So the weights ARE {c^2, s^2} = {0.7688, 0.2312}. The mixing angle is the INPUT,
so the "entropy-selected value" collapses back to s^2_W by construction -> a
tautology, not an independent selection. The seed itself concedes H_2 = -s^2 ln s^2
- c^2 ln c^2 peaks at 0.5, NOT 0.2312, so bullet 1 needs a "free structure
constant to move off 0.5" — which kill condition K explicitly disqualifies
("ill-posed (needs a free structure constant to move off 0.5)").

**Bullet 2 (m_mu/m_e = 206.77 holonomy -> X-pin [106,453]):**
206.77 already sits INSIDE [106,453], so "renormalize into the X-pin" is trivial
band-membership (K's own flagged concern). X/1000 over [106,453] gives
[0.106,0.453]; pinning the image to 0.2312 (X ~= 231.2) has no mechanism — the
fold is arbitrary. Omega = 2*pi*frac(206.77) = 2*pi*0.77 = 4.84 rad carries no
0.2312 either.

**Coincidence gate:** No independently DERIVED shared number. Bullet 1 returns
s^2_W by tautology; bullet 2 is trivial membership that does not encode 0.2312.
The m_mu/m_e <-> s^2_W link is asserted, not derived. This is exactly the
DOF-tautology kill condition (ref_0001, ref_0055, LEDGER 0002/0067:
"P not same across bullets" / "free-fit, seed garbled").

## Why not NEAR-MISS
The only "principled fixes" available are: (a) specify a partition structure that
moves the entropy selection off 0.5 to 0.2312, or (b) fold the X-pin image to
encode 0.2312. Both require making the number come out right -> forbidden
(target-dependent) fixes. No fix survives whose justification is independent of
the target.
