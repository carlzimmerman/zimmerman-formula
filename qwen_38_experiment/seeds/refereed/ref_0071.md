# ref 0071 -- blind referee

## GRADE: DISCARD

## Verdict reason (one line)
The pool {c, G, rho_L, hbar, e} admits exactly one dimensionless combo
(hbar*G^2*rho_L/c^5 ~ 1.9e-123); reaching 137.036 needs e^k with k~630,
not a <=2-transcendental O(1) prefactor, and nu0 is undefined so z_t is
non-computable -- both kill conditions fire.

## Arithmetic (2-min check, on the paper -- mm_search NOT run here)
- Pool {c, G, rho_L, hbar, e}: e (Euler) is dimensionless, so it cannot
  supply dimensional structure; the physical subset {c,G,rho_L,hbar} gives
  4 quantities in 3 dims (M,L,T) => exactly ONE dimensionless invariant.
- Solve M^0 L^0 T^0 for hbar^a c^b G^c rho_L^d:
    M: a - c + d = 0  => c = a + d
    T: -a - b - 2c = 0 => b = -3a - 2d
    L: 2a + b + 3c - 3d = 0 => 2a - 2d = 0 => a = d
  => combo = hbar * G^2 * rho_L / c^5.
- Magnitude: (1.055e-34)(6.674e-11)^2(1.0e-26)/(3.0e8)^5
  = 1.055e-34 * 4.45e-21 * 1e-26 / 2.43e42 ~ 1.9e-123.
- To hit 137.036 from 1.9e-123: e^k = 137/1.9e-123 => k ~ 123*ln(137) ~ 630.
  That is a fitted monster exponent, NOT "<= 2 transcendentals, O(1) prefactor".
- Also: alpha^-1 = e_charge^2 / (4 pi eps0 hbar c) is intrinsically tied to the
  ELECTRON charge, which is absent from {c,G,rho_L,hbar,e=Euler}. No physical
  route to 137 exists within this pool.

## Kill conditions fired
- "No closed form within 1 s.f. of 137.036 at either a0 footing -> REFUTED"
  (the only invariant is ~1e-123; any bridge to 137 needs a fitted power).
- "Requires > 2 transcendentals or a fitted prefactor -> DISCARD"
  (k~630 exponent of e is precisely a fitted prefactor, not O(1)).
- Second bullet z_t = nu0^(-1/3) - 1: nu0 is asserted "fixed by a0" but is
  NEVER operationally defined in the seed, so z_t cannot be computed -> the
  conjunction (single R* threading BOTH bullets) is not falsifiable as written.
- The author concedes e is a "thin" shared-number candidate (1.4732/e^-1 ~ 4.005,
  ~0.1% off from 4), i.e. not tight.

## Fix attempt (was there a principled, target-independent fix?)
No. The only fix that makes 137 come out is to ADD the electron charge to the
pool -- but that is circular (e_charge is what DEFINES alpha), so the fix's
justification depends entirely on the target value: that is p-hacking, not a
principled fix. nu0 cannot be defined without it producing z_t in [17,35],
again target-dependent. No target-independent principled fix exists.

## Note
Not NEAR-MISS: the miss is not "within 2x of a tolerance" -- it is 12+ orders
of magnitude (1e-123 vs 137), far outside any 2x band, and a second bullet is
non-computable. DISCARD is the honest grade.
