# REF 0042 — blind referee

## Grade: DISCARD

Idea H042 claims a single shared dimensionless number X = 1/3 (entropy share of
ONE sector in a 3-fold aether-tilt partition, with Koide 2/3 = 1 - X as its
complement) sits behind BOTH the PMNS solar mixing angle and the recombination
"off-switch". I check the two bullets independently with the pre-registered test.

## Test (a) — mixing angle
Target sin^2(theta_12) = 0.307 +/- 0.003.
- Anchor alone: X = 1/3 = 0.3333 -> |0.307 - 0.3333| = 0.026 = 8.7x the 0.003
  tolerance. The 1/3 anchor MISSES the band by ~9x, so the premise "X is the
  shared number" already fails its own pre-reg test.
- Recovery needs eps = 0.307/(1/3) - 1 = -0.078 (a free param, no independent
  anchor): (1/3)(1-0.078) = 0.3073 lands in band, but this is a FIT to the
  target, not a prediction. Own KILL cond "X = 1/3 chosen after seeing 0.307 with
  no independent anchor for Koide's 2/3 -> p-hacking" FIRES.

## Test (b) — off-switch redshift
z_off = X / (n_b/n_gamma-type dimensionless ratio), compare to recombination
z ~ 1089.
- For X = 1/3 to yield z_off = 1089 the "ratio" must be X/z_off = 0.333/1089
  = 3.1e-4. The baryon/photon density ratio n_b/n_gamma ~ 2.5e-9 (reciprocal
  ~4e8). Neither matches 3.1e-4; no consistent dimensionless ratio links X to
  1089, and no single eps from (a) = -0.078 can fix a redshift construction.
- The two bullets (mixing 0.307 vs redshift 1089) are NOT the same number; they
  are forced into X = 1/3 via unrelated ad hoc constructions. Own KILL cond "the
  two bullets are NOT the same number; DISCARD" FIRES.

## NEAR-MISS check
Neither bullet is a within-2x-tol miss: (a) anchor misses by 8.7x tol and (b) is
dimensionally incoherent (a baryon/photon ratio cannot produce 1089 from 1/3).
No single principled, target-independent fix exists — every fix is value-dependent
p-hacking, explicitly forbidden. NEAR-MISS branch unavailable.
