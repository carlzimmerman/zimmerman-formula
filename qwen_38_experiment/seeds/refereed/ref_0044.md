# REF_0044 -- blind referee for interp_0044

GRADE: DISCARD

## Hypothesis (as decoded)
"Single shared number kappa=1/2 unifies BULLET 1 (X-pin window half-width
coefficient) AND BULLET 2 (n_s-remnant -> rho/n renormalization coefficient)."
Both bullets are flagged as a prediction to be killed, not a proof; kappa=1/2
explicitly stated to be a FIT parameter (0.551+/-0.043), not derived.

## Referee arithmetic / structure check
- BULLET 1 (X-pin window): the headline "observation" is that the window is
  log-symmetric, X_min/X_ref = X_ref/X_max = 0.484 ~ 1/2. BUT X_ref is DEFINED as
  the geometric mean sqrt(X_min*X_max)=sqrt(106*453)=219.1, so
  X_min/X_ref = sqrt(X_min/X_max) = X_ref/X_max is an ALGEBRAIC IDENTITY -- zero
  empirical content. The 0.484 coefficient is just sqrt(106/453)=0.4837; calling
  it "kappa=1/2" is a relabel, not a measurement. Also minor slip: the stated
  X_pin=219.1*0.307/0.5=134.5, not the claimed 133.6 (proposer used 0.305), a
  within-1% arithmetic error that flags the numbers were not carefully checked.
  The genuine test (does a peak sit at X~=133.6 in the X-pin spectrum) requires
  building that spectrum, which has no in-repo object; and it is decoupled from
  the "shared number" premise (the 0.5 it leans on is the tautological one).
- BULLET 2 (n_s remnant -> rho/n): the "renormalization coefficient" IS kappa
  itself, the fit parameter. Checking "does the fitted coefficient equal 0.5" is
  circular; its central value 0.551 already misses 0.5 by 0.051 > the 0.043 tol
  (just outside 1-sigma), so the pre-registered leg does not even hold on the
  fit, and the footing ratio R=1.1279e-10/9.3619e-11=1.2048 (Q0(2)=1.2048*Q0(1))
  is the only footing-defined number and it is NOT 0.5.
- SHARED-NUMBER KILL (the whole hypothesis): one leg (B1) is a tautology, the
  other (B2) is the free fit parameter => the "single number in two places" is a
  tautology-plus-circularity, NOT two independent measurements converging on 0.5.
  The collision is coincidence.
- NOT NEAR-MISS: B2's 0.551-vs-0.5 gap (0.051) is ~1.2x tol, but B1 is
  dimensionally a tautological identity that no target-independent principled fix
  can repair without changing the hypothesis entirely; the only "fix" (measure the
  window from an independent physical bound / predict kappa from a mechanism)
  re-imports the free parameter / new data and is value-dependent (forbidden). No
  single principled, target-independent fix exists.
- Unlinked flavor/spectro (X-pin PMNS readout) + cosmo (n_s remnant) glued by one
  number with no shared mechanism = the numerology/CONVENTION family of
  ref_0033..0043.
- Footings: B1 X=sqrt(y)c/v is dimensionless (footing-independent, stated), so the
  9.3619e-11/1.1279e-10 duality lives only in B2 (Q0 is a0-dependent mass); B2's
  footing ratio 1.2048 is footing-defined but unconnected to 0.5.
- No FDR surface (pure hypothesis decode, no catalog/mm_search run); no
  CONVENTION-grade match counted as a hit.

## Verdict
DISCARD. The unification premise is a tautology (B1 log-symmetry is an identity
given X_ref=geometric mean) plus a circularity (B2 coefficient = the kappa fit
parameter), so the "shared kappa=1/2" is coincidence, not a falsifiable
prediction; neither 0.5 is independently established. kappa=1/2 stays FIT
0.551+/-0.043, never claimed derived. DISCARD is the success.
