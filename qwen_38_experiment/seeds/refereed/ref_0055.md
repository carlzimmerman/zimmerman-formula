## Arithmetic (blind, from interp_0055.md only)
- KILL A (dimensional / DOF tautology): q_g = 0.00994 / 0.00706 Mpc^-1 is a
  WAVENUMBER (dimensionful); c0 ~ 0.31 is DIMENSIONLESS. Equating the two needs a
  committed dimensionful divisor D (Mpc^-1). The interp concedes "No such D is
  committed in the framework => the map is UNRUNNABLE as stated." A free divisor
  chosen so that q_g/D ~ 0.31 is p-hacking by construction -- the same failure mode
  as ref_0001 ("shared C is a DOF tautology") and ref_0024 ("asserts R rather than
  derives it"). This kill is INDEPENDENT of any numerical tolerance.
- KILL B (agreement): c0 must equal BOTH 0.307 (tan^2 theta_12) and 0.363
  (delta_CKM/pi) within tol = 10%. |0.363-0.307|/0.307 = 18.2% (and /0.363 =
  15.4%); both exceed 10%. No single dimensionless c0 within tolerance matches two
  targets that themselves disagree by ~18%.
- KILL C (lattice): the quantization test |Q0*n - c0*m| < tol compares a wavenumber
  times an integer to a dimensionless number times an integer -- dimensionally
  incoherent, so the test cannot even be posed.

## Why not NEAR-MISS
On B ALONE the miss (18.2%) is within 2x the 10% tolerance, which would look like a
near-miss band. But A is a structural/dimensional kill that a single principled
refinement cannot fix: the only candidate fix is to introduce a committed divisor D,
and choosing D to make q_g/D come out to 0.31 is precisely the p-hacking KILL A
forbids (its justification depends entirely on the target value, not on the EFE/Q0
split). NEAR-MISS requires ONE principled fix whose justification is independent of
the number; none exists. The idea is a numerological DOF tautology, not a one-tweak
refinement.
