INTERP 0063 -- "dual pivot" unification of the m_p/m_e interpolation and the charge-quantization duality
Seed: random collision of (i) a footing-invariant drain-vs-pin fixed-point combination
interpolating to m_p/m_e = 1836.15; (ii) a duality exchanging sin^2 theta_W = 0.2312 that
quantizes the dust-mass-IS-the-charge theorem rho/n = Q0; (iii) the wildcard: one shared
dimensionless number.

CHARITABLE DECIPHERMENT
- Bullet (i): the "drain vs pin" is a one-dimensional dynamical balance (drain rate = pin
  rate). Its FIXED POINT is footing-invariant (a fixed point of the autonomous map does not
  depend on which footing 9.3619e-11 vs 1.1279e-10 is used). A footing-invariant COMBINATION
  built on that fixed point is claimed to interpolate to the proton/electron mass ratio.
- Bullet (ii): the duality is an INVOLUTION on the weak mixing: D: x -> 1 - x exchanges
  sin^2 theta_W (0.2312) <-> cos^2 theta_W (0.7688). An involution x -> 1-x has fixed point
  x = 1/2. That same 1/2 is the framework's universal coupling kappa (idealized 1/2,
  fitted 0.551 +/- 0.043). The claim: this fixed point quantizes the charge density
  rho/n = Q0 (the dust-mass-IS-charge theorem).
- Bullet (iii) wildcard ANSWER: the shared dimensionless number is kappa = 1/2 -- the fixed
  point common to both the drain-vs-pin map and the weak-mixing involution.

SINGLE HYPOTHESIS H-0063
There is ONE footing-invariant dimensionless number gamma = kappa (= 1/2 idealized,
0.551 +/- 0.043 fitted) that is simultaneously
 (a) the drain-vs-pin fixed point whose footing-invariant combination reproduces
     m_p/m_e = 1836.1526734(95) [PDG 2022], and
 (b) the fixed point of the involution D(x)=1-x exchanging sin^2 theta_W=0.2312 <->
     0.7688, and which quantizes rho/n = Q0.
If H-0063 is true, the SAME gamma governs both; if the gamma that fits (a) differs from
the gamma that fits (b), the unification is REFUTED.

- sin^2 theta_W = 0.2312 (as given); cos^2 theta_W = 0.7688.
- footings: f1 = 9.3619e-11, f2 = 1.1279e-10 (both must be reported for any dimensional number).
- Q0 = the fundamental charge the theorem sets rho/n equal to.

EXACT TEST (for the blind referee; do not pre-test here)
- Test A (mass): form the footing-invariant combination C(gamma) of the drain-vs-pin fixed

- Test C (the unifier, strongest): the gamma extracted from Test A MUST equal the gamma

  "single number."

KILL CRITERIA (any one kills H-0063)

- K3: gamma_A (from mass) and gamma_B (from charge) differ by more than 0.043 -> the two
