# interp_0058 -- charitable read of seed 0058 (wildcard bridge)

SEED: (a) drained remnant of the 0.108-dex RAR at Ups=0.70 -> CKM CP phase ~1.14 rad.
(b) boundary-term ratio of the top Yukawa (~0.70) -> shadow of kappa = 0.551 +/- 0.043.
Wildcard: what single dimensionless number would BOTH bullets share if true?

## Reading
The 0.70 in both bullets is the tell. "Ups=0.70" and "top-Yukawa boundary
ratio ~0.70" are the SAME number, not two. The 0.108-dex RAR scatter is the
residual noise floor (not a signal); "drained remnant" = the offset left after
the main RAR trend is fit out. The hypothesis: a single bridge number
beta = 0.70 is read two ways -- as a velocity/velocity-like axis value Ups,
and as the top-Yukawa boundary ratio r_t -- and each reading lands on a
different SM/fits target (CP phase, kappa). This is a DIMENSIONLESS bridge
(no footings 9.3619e-11 / 1.1279e-10 apply -- both bullets are pure ratios).

## Hypothesis (one, concrete, falsifiable)
There exists ONE parameter-free interpolation f(beta), beta = 0.70 fixed,
reproducing BOTH targets from the SAME beta:
  - f_Ups(0.70)  = CKM CP-violating phase delta_CKM = 1.14 rad  (target A)
  - f_Yuk(0.70)  = kappa = 0.551 +/- 0.043                       (target B)
with no free parameter beyond beta itself (the function form is pre-fixed:
the RAR-residual-vs-Ups curve for A; the top-Yukawa-boundary-vs-ratio curve
for B). i.e. 0.70 is not two numbers that coincidentally match two targets,
but one bridge read twice.

## Exact test
1. Fix the two function forms from independent data (RAR residual vs Ups from
   the baryonic RAR fit; top-Yukawa boundary ratio vs coupling from a
   1-loop RGE boundary term). 2. Evaluate both at beta=0.70. 3. Check delta_CKM
   lands within its quoted uncertainty of 1.14 rad AND kappa lands within
   0.551 +/- 0.043 -- BOTH at the same beta=0.70.

## What kills it
- If hitting BOTH targets needs >1 free parameter -> coincidence, not a bridge.
- If the same beta=0.70 that nails delta_CKM puts kappa OUTSIDE 0.551+/-0.043
  (or vice versa) -> the "single number" is actually two numbers.
- If either target miss exceeds 1 sigma of its uncertainty -> DISCARD.
- If a naive chi-square over both targets gives p < 1/(searches x 2) it is a
  CONVENTION-grade fluke (not a hit) -> DISCARD.

## Honest prior
This is a wildcard; the prior is that 0.70 appears twice by construction of the
seed, not by physics. Grade honestly -- REFUTED/NULL/DISCARD are fine outcomes.
kappa = 0.551 +/- 0.043 is FITTED, not derived; the bridge would only be
evidence if it predicts kappa independently of the fit.
