# INTERP 0029 -- single shared dimensionless number links Cabibbo boundary term and Koide y-gate

Seed: boundary ratio of A(Q)=kappa^2 G(-K) renormalizes to the Cabibbo angle
(0.2250); a projection of the Koide relation (2/3) quantizes the y-gate;
wildcard asks for the ONE dimensionless number both bullets would share.

## Hypothesis H (one number, two extractions)
There is a single framework number X that is (a) the boundary-term ratio of the
pressure promotion A(Q)=kappa^2 G(-K) that renormalizes into the Cabibbo angle,
AND (b) the Koide-2/3 projection that quantizes the weak "y-gate". The shared
number is the framework's kappa itself (FITTED 0.551 +/- 0.043; NOT claimed
derived -- kappa = 1/2 is a hypothesis seed, not a result).

## Exact quantities
- Cabibbo angle: sin(theta_C) = 0.2250 (PDG; theta_C ~ 13.1 deg).
- Koide ratio: Q = (sum_l m_l)/(sum_l sqrt(m_l))^2 = 0.66665 ~ 2/3.
- kappa = 0.551 +/- 0.043 (fitted).  Framework pressure A(Q)=kappa^2 G(-K).
- y-gate g_y = framework weak-mixing gate parameter (b<->s / d<->s mixing channel).
- Boundary-term ratio r = (boundary term of A(Q))/(bulk of A(Q)).

## Exact test (two independent extractions must agree on X=kappa)
1. CABIBBO SIDE: evaluate r from A(Q)=kappa^2 G(-K) at the weak scale; predict
   sin(theta_C) = f(r) with f the framework renormalization map.
   PASS iff predicted sin(theta_C) = 0.2250 +/- 0.0001.
2. KOIDE SIDE: project Q=2/3 onto the y-gate to get g_y; PASS iff g_y = kappa
   (0.551 +/- 0.043) within kappa's own tolerance.
3. CONSISTENCY: the two extractions must yield the same X (i.e. r and g_y map to
   the same single number).  PASS iff |X_cab - X_koide| < max(tol_cab, tol_koide).

## What kills H
- If predicted sin(theta_C) != 0.2250 +/- 0.0001 -> REFUTED (Cabibbo side fails).
- If g_y != 0.551 +/- 0.043 -> REFUTED (Koide side fails).
- If the two X-extractions disagree beyond their tolerances -> REFUTED
  (no single shared number exists; the wildcard is false).
- If X must be re-fit separately per side (cannot be held common) -> REFUTED.

## Footings
All quantities here are dimensionless (Cabibbo, Koide, kappa); dimensional
footings (9.3619e-11 / 1.1279e-10) do not apply.

## Grade target
NULL or REFUTED are both valid outcomes. A positive would require the single
number X to survive BOTH extractions simultaneously, which is a strong claim.
