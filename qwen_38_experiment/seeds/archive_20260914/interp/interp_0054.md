# INTERP 0054 — seed 0054 interpreted (charitable, then falsifiable)

**Seed bullets.**
 (1) A boundary-term ratio of the *drain flow* might select the Koide relation, value 2/3.
 (2) The continued fraction of the scalar index n_s = 0.9649 might set the *DBI wall*.
 (3) Wildcard: what single dimensionless number would BOTH bullets share, if true?

**Hypothesis H (the charitable reading).** There is ONE framework dimensionless
number — call it the "wall" w — reachable by two independent routes:
 - Route A (Standard Model / leptons): the drain-flow boundary-term ratio equals the
   Koide complement 1 - Q = 1 - (1/3) = 2/3, so  w_A = 2/3 = 0.66667.
 - Route B (cosmology / DBI): the wall is the DBI sound speed c_s, read off a convergent
   of the continued fraction of n_s = 0.9649, NOT a free parameter.
   CF(0.9649) = [0; 1, 27, 2, 24, ...]  ->  convergent 55/57 = 0.96491 (matches n_s to 3 dp).
   The wall map gives w_B = f(partial quotients); the wildcard claim is w_A = w_B.
 The falsifiable core: a SINGLE number, two routes, must agree.

**Exact quantities.** w_A = 2/3 = 0.66667;  n_s = 0.9649 (Planck, 1 sigma = 0.0042);
 CF convergent 55/57 = 0.96491;  c_s = w (DBI wall sound speed). All dimensionless,
 so no length/time footing applies.

**Exact test.**
 1. Compute the drain-flow boundary ratio numerically in the framework; assert
    |ratio - 2/3| < 0.05 (first cut).
 2. Build CF(n_s) = [0;1,27,2]; take the convergent the framework's wall-map uses;
    assert it equals w_A (i.e. the Route-B wall c_s must equal 2/3).
 3. If the single-number unification holds, c_s = 2/3 is a *predicted* (not fitted)
    value; report it to mm_search.py (which self-registers FDR).

**What kills it (any ONE suffices).**
 - K1: drain-flow ratio != 2/3 within tolerance  -> bullet 1 dead.
 - K2: the n_s CF convergent != 2/3. It is 55/57 = 0.96491, off from 0.66667 by ~40%.
   As literally stated (both bullets = 2/3) this is FALSE NOW -> DISCARD the literal form.
 - K3: the two routes require two different numbers -> no shared wildcard; seed is a
   random collision.

**Honest pre-registered note.** K2 is live. 0.96491 != 0.66667, so the literal
"both bullets = 2/3" unification is almost certainly REFUTED. The only salvageable
re-cast: the shared object is not 2/3 itself but the *operation* "boundary/CF ratio"
(i.e. w is a ratio-of-ratios and both bullets instantiate the same ratio-map). Under
that reading the test becomes "do both routes use the same map," not "do they equal 2/3."
Grade honestly on that: expect REFUTED or NULL.
