GRADE: DISCARD

REASON (one sentence):
The "wildcard" Omega* is DEFINED as sqrt(y_t^2 + m_W/m_Z), so bullet 1
(y_t = sqrt(Omega*^2 - m_W/m_Z)) and bullet 2 (m_W/m_Z = Omega*^2 - y_t^2)
are two rearrangements of the SAME single equation -- a tautology (K4
circular, the band itself built from y_t,m_W/m_Z), and no named standard
polyhedron has solid angle 1.1711 (nearest is the regular dodecahedron
~1.1588 sr, ~1% off; tetra 0.5513 / cube 0.5444 / octa 1.9463 /
icosa 2.5861 sr), so K1 fires.

ARITHMETIC (my own, 2-min check)
  y_t^2        = 0.4900
  y_t^2 + m_W/m_Z = 0.4900 + 0.8814 = 1.3714
  Omega*       = sqrt(1.3714) = 1.1711   in [1.1614, 1.1814]  OK
  (arithmetic is self-consistent; the number is not the problem)

  K1 1.1711 is not a named polyhedron's solid angle. No polyhedron is
     even proposed (T1 uncheckable as written); nearest standard value
     (regular dodecahedron ~1.1588 sr) is ~1% off.  -> FIRES.
  K4 relation is circular: Omega* constructed from y_t and m_W/m_Z; both
     bullets are rearrangements of one equation; band derived from same.
     -> FIRES.
  NEAR-MISS not met: no pre-registered geometric tolerance exists, and the
     only fix (name a polyhedron with Omega=1.1711) requires inventing the
     number -> p-hacking, not a principled fix.  -> not satisfied.

VERDICT: DISCARD -- tautology + no matching named polyhedron.
