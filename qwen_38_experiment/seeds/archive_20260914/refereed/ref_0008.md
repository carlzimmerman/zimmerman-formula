# REF 0008 — blind referee for interp_0008 (seed_0008)

IDEA (H8): single dimensionless sigma = 1 - n_s = 0.0351 sets BOTH
(i) a dust-mass charge-ratio saturation 1-(rho/n)/Q0 = sigma AND
(ii) a recombination off-switch T_switch where the RG-run top Yukawa
    y_t(T_switch) = 1 - sigma = 0.9649, predicting z_rec with no free param.

## VERDICT: DISCARD

## Reason (one sentence)
KILL condition 1 fires: the SM top Yukawa is a running-up coupling
(beta^{(1)} dominated by +9/2 y_t^3, Landau-pole direction) so it
DECREASES as the scale is lowered from M_Z; with y_t(M_Z) ~ 0.93 (PDG)
or 0.70 (seed) -- both BELOW 0.9649 -- the equation y_t(T) = 0.9649 has
NO crossing on [0.26 eV, M_Z], so T_switch is undefined and the
z_rec prediction cannot be formed.

## 2-minute arithmetic (the kill)
- Sign of beta_{y_t}^{(1)}: +9/2 y_t^3 > 0 for y_t ~ 0.7-0.93, no sign
  change on the interval -> y_t strictly decreases as mu decreases.
- y_t(M_Z) = 0.93 (PDG central) or 0.70 (seed input) -- both < 0.9649.
- Running DOWN: y_t(T< M_Z) < y_t(M_Z) < 0.9649 for all T in range.
- Therefore {T : y_t(T) = 0.9649} = empty set -> T_switch undefined
  -> KILL cond 1 fires -> H8 refuted without needing KILL cond 2 or 3.
- (Flag as required: the seed itself notes y_t=0.70 vs PDG 0.93, a ~30%
  input error; this only makes the crossing even less likely, since
  both anchors sit below 0.9649.)

## Independent red flag: circularity of the "single number"
- sigma is DEFINED as 1 - n_s, so it equals the measured 0.0351 by
  construction. Bullet 3 ("saturation reading must give 1-n_s = sigma
  agreeing with 0.0351") is tautological -- it predicts the input from
  a definition equal to it. The claim that one number jointly fixes both
  bullets is thus not two independent predictions; it is one number
  (n_s) re-described two ways.
