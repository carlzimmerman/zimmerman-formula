BLIND ARITHMETIC (2-min, from interp_0028 only, no seed/ledger/TASKS context)
Charity functional forms read off a single phase phi = 2*pi*frac(N/k):
  G(N) = 1/phi   = 137.036  =>  phi = 1/137.036 = 0.00730 rad
  F(N) = tan(phi) = 0.2250   =>  phi = atan(0.2250) = 0.2212 rad
Both bullets demand the SAME phi from the SAME N. 0.00730 vs 0.2212 is a ~30x gap,
an order of magnitude beyond any 2-sigma / 2x tolerance. The pre-registered charity
forms therefore fail immediately.

WHY DISCARD (not NEAR-MISS, not PURSUE)
- The two targets are physically unrelated SM quantities: the Cabibbo mixing angle
  (a CKM element, ~13 deg) and the inverse fine-structure constant (a gauge coupling,
  ~137). No known topological object ("drain flow"/holonomy) produces both from one
  winding N; there is no mechanism, so no NEAR-MISS window and no principled fix whose
  justification does not depend on the number coming out right.
- Any (F,G,k,N) that DOES reproduce both 0.2250 AND 137.036 is, by the seed's own
  "WHAT KILLS IT" clause, a search over N/k/F/G => CONVENTION-grade, not a hit. A
  prediction requires F,G fixed a priori; here they cannot be fixed without fitting.
