# interp_0066 -- the single shared dimensionless number

## What the seed is really saying (charitable reading)
The seed collides two bullets and asks for the ONE number both would share:
 (B1) an *entropy partition* of the dust-mass-IS-charge theorem (rho/n = Q0) sets
      n_s = 0.9649 (the observed scalar spectral index; 1 - n_s = 0.0351 tilt).
 (B2) a *polyhedral solid angle* built from the muon/electron mass ratio
      m_mu/m_e = 206.768 selects the pinned Q0 band.
 The wildcard: the two routes must converge on a single dimensionless X.

## Hypothesis (one, concrete, falsifiable)
There exists a single dimensionless X -- the "polyhedral entropy tilt" --
defined geometrically as the solid-angle fraction of one face of a chosen
Platonic solid, X = Omega_face / (4*pi), that is IDENTICAL to the entropy
partition fraction that sets the spectral tilt, 1 - n_s = X.
 i.e. n_s = 1 - Omega_face/(4*pi) = 0.9649  =>  Omega_face = 0.0351 * 4*pi
     = 0.4406 sr, which pins the solid (one face-subtended solid angle 0.4406 sr).
 The SAME X re-enters B2 as the selector: the integer face-count F of that solid,
 read off from a polyhedral solid-angle map of m_mu/m_e = 206.768, must fall
 inside the pinned Q0 band (rho/n = Q0). No free parameter: the solid is fixed
 by X, F follows, and the band is fixed by the framework's Q0.

## Exact quantities
 - X = 1 - n_s = 0.0351 (from Planck n_s = 0.9649), equivalently Omega_face = 0.4406 sr.
 - m_mu/m_e = 206.768 (PDG).
 - Q0 = the pinned framework charge/entropy density (rho/n); Q0 band = its
   pre-registered tolerance interval (both footings 9.3619e-11 and 1.1279e-10).
 - F = integer face-count of the solid with face-solid-angle 0.4406 sr.

## Exact test
 Route A (cosmo): solve Omega_face = 0.4406 sr for the Platonic solid and read F.
 Route B (charge): map m_mu/m_e = 206.768 through the polyhedral solid-angle
   selector to a predicted F and a predicted Q0 band; run mm_search with both
   footings and let its FDR pre-registration stand.
 PASS = Route A and Route B return the SAME integer F AND that F sits in the
   Q0 band; the shared X reproduces n_s to within 2 sigma.

## What kills it
 - Route A and Route B pick DIFFERENT solids / DIFFERENT F -> shared number is a
   fiction, hypothesis DEAD.
 - No Platonic (or archimedean) solid has Omega_face = 0.4406 sr -> B1 cannot
   produce 0.9649, DEAD.
 - 206.768 does not map into the Q0 band under the selector -> B2 fails, DEAD.
 - Any match that is CONVENTION-grade (unit/normalization artefact, not a
   structural coincidence) counts as a DISCARD, not a hit.
