# interp_0082 -- golden-ratio common-number hypothesis

SEED 0082 (collision of two weak hints + a wildcard). Interpreted charitably,
then made brutally falsifiable. Honest flag up front: the two bullets are
independent noise; the "wildcard" is the only thing with teeth. If the wildcard
fails, the whole thing DISCARDS.

## Single conjecture
The ONE shared dimensionless number is the golden ratio  phi = 1.6180339887.
It must appear in BOTH bullets below. This is the load-bearing claim.

## Bullet 1 -- muon/electron mass ratio (SM footing)
"Golden-ratio point of the shift charge Q0*n sets m_mu/m_e = 206.77."
- Define shift charge Q0 = phi. The "golden-ratio point" is the integer index
  n* that minimizes |Q0*n* - K| for an integer anchor K (anchor is a free
  integer, pre-registered before any fit).
- Prediction: the mass ratio is fixed by n* ALONE, i.e.
  m_mu/m_e = 206.7682 = f(n*, phi) with f an O(1)-prefactor rational function
  of phi only (no other constants).
- Exact target: m_mu/m_e = 206.7682835 (PDG). Tolerance: 0.1%.
- KILL: if no integer n* and no O(1)-prefactor rational function of phi hits
  206.768 to 0.1%, Bullet 1 is REFUTED. (Sanity: phi-1 = 0.618, 1.5*alpha^-1
  = 205.55, neither hits; expect this to fail -- that is the point.)

## Bullet 2 -- drained remnant of alpha^-1 -> aether tilt (framework footing)
"Drained remnant of alpha^-1 = 137.036 interpolates to the aether tilt."
- Define drained remnant R = alpha^-1 - D, where D is a named drain already in
  the framework ledger (pre-registered which drain; default D = 0).
- Prediction: R maps to the framework's aether tilt angle theta (rad) by
  theta = R * (phi - 1)  [the golden conjugate], a named one-step map.
- Exact target: whatever theta the framework assigns to that drain.
- KILL: if R * (phi - 1) does not equal the framework tilt within 1%,
  Bullet 2 is REFUTED.
- Dimensional numbers, if any, are checked at BOTH footings
  9.3619e-11 and 1.1279e-10; a footing-dependent result is REFUTED.

## Shared-number gate (the wildcard -- decides PASS/FAIL)
The conjecture PASSES only if BOTH bullets reduce to the SAME phi and each
individual bullet survives its own kill test. If Bullet 1 needs a different
number than Bullet 2, the "single number" claim is false -> DISCARD.

## Verdict routing
- Both bullets survive AND share phi -> PURSUE (one refinement, priced honestly).
- Either bullet fails its kill test -> REFUTED (a success).
- No shared number -> DISCARD.
- k..2-sigma near-miss on either bullet -> REFINE-once (justify tweak blind to
  the target value, trials=2, faces its own referee).
- Never a CONVENTION-grade match counts as a hit.
