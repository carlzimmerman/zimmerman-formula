# Two-electron scattering stage

The authorized objective is absolute finite collision rates coupled to explicit
photon recycling, with shared microscopic inputs and conserved charge/energy.
The previous one-electron spectrum cannot determine these rates.

Work in the same Coulomb atomic units and mass ratio100. Compute correlated
fixed-nuclei two-electron singlet/triplet energies, including the neutral and
negative-ion channels omitted previously. Test basis sensitivity and nuclear
binding. Derive the scattering-to-rate normalization and implement a conservative
finite-rate interface to the existing photon solver. Test that interface using
explicitly synthetic probabilities, never as physical galaxy evidence.

Do not substitute finite Gaussian-basis eigenvalues for a continuum S matrix.
Do not identify unit incident-flux loss with a calculated reaction probability.
If continuum/nuclear couplings are not computed, report absolute rates and a new
physical disk/dwarf/cluster test as unresolved. A first-Born shortcut is acceptable
only if its Coulomb-distortion validity test passes in the relevant gas regime.
No environment label enters microscopic physics.
