Kepler Grade Prediction Chart

Every testable prediction found on the record, dated where the data has a date, with the framework's number, what the rivals say, and what would count against it. The confronted record and the retracted claims are on the same page so the chart does not read as a list of wins.

Standing terms. κ = ½ is fitted, not derived. Two footings, canonical a₀ = 9.36e-11 and alt 1.13e-10 m/s², are never pooled and are written can / alt. The cold energy's mass is still required. This is not a closed theory. Built 2026-10-11 from five sweeps of the repo (predictions ledgers, prep_2026 pre-registrations, lanes CFG1 to CFG700, the atomos kill sheet, memory notes). Some lane folders were only keyword-screened, so this is thorough but not a guarantee of completeness. Release dates for Euclid, Rubin, JUNO, LISA and 4MOST come from the record's own inventories and are not independently verified. Rules applied. Verdicts use raw data against framework-native predictions. Rows tied to the retired modified-inertia arm are tagged MI-ARM and are not live.
K1

Kepler grade. A number fixed before the data exist (frozen criteria or a sealed hash), a date, and a stated result that counts against it.

K2

Capped. The number is sharp, but the test cannot reach 3σ with today's systematics, the rivals predict nearly the same, or it is conditional on an assumption.

K3

Open. A real prediction with no usable data, no date, or only a forecast.
