## What the reading does not derive (section 9)

1. **Where the halo ends.** The end radius x_t r_M comes from the share rule (PD1's Lagrangian share). It is not from
   any equation of motion. Nothing in the record makes a galaxy's halo stop at X M_b.
2. **The halo's profile.**
   - PD1 P7 / A2 item 5 records it as a closure: the component's dispersion is locked to
     sigma^2 = (1/2) sqrt(G M_b a0), equivalently div Pi = -rho (nu - 1) g_N.
   - Since then the lead's note FB1 (`fable52_push/FB1_form_b_from_the_action/NOTE.md`; a note, not a graded lane;
     not re-derived here) has checked one thing about PAPER70's action (QX17 (A)). With a static clock, gamma_L = 0
     and mu_K = 0, its static equations give the law's halo as the khronon sector's own energy density. The canonical
     stress of the law's Lagrangian then balances it pointwise.
   - FB1's own caution: the stress identity holds for any J(g), so it shows self-balance, not that this J is right.
   - So the profile inside the end radius has a static solution in one action of the record. Three things have none:
     the collapse that reaches it (the 2026-11-01 spiral wall); one mu_K that is both dust for the CMB and small
     enough for galaxy lensing (FB1 section 2); and the end radius.
   - **No action in the record produces the profile from infall. "Expected: none" holds for the dynamics, not for the
     static state.**
3. **Where a0 = (1/2) c sqrt(G rho_DE) enters.** In this lane, only through the halo:
   - its scale r_M = sqrt(G M_b / a0), and with it the end radius and the dispersion relation above;

   through a0.

## What I found wrong in the lead's pre-freeze note

1. **The calibration.** The note's table puts the halo's end at the catalogued masses (k = 1). The same lenses' inner
   window asks for 2 to 3 times those masses. The end radius grows as sqrt(k M_b), so the shape ratio does not cancel
   the calibration for this model. With k fitted, as KO1 PH3 did, PD1's share gives R_s 0.86 / 0.73 without neighbours
   and 1.00 / 0.85 with them at 1.6 R_h, not 0.525 / 0.477. The note's "1 to 2.5 sigma low" becomes 0.2 to 2.7 sigma
   **high** across the vetoes. The model then sits close to the law with no end (0.98).
2. **"Late below, early above."** That holds at k = 1 only (early +1.56 / +1.96 sigma at 1.6 R_h). With the inner-window
   calibration fitted per type, early types sit on the model (-0.65 / +0.21) and late types below it. The frozen
   type-difference line passes at every veto, so "by type it does not close" is not what the frozen statistic reads.
   What does hold is that late types sit low.
3. **The neighbours' "about 0.1".** E8's point masses scaled to 59.5 M_b do raise the outer amplitude by about 0.1. They
   raise the inner window more, so R_s moves by only +0.02 / +0.04. The reading's own extended halos move R_s by +0.06
   (1.0 R_h) and +0.13 (1.6 R_h). The number is right in size at the widest veto, but not by the note's route.
4. **Monotonicity in X.** R_s does not rise monotonically all the way to the law. At k = 1 (canonical, 1.6 R_h) it rises
   from 0.10 at X = 5 to 1.017 at X = 300, then falls back to 1.000. A halo that ends just beyond the outer bins lacks
   the exterior shells that lower DeltaSigma there (Lean `shell_lowers`). The inner amplitude is not monotone either:
   1.008 at X = 23, 1.020 at X = 40, then falling to 1. So the Lean lemma `ratio_mono` applies on X <= 300 for the outer
   amplitude, not as a global statement.
5. The note's X = 59.5 is 59.486 / 59.503 by PD1's own table. That makes no difference.
