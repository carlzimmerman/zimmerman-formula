# AZ45 amendments

## A1 — batch signal forwarding, before production grid submission

The batch handler currently polls and signals the child inside the handler.
Move child notification to the normal polling loop, once per interrupted
child; the handler must only set its flag. This corrects the process contract
without changing the4032-case iterator, numerical engine, worker, fitting
budgets, data, control definitions, identities or grading tolerances.

Before queue submission, verify the handler structure and interrupt a real
bounded one-case batch while its worker is live. Require parent exit75,
worker checkpoint existence, no remaining child, resumed scientific output
identical to an uninterrupted one-case baseline, and preservation of the
completed case when the next bounded batch resumes. Partial batches still
exit75; only all4032 completed computations may produce COMPUTE_DONE.json.
This amendment is committed alone before the controller edit. No physical
verdict or post-result tolerance change is authorized by this correction.
