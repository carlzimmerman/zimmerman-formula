# TP01-SC conditional capacity continuation, before its forward run

Primary run 002 passes its controls. Known diagnostics: initial spin adds no leave-one-out prediction skill; contraction weakens the S–spin rank association and reduces its scatter. Thus no measured predictive spin model is established. This continuation tests only capacity under the explicitly idealized association allowed by the original contract.

Inputs: run 002's nine measured pairs, frozen SL1 NR1-primary cache, raw SPARC catalogue for effective brightness/disc sizes, NR2's completed median anchors and recorded scalar baseline. The forward code reads cache arrays directly; it never executes mutable legacy pipeline modules. Reproduce cached NR1 baseline to 1e-9 in Upsilon/rms. Rebase only eta below 10^12 to NR2's medians via the already specified log-interpolation rule, and require Upsilon within 0.005 and rms within 1e-5 of NR2's recorded line before interpretation. No cluster or group grading in this continuation.

Preserve each actual pair (S_no_disc(z0)/median S_no_disc(z0), f_Q). At every galaxy's halo mass, multiply NR2's S by that measured factor and retain cold mass/R200 with the existing compact smooth-core root (explicitly report saturation). Compute the response on each observed baryonic load, one-mass homology assumed. The spherical Blumenthal shell equation is solved directly at queried final radii, rather than discretizing 300 initial shells. Benchmark it against both 300- and 1200-shell legacy interpolation on the first three eligible galaxies at Upsilon .50; require <0.5% maximum relative mass difference from the 1200-shell result. This tests a numerical realization of the same spherical prescription, not its physical validity.

No-association model: average the nine predicted cold forces at each galaxy, retaining joint seed pairs. Idealized rank model: order seeds by initial spin, galaxies by catalogue effective brightness, and assign lower-spin pairs to brighter quantile bins. This rank-perfect association is stipulated, not measured or optimized. Missing/nonpositive brightness uses the ensemble mean. The same rank bins apply to both backgrounds. Diagnostic controls: scatter with no response under the identical ranking; median f_Q response with no scatter; cyclically permuted f_Q under the same scatter/ranks. Do not select the better permutation or association.

Grade all 175 rotation curves with original radial weights, masks and Upsilon grid; report rms, median Upsilon and six velocity-bin medians. HS1 sample/cuts: Vflat 60–120, Q<=2, inclination>=30, Upsilon=.50 at 2 Rd, interpolate in log R only inside measured support. Bootstrap 10,000 galaxy samples, PCG64 seed 20261101; report slope, uncertainty, mean residual and rms. A joint line requires original rms<=.110 and median Upsilon .50–.80 on both backgrounds, plus |b|<=2 sigma on background A. Report each gate even on failure. An idealized pass establishes capacity only under rank-perfect association, inherited one-mass response and fixed profile assumptions. It does not establish galaxy spins, angular-momentum retention, feedback, or general cosmological dynamics. Preserve raw per-galaxy output and v2 provenance.
