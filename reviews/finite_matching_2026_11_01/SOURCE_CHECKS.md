# Source and convention checks

Authenticated primary source: Stephen P. Martin, hep-ph/0111209v2,
[full HTML](https://arxiv.org/html/hep-ph/0111209v2) and
[PDF](https://arxiv.org/pdf/hep-ph/0111209v2), read through web tools on
1 November 2026. The coefficient V^(2) excludes (16 pi^2)^-2.

- Equations 2.10-2.16 define real-scalar, Weyl, scalar/vector and gauge
  vertices. Fermion rotations need only diagonalize squared masses; a
  verified Takagi basis permits diagonal real mass insertions.
- Equations 2.17-2.28 define the subtracted master integrals, including
  finite zero-mass cases. These are renormalized vacuum functions.
- Equations 4.2-4.11 fix graph symmetry factors. In particular barFFS has
  an explicit complex conjugate; barFFV does not have an extra one.
- Equations 6.11-6.30 give all ten DRbar-prime classes. The scalar and
  scalar/fermion functions are unchanged from section 4; vector functions
  must include dimensional-reduction contributions. MSbar vector functions
  would not be consistent with the supersymmetric input running.
- Section 8.1 supplies the supersymmetric Wess-Zumino cancellation;
  section 8.2 supplies broken and unbroken supersymmetric Abelian controls.

The Landau-gauge component scalar anomalous dimension in Eqs 7.5-7.6 is
different from the chiral-superfield anomalous dimension in Eqs 7.8-7.9.
At one loop its gauge term is -g^2 C, whereas the chiral term is -2g^2 C.
An unreduced component-potential CS check must use the former. The retained
X field is a gauge singlet, so the two agree for X; this distinction does
not by itself invalidate TP02's fully heavy-minimized fixed-X CS equation.
It does change the dictionary for gauge-charged background coordinates.

No external theorem supplies the model-specific finite graph contractions,
current vertices, selected state or a finite remainder bound. Those require
the calculations and explicitly stated limits in this checkpoint.
