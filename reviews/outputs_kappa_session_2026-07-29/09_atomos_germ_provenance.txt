S4. A SECOND, INDEPENDENT ISSUE: there are two different 3's
==================================================================================================
  The germ pool lists `3` as 'the generation count' (an SM fact).
  But sqrt(8pi/3) already contains a 3 -- Friedmann's, from Lambda = 3H^2/c^2,
  which is about spatial geometry and has NOTHING to do with generations.
  Same numeral, two unrelated origins. Treating them as one germ family, or
  letting one stand in for the other inside an expression, is a numerological
  conflation of exactly the kind the paper warns against.

  Worked check -- the two 3's enter with different powers and different roles:
    Friedmann 3: Lambda = 3H^2/c^2   -> enters Z as 3^(-1/2) = 0.577350
    generation 3: a COUNT, dimensionless, enters as 3^(+1) = 3
  [OK  ] Friedmann's 3 enters as an inverse square root, not as a count
  The enumeration's step menu contains POW in {2,3,1/2,-1,2/3} and unary
  {SQRT,CBRT,INV}, so it can freely convert 3^(-1/2) <-> 3^(+1). The two 3's are
  therefore NOT distinguishable inside the search -- it cannot tell a generation
  count from a piece of FRW geometry.

S5. What this does to the NUMBER-FIELD OBSTRUCTION
==================================================================================================
  The standing obstruction reads: 'Z carries a transcendental sqrt(pi) while the
  flavour and coupling data are algebraic, so an exact identity requires the
  sqrt(pi) to cancel -- in which case the germ was not load-bearing.'

  That argument is CORRECT for the search that was run, since the germ used
  really is sqrt(8pi/3). But it must NOT be read as 'the framework's number is
  transcendental'. The framework's number is kappa = 1/2, RATIONAL. The sqrt(pi)
  belongs to Einstein's 8pi, i.e. to GR.

  Note the flip side, stated against interest: a search whose germ were the
  framework's actual rational kappa would be VACUOUS -- rationals are dense, so
  any measured constant sits inside some rational's window and the search would
  certify noise trivially. The transcendental germ is what made the atomos search
  non-trivial in the first place. So the vocabulary choice was pragmatically right
  even though its provenance was mislabelled.
