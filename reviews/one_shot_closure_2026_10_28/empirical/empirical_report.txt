2. A universal hot-group sign exclusion is false

High-priority claim-scope correction:
  DS1_hot_displacement/README.md:29-36;
  GA1_group_gas_audit/README.md:59-60;
  DY1_group_dynamics_audit/README.md:47-48.

These passages move from several tested models predicting positive D to an
assertion about every g_pred=F(g_bar). The latter assertion is false.

HG1's statistic is correctly oriented: in 0.1-dex sigma bins it computes the
BRIGHT-minus-FAINT difference of median residuals, then averages those with
weights min(n_B,n_F) (hg1_hot_gas_selector.py:130-142). The residual is relative
to a rising KiDS reference. Thus increasing absolute g_pred does not imply an
increasing residual. No sign inversion was found in HG2, HO1, DS1, GA1 or DY1.

Independent finite result (statistic_run/result.json):
  Source groups: 190; supported: 188; shared bins: 11 BRIGHT and 105 FAINT.
  Independently reproduced D_measured = -0.2939826776809691 exactly to 1e-12.
  F(g)=A*g^0.1 gives D_pred = -0.21127935425469407.
  F(g)=A*g^0.01 gives D_pred = -0.2866506371691509.
Both F are positive and strictly increasing. A is selected so that F>=g_bar
on every supported sample row (within 5e-15 floating error). Their D values
are inside HG2's stored [-0.511,-0.076] interval. This is a finite mathematical
counterexample to the universal sign assertion, not a proposed physical fit.

An exact structural explanation also follows. Set
  F(g)=g_ref(g)*(g/g_*)^(-epsilon).
Then its residual is -epsilon*log10(g/g_*). Affine equivariance of each median
gives D_pred=-epsilon*D(log10 g_bar). On these stored rows,
  D(log10 g_bar)=0.8684996586756988.
Therefore any epsilon>0 produces negative D. This identity does not guarantee
monotonicity of that particular F, but the power-law examples above do.

The correction does not change the failures of the tested CL2, GT1, or DS1
rules. Suggested replacement: "Every explicitly tested rule in these lanes
predicts the wrong sign on these inputs. No general exclusion of F(g_bar)
has been established."

3. HG2 is an open model-dependent tension, not a precision exclusion

HG2's frozen classification remains UNDERPOWERED: power 0.448 against 0.50,
11 shared-bin bright groups, measured D=-0.294 with interval [-0.511,-0.076]
(HG2 README.md:17-35). Its planted +0.30 control shifts D by exactly +0.30;
the failed expected class is a control-design mistake, not failure to respond.
The power calculation simulates a planted positive effect with group scatter
and a fixed reference. It does not license a stronger astrophysical exclusion
just because the observed sign is negative.

GA1's audited gas model gives D=-0.362 versus +0.306 predicted (canonical),
and DY1's member-velocity calculation gives -0.373 versus +0.326. The sign
survives these specified checks. It does not follow that gas masses or dynamics
are universally "sound": GA1 replaces gas estimates by a finite scaling fit;
DY1 checks catalogue dispersions on substantially the same memberships. The
geometry of 3*sigma^2/r, membership systematics, covariance of shared sources,
and the difference between lensing and dynamical estimators remain open.

The HO1/GA1/DY1 frozen rule compares a point D_pred with a confidence interval
for D_meas. Both quantities depend on the same estimated reference curve and
on noisy group inputs, while prediction uncertainty is not propagated. For a
formal model-rejection significance, jointly resample data and prediction and
evaluate their paired discrepancy. Also, D(x-y) need not equal D(x)-D(y), since
medians are nonlinear. No formal global significance is certified here.

4. FD1: frozen result survives, while the physical test remains inadequate

At 36b861cb7414dde9e39bdc2e9653facb620b1b01, FD1's completed primary gives
IC 1613 E=-0.3054129528 dex, Z=-3.854726681 canonical, versus the earlier
-0.5351615 dex and about -6.75. The improvement is about 43%, so it correctly
misses the frozen at-least-half reduction criterion. Field S1/S2/S3 all fail.
The alternate result is E=-0.3431475851, Z=-4.468870301. These are faithful
statements about the declared inputs and old error model, not robust physical
exclusion significances. FD1 is a law-branch test and does not regrade BS1's
halo branch (FROZEN_CRITERIA.md, section 2).

The script changes stellar mass, inner gas assignment and kinetic terms while
retaining sdMC[Newton] as s (fd1_field_dwarf_audit.py:64-72). It neither
propagates the new quantities' errors nor resolves whether global HI rotation
belongs at the stellar half-light radius. The README now acknowledges the
rotation approximation. Source-specific kinematic validation is being handled
by the coordinator; no external literature was independently authenticated in
this sub-audit.

Concrete numeric prose correction: FD1 README.md:31 says the 13 km/s rotation
term adds +0.06 dex. It actually adds
  log10(1 + 13^2/(3*10.8^2)) = +0.1711316437 dex.
The stored primary minus M+G and K-only minus baseline agree with this. The
main table is consistent; this is an explanatory-text error. The mass-only
step shifts E by +0.23256 dex. Adding gas after that shifts E by -0.173946 dex,
whereas adding gas to the old mass alone shifts E by -0.08272 dex. Mixing the
standalone and sequential changes is not a valid additive decomposition.

The FD1 mutation stops on log10 of negative kinetic energy for a strong
rotator after printing the deliberately failed K0; the README discloses this.
It is not a completed mutation-output verification. K1 is set True in source
(line 84) while match/miss details are printed; it is not an independent
assertion of catalogue correctness.

5. LEE1 is local parameter-volume accounting, not a trials correction

The stored 24 seeded draws give 10 canonical passes and zero alternate passes.
The source computes the 68% Clopper-Pearson interval correctly for those draws,
about [0.303,0.539]. "BROAD" is its frozen p_hat>=0.40 class; the interval
straddles that threshold, so the class is not strongly determined by 24 draws.
The box and fixed S9/budget prescription were chosen after locating passes
(LEE1 README.md:84-92). This is useful local robustness information, not a
global look-elsewhere correction, Bayes factor, or null-model p-value. The
historical 4/48 configuration count is a dependent adaptive search record;
its printed binomial confidence interval has no sampling interpretation
without a population and sampling design. The README correctly avoids using
that census as the final model's pass rate.
