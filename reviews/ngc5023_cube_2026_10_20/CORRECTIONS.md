# Preserved versions and qualifications

The initial acquisition/contract language called the older WHISP cube
independent on the basis of its separate 1996 campaign. The later
`independent/INDEPENDENCE_CHECK.md` narrows that statement: different
campaigns are verified and the primary papers describe new HALOGAS tracks,
but a complete observation-ID manifest certifying zero reused visibilities
was not recovered. Both use WSRT. Do not multiply significances as fully
independent. Earlier source, candidate and run versions remain unchanged.

`plot_run001` retains the initial independence labels. `plot_run002` is
the current presentation and labels distinct campaigns with the visibility
overlap qualification. This is a label/provenance correction, not a
scientific rerun or changed candidate. All original run hashes remain valid.

The initial known-feature mask tests bin centers. The additional
footprint-aware masks remove a selected bin whose footprint partly
overlaps a known-feature exclusion. The selected region was not moved
after seeing the older cube. Both the original and stronger controls are
retained; stronger masking does not prove the known source causes the
signed contrast or erase the measured emission.

Initial center-grid blank-scatter labels reuse the nominal blank operator;
they quantify sensitivity, not calibrated significance at every nuisance
point. Additional cubic/dewarp/baseline/spectral controls explicitly
reprocess blank apertures through the same operator. No Gaussian discovery
sigma is claimed anywhere in the reconciled report.

The first primary download failed on sandbox DNS access before creating a
data file. The explicitly authorized public download then completed with
network access and verified release checksums. No scientific run failed;
acquisition failure is not a physics result.
