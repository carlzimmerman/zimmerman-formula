## Executed analytic discriminator: the response receipt

This subsection independently reconstructs a necessary response condition
directly from the frozen S2 action, rather than accepting an interpolation-fit
verdict. It is analytic self-review; the coordinator can compare it with the
independent response reconstruction in the parent packet.

Expand S2's square. At prescribed total source `g = grad Phi`, the material
energy and its coupling are

`E_mat[P] - g.P`, with
`E_mat = K P^2/2 + W(u) + gamma |grad P|^2/2`, `u = K|P|`.

On a uniform aligned responding branch,

`g = u + K W'(u) = u + u^2/(a0-u) = a0 u/(a0-u)`.

Therefore `u = a0 g/(a0+g)`. The radial and tangential Hessians of the local
material functional are, respectively,

`H_parallel = K + K^2 W''(u) = K a0^2/(a0-u)^2`,

`H_perp = K + K^2 W'(u)/u = K a0/(a0-u)`.

The gradient term adds `gamma k^2` to each. Here parallel/perpendicular refer to
the background `P`, not automatically to the wave vector. Choose a probe with
`k` parallel to `P` for the density-carrying longitudinal channel. Its static,
irreducible material susceptibility must satisfy

`chi_parallel^mat(0,k) = 1/[K a0^2/(a0-u)^2 + gamma k^2]`.

At `k -> 0`, `K chi_parallel^mat = [a0/(a0+g)]^2`; at `u = 0` it becomes
`1/(K + gamma k^2)`. The transverse receipt is
`1/[K a0/(a0-u) + gamma k^2]`. These are necessary local tests of the exact
constitutive energy. A candidate matching this Hessian still owes the full
nonlinear `W`, normalization, source, domain and dynamics.

This is a **material response at prescribed total source**, not the full
self-gravitating response to a change in baryonic density. Gravity and the live
host must then be eliminated exactly once; the longitudinal critical `K` term
already cancels its own Newtonian attraction in the canonical on-shell energy.
Adding a second copy would change the law. The prior fixed-environment derivation
is `reviews/polarization_link_2026_10_20/CANONICAL_MEMORY.md:8–54`.

The same prior result establishes strict convexity on a fixed convex admissible
class and hence at most one static minimum (`CANONICAL_MEMORY.md:56–96`). Thus
an unchanged canonical field in the same domain cannot store memory by choosing
between two polarization minima. At nonzero source, imposing `P=0` while allowing
arbitrary small material variations does not make an off branch
(`CANONICAL_MEMORY.md:98–113`). A real memory state must alter a physically
derived microscopic sector/domain or add an actual dynamical state variable
from the existing fields. Calling a state old, bound, free or topological does
not establish that change.

## The precise next test: release, restore, probe

Choose one finite candidate condensate/collective state and one live baryonic
host, with actual microscopic action, supply, charges, angular momentum,
boundaries and energy receiver specified. Define the microscopic operator for
the additional `P` **before** computing its response. Do not select whichever
density/current combination happens to give the desired answer afterwards.

Prepare two histories. In A the candidate remains on its bound branch. In B a
physical source/host cycle releases it, and then restores the measured source
controls and coarse material conditions used for comparison. Count work,
escaping flux and host recoil; a change in local mass is not silently called
the same material state. Where exact matching of a coarse condition is
impossible, keep the difference explicit instead of claiming a matched test.
The final microscopic states may differ: that difference must be the actual
candidate memory, not a hidden population bit.

At the three checkpoints—bound, released, restored—compute the same retarded
mode-resolved susceptibility, including the host, and record both:

1. retained ordinary gravitational mass/density and its legitimate response;
2. the additional canonical polarization response under the operator map.

The responding branch must have the canonical material receipt above (and the
parent packet's frequency/spectral checks). The released branch must lose the
specified additional response while retaining whatever mass the proposed
memory needs. A zero-density vacuum, free-motion pole, host support held fixed
by hand, or merely different total mass fails to demonstrate this switch.
Ordinary gravity is allowed to respond after release.

**Restoration null.** In the same canonical connected admissible domain, at
restored source and boundaries, equilibrium response returns to the unique
canonical branch. An asserted permanently released/non-recapturing S4 state
must therefore supply a distinct physical sector/domain or a calculable
nonequilibrium state with an actual lifetime. If it returns to the responding
branch after restoration, the permanent-memory claim fails for that candidate.
If it stays off only because a label or a fitted damping/capture rate was
inserted, the microscopic closure test also fails. No unknown bath occupation
or release timescale may be replaced by a fit to the dwarf excess.

**Cross-population holdout.** Use the same derived state rule and coefficients
to predict which measured histories put dwarfs, red spheroids and cluster cores
on which response branch, with gas-rich rotators as the control. Hold the
third excess population out while checking the first two; the state rule must
predict the third and must preserve cluster OUTER and the rotators. Carry each
population through its actual observable operator and radius. This is a
validation requirement after deriving a candidate, not permission to fit a
new two-variable selector. If the microscopic inputs needed for that prediction
are unmeasured, the result remains conditional, with the missing input named.

The cheapest decisive work is the analytic finite-host Hessian/source and
response calculation, followed by release/restoration limits. An astronomical
snapshot of remnant mass alone cannot measure this susceptibility. The current
repository's class averages do not execute this test.
